# 《让你代管废材班，怎么成武神殿了》第一章 — 分镜脚本

> **小说标题：** 让你代管废材班，怎么成武神殿了  
> **章节：** 第1章 最强名师系统  
> **作者：** 向阳的心  

## 世界观

全民武道，凶兽纵横。武道境界：九品武者→八品武灵→七品武玄→六品武尊→五品武王→四品武皇→三品武帝→二品武神→一品武圣。淬体液是昂贵稀缺资源。

## 人物设定

- **苏阳** — 27岁，武道理论教师。清秀疲惫，不甘野心。简约深色武道服/衬衫西裤
- **刘振** — 高一年级组长。虎背熊腰，魁梧硬朗。深色西装或教官制服
- **李老师** — 年轻男教师，刚转正，稚嫩紧张
- **陈老师** — 转业军人，脸上伤疤，缺左手。杀伐果断
- **五班学生** — 权贵子弟，张扬跋扈，反骨难驯

## 六大场景

| 场景 | 内容 | 关键画面 |
|------|------|---------|
| SC-01 教学楼的坠落 | 前班主任被踹出窗外，砸地怒骂 | 坠落 + 尘土 + 围观麻木的学生 |
| SC-02 年级组长的头疼 | 刘振愁眉按太阳穴，俯瞰校园 | 特写眉头 + 背影剪影 |
| SC-03 第四次紧急会议 | 无人敢接五班，陈老师亮狠话 | 会议室沉默 + 拍桌 + 淬体液条件 |
| SC-04 系统觉醒 | 蓝色全息面板浮现，师者无敌技能 | 瞳孔微光 + 蓝色系统UI + 金光技能 |
| SC-05 挺身而出 | 苏阳弹起接任务，全场震惊 | 突然起立 + 刘振大喜拉走 |
| SC-06 任务完成与终极誓言 | 刘振指大理石桌发誓 | 拍肩 + 吃桌子誓言 + 走向教室门 |

## 视觉风格

- **风格：** 日系动漫（类似《我的英雄学院》《咒术回战》）
- **色调：** 现实场景冷蓝灰 → 系统觉醒蓝光 → 决心后暖金色
- **系统面板：** 半透明蓝色全息 + 发光中文 + 技能品质颜色（金=神话）
- **比例：** 全部 16:9
