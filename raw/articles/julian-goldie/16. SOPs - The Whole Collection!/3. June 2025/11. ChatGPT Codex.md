 What Is Codex?
Codex is a 
cloud-based AI agent
 designed for 
software engineering tasks
. It can:
Write features
Fix bugs
Propose pull requests
Answer questions about codebases
It's not built to replace tools like Cursor or Windsurf but is more like a smart, cloud-based coding partner.

 Step-by-Step SOP: How to Use Codex
1. Access Codex
Available to 
ChatGPT Pro
, 
Enterprise
, and 
Team users
 first
Plus and Education users
 will get access later
2. Integrate with GitHub
Link a GitHub repo
Choose the branch to work on
You’ll be able to:
View open/merged PRs
Inspect diffs and changes
Interact with Codex using 
natural language
3. Assign Tasks
Type a prompt and hit 
“Code”
Or simply 
ask a question
 about your codebase
Each task runs in an 
isolated, preloaded environment
Includes access to your codebase, env variables, terminal, test suites
4. Task Execution
Codex reads and edits files
Can run terminal commands and tests
Tasks can take 
1–30 minutes
You can 
run multiple tasks in parallel
5. Review and Verify
Codex commits changes directly
It provides:
Terminal logs
Test results
You’ll be able to 
verify the work
 just like in tools like Cursor
6. Open Pull Requests
Codex can open PRs directly
Helpful for teams where AI writes code and devs do the code review
7. Customize Behavior with agents.md
Place an agents.md file at the 
root of your repo
Use it to:
Define project rules
Specify test commands
Guide Codex on code structure and best practices

Codex is available via the
