# 19. Gemini 2.5 Pro Upgrade

🚀
 SOP: How to Use Google Gemini 2.5 Pro to Code AI Tools in Minutes
Step 1: Get Free Access to Google Gemini 2.5 Pro
Go to 
Google AI studio
Select 
Gemini 2.5 Pro Preview
 from the top-right menu.
You don’t need to enter credit card details (it’s free, with usage limits).
Bonus: You can also access Gemini via 
Gemini Advanced
 or 
Canvas
 for a better visual experience.
Step 2: Set Up for Coding (Multiple Ways to Build)
Choose your tool:
Option A: AI Studio (Recommended for Simplicity)
Start a new chat.
Select 
Gemini 2.5 Pro
.
Type your prompt (e.g., “Build a CRM dashboard in HTML”).
Hit Run.
Option B: Visual Studio Code
Create an API key in AI Studio.
Use the 0325 model for the latest Gemini Pro version.
Plug the key into Visual Studio Code via 
Klein
 extension.
Start coding and testing your outputs.
Option C: Bolt DIY
Set up locally using the CLI.
Grab an API key from 
OpenRouter
.
Select Gemini 2.5 Pro Preview.
Start coding (e.g., “Build an SEO calculator”).
