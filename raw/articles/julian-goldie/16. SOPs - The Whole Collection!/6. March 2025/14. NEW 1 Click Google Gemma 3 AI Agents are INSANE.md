 Overview
This SOP walks you through how to 
set up AI agents using Gemma 3 and 
n8n
, automate workflows, connect to Google APIs, and integrate OpenRouter for seamless automation.
🚀
 Step-by-Step Guide to Setting Up AI Agents in 
n8n
1️
⃣
 Install and Set Up 
n8n
Go to 
n8n.io
 and create an account.
Install 
n8n
 
locally
 or use the 
cloud version
.
Create a 
new workflow
 inside 
n8n
.
Add a 
Webhook Trigger
 (if using a chatbot or API request).
2️
⃣
 Connect AI Model (Gemma 3)
Option 1: Use Google's API (If Available)
Get your API key
 at AI Studio Google.
Copy your API key.
Inside 
n8n
, add a 
HTTP Request Node
 → Set method to 
POST
.
Enter the Google API endpoint and 
paste your API key
.
Select 
Gemma 3 27B
 as your AI model.
Option 2: Use OpenRouter (Recommended if Google API Fails)
Sign up at OpenRouter
.
Go to 
Settings → API Keys
 and create a new key.
Inside 
n8n
, add a 
HTTP Request Node
 → Set method to 
POST
.
Enter the 
OpenRouter API endpoint
 and paste your API key.
Select 
Gemma 3
 from the model list.
3️
⃣
 Automate AI Responses in 
n8n
Add a 
Function Node
 to process user input.
Connect it to the 
HTTP Request Node
 to send the input to the AI model.
Use a 
Set Node
 to format the AI’s response.
Connect to 
Telegram, Email, or another platform
 to send back AI-generated replies.
4️
⃣
 Enable Memory (Optional)
Add a 
Storage Node
 in 
n8n
 to store chat history.
Set it to 
save the last 10 interactions
 for better context retention.
5️
⃣
 Testing & Deployment
Run a test
 → Enter a sample query and check the AI’s response.
Debug if needed
 → Adjust API settings or model selection.
Deploy
 the AI agent and set it to 
Active Mode
.
🔥
 Bonus: Automate Blog Writing with SEO Optimization
Set up a 
Webhook Trigger
 for blog input.
Add a

 to structure the query.
Connect to the

 via OpenRouter.
Format the AI response into an

.
Auto-publish to 
WordPress, Medium, or Google Docs
.

 Errors in

 Workflow?

Check API key, node connections, and execution logs.
