# 3. Claude 3.7 Sonnet FREE AI Agents!

SOP: How to Build Free AI Agents Using Claude 3.7 Sonnet in Vector Shift
Overview
This guide will walk you through building a 
free AI agent
 using 
Claude 3.7 Sonnet
 inside 
Vector Shift
. With this, you can create AI-powered chatbots, content generators, and automation tools—without spending a dime!
Step 1: Access Vector Shift
Go to
 
VectorShift
Sign up or log in
 if you don’t have an account.
Step 2: Set Up Your AI Agent
Delete Existing Nodes (if necessary)
If you have existing workflows, 
delete them
 to start fresh.
Add a New LLM Module
Click
 “Add New Module.”
Select
 "AI" → 
Choose Anthropic
 as the LLM provider.
Set the model
 to 
Claude 3.7 Sonnet
.
Enter system instructions
 for the AI.
Step 3: Connect the Modules
Create an Input Field
This will take user input from the chatbot.
Connect Input to Claude 3.7 Sonnet
Use 
curly brackets 
{} to tag the chat memory and input fields.
Add a Knowledge Base (Optional but Recommended)
Go to 
Knowledge Base
 in Vector Shift.
Click 
"Add Document"
 to upload files or add URLs.
This helps the AI learn from 
your specific content
.
Enable Chat Memory
This ensures the AI remembers past conversations.
Select "Chat Memory"
 and link it to the LLM.
Set Up the Output Node
Connect 
Claude 3.7 Sonnet's
 response to an 
Output Node
.
This determines how results are displayed.
Step 4: Test and Deploy Your AI Agent
Run a Test
Go to “Run”
 → Select 
Chatbot
.
Enter a test prompt
 (e.g., keyword = SEO training in Japan).
Wait for the AI response
 – it should return 
formatted, ready-to-use content
.
Deploy the AI Agent
Click "Deploy" → "Export"
.
Choose how to use it
:
As a chatbot
 (bookmark it for easy access).
Embed it on your website
 (copy and paste the code into WordPress).
Automate tasks
 by integrating with 
Google Sheets, WordPress, Gmail, 
etc.
.
Bonus: Automate Content Publishing
If you want to 
publish content directly to WordPress
:
Go to Integrations
 → Select 
WordPress
.
Connect your WordPress account
.
Enable automatic publishing
 from the AI agent.
Final Thoughts
🚀
 
That’s it!
 You now have a fully functional, 
free AI agent
 that can generate content, chat, and automate workflows—all powered by 
Claude 3.7 Sonnet
 in 
Vector Shift
.
