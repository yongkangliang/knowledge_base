Github here
Free API method? Setup an API key from Hyperbolic or Groq = Free!
Instructions:
Step 1:
conda create -n open_manus python=3.12
conda activate open_manus
Step 2:
git clone 
https://github.com/mannaandpoem/OpenManus.git
cd OpenManus
Step 3:
pip install -r requirements.txt
Step 4:
cp config/config.example.toml config/config.toml
Step 5:
nano config/config.toml
Step 6:
Setup the global LLM configuration below > Insert your API key
Step 7:
Control + X > Y > Enter
Step 8:
python 
main.py
Step 9:
Test it out
Step 10: 
Any issues? Screenshot the issue + paste into terminal, with the GitHub instructions.
