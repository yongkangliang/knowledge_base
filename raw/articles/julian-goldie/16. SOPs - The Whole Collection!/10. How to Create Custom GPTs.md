️ Step-by-Step Instructions
Step 1: Access the GPT Builder
Open ChatGPT
Go to the left-hand menu → Click 
Explore GPTs
Click 
Create a GPT
Choose:
🗣
️ 
Conversation Setup
 (guided chat with GPT Builder)
⚙
️ 
Configure manually
 (more control)
Step 2: Set Up Your Tool
In the 
configuration tab
:
Name
 your GPT
Example: YouTube Title Generator, Weekly Workout Bot
Description
Write what your tool does
Example: “Creates catchy YouTube titles using your video topic”
Instructions for the GPT
Think like you're giving it a job description.
Example:
pgsql
CopyEdit
When the user enters a topic, generate 10 attention-grabbing YouTube titles. Use clickbait tactics while staying truthful. Make titles under 70 characters. Format as a bullet-point list.
Step 3: Choose Built-In Tools
✅
 Enable the tools your GPT needs:
Web Browsing
: For up-to-date research
Code Interpreter
: For math, charts, logic
DALL·E
: For AI image generation
APIs & File Uploads
: For custom logic and document handling (advanced)
Step 4: Add Prompts or Templates
Insert templates that guide the AI’s behavior.
Example (for a fitness planner):
pgsql
CopyEdit
Ask the user about their fitness goal (e.g. lose fat, gain muscle). Then ask about experience level (beginner, intermediate, advanced). Then create a 4-week workout plan with exercises, reps, sets, and rest periods.
You can paste this into the instructions section to give the GPT its core function.
Step 5: Add Conversation Starters
These help people get going. Examples:
“What kind of video are you making?”
“What’s your fitness goal?”
Step 6: Create a Custom Icon
Upload your own image or use 
DALL·E
 to generate one instantly.
Step 7: Test It
Try a few test prompts:
For a YouTube bot: 
"My video is about productivity hacks"
For a resume bot: 
"I’m applying for a marketing role"
Check if the output:
Follows your instructions
Looks good
Needs any tweaking
Step 8: Improve with Feedback
Tweak your instructions if:
Results are too vague → Make prompts clearer
GPT goes off-topic → Add guardrails
Needs more formatting → Add markdown rules or character limits
Step 9: Add Bonus Functions (Optional)
You can train it to:
Generate content
Format output in HTML or Markdown
Use formulas
Insert external or internal links
Create PDFs or images
