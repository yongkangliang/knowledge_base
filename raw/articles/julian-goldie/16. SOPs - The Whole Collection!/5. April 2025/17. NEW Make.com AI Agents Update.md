 Goal
Create your own AI agent on 
Make.com
 that can perform tasks automatically (like sending emails, retrieving Google Docs, or chatting in Telegram) using simple workflows.
🛠
️ Step 1: Get Set Up on 
Make.com
Create an account
 on 
Make.com
Upgrade to the $10/month plan
 (you need this to access AI Agents - it’s currently in beta).
Go to 
Organization → Subscription
 and make sure you’re on the correct plan.
🧠
 Step 2: Create Your First AI Agent
Click 
“Create Agent”
Choose an AI model (e.g., Gemini, Claude, ChatGPT).
Name your agent
 (e.g., "SEO Assistant for Julian Goldie").
Add a 
system prompt
 like:
“You are a helpful assistant for Julian Goldie.”
Hit 
Save
.
🔗
 Step 3: Connect Tools & Workflows
What you can connect:
Gmail
Google Docs
WordPress
Telegram
How to connect tools:
Create a 
new Scenario
 (e.g., “Send Email”).
Add a module (e.g., Gmail → “Send an email”).
Set inputs like:
Email address
Subject
Content
⚠
️ Make sure your scenario is:
Active
Set to 
“on demand”
 (not scheduled or watching a sheet)
Link this scenario to your AI agent via 
System Tools
 → Add Scenario.
📄
 Step 4: Build and Connect Scenarios (Examples)
Example 1: Sending Emails
Create scenario → Gmail → “Send email”
Add required inputs (email, subject, content)
Link this scenario to your AI agent
Example 2: Google Docs Automation
Create scenario → Google Docs → “Get content”
Add output as text
Link the output to your agent’s actions
💬
 Step 5: Integrate with Telegram
Create a 
Telegram bot
 via BotFather on Telegram
Use /newbot, name it, and get the token.
In 
Make.com
:
Add 
Telegram → Watch Updates
Add your Telegram bot token
Create a new scenario:
Telegram Watch Update → Make AI Agent → Telegram Reply
Use the 
chat ID
 and 
message text
 from Telegram as inputs
Add your AI agent scenario as the response
🚀
 Step 6: Run It!
Use Telegram to send messages
Your AI agent processes and replies in real time
It can now access Gmail, Google Docs, and anything else you connected!
