Standard Operating Procedure: Using GPT Image One API in N8N Workflows
Overview
This SOP guides you through setting up an automated workflow in N8N that uses OpenAI's new GPT Image One API to generate high-quality images. The workflow allows you to input prompts via chat and automatically generate, convert, and download images.
Prerequisites
An N8N account
OpenAI API key (from platform.openai.com)
Step 1: Create a New N8N Workflow
Log into your N8N account
Create a new workflow
Name your workflow (e.g., "GPT Image Generator")
Step 2: Set Up the Chat Trigger
Click the "+" button to add a new module
Select "Chat Message" or "Trigger on Click" as your initial trigger
Configure the module to receive your text input
Step 3: Configure the HTTP Request
Add a new HTTP Request module by clicking "+" and selecting "HTTP Request"
Connect it to your trigger module
Configure the HTTP Request with these settings:
Method: POST
URL: https://api.openai.com/v1/images/generations
Headers: Add authorization header with Bearer YOUR_API_KEY (replace with your actual API key)
Toggle "Send Body" ON
Body Format: JSON
Body content:
json
{
  "model": "gpt-image-1",
  "prompt": "{{$node["Chat Message"].json["message"]}}",
  "size": "1024x1024",
  "quality": "standard"
}
Note: You can customize the "size" parameter for different dimensions (e.g., for YouTube thumbnails)
Step 4: Convert JSON to Image File
Add a "Convert to File" module
Connect it to the HTTP Request module
Configure with these settings:
Base Input Field: Select "b64_json" from the dropdown
Operation: "Move base64 string to file"
Step 5: View or Download the Image
Once the workflow runs, click "View" in the Convert to File module to see the generated image
Click "Download" to save the image to your computer
Step 6 (Optional): Add AI Agent for Prompt Enhancement
Insert an AI agent module between your trigger and HTTP Request
Configure the system message: "You are a creative thumbnail designer for YouTube videos. Take the idea from the team and turn it into an amazing prompt for image generation."
Set the input message to use the content from your chat trigger
Connect the output to your HTTP Request module
Update the HTTP Request to use the AI agent's output as the prompt
Step 7: Test Your Workflow
Activate your workflow
Type your image idea in the chat (e.g., "SEO link building thumbnail")
Wait approximately 30-45 seconds for the image to generate
View and download your image
Tips for Better Results
Be specific in your prompts
Include style information (e.g., "photorealistic," "cartoon," etc.)
Specify the composition you want (e.g., "person looking shocked at chart")
Use the AI agent to enhance basic ideas into detailed prompts
Optional: Make Your Workflow Public
Toggle the workflow to "Active"
Click on "Share" and make it publicly available
Share the chat URL with team members or clients
