Lutra AI: Standard Operating Procedure
Introduction
Lutra AI is a one-click AI agent that allows users to automate various tasks by connecting multiple applications without coding. This SOP outlines how to set up and use Lutra AI for common business workflows.
Getting Started
Setup Process
Go to 
lutra.ai
 and create an account
Note that the free plan includes 15 messages per day
Navigate to the chat interface to begin using the agent
Connecting Tools
Go to the "Tools" section in the Lutra AI interface
Connect desired integrations through one of three methods:
Native integrations (Google services, PayPal, etc.)
Third-party MCPs (Model-Controlled Processes)
Custom MCP server connections
Authorize access when prompted to complete each connection
Common Workflows
Creating and Sending PayPal Invoices
Connect PayPal in the Tools section
Click "Use this server" for PayPal
Log in to your PayPal account when prompted
Authorize the connection
In the chat interface, provide the following information:
Company details
Invoice amount (e.g., "$500")
Service description (e.g., "SEO link building")
Client email address
Type a command like: "Create a $500 PayPal invoice link for [service]"
Lutra will generate a PayPal invoice link within seconds
To send the invoice via email, type: "Send this link via email to [
client@email.com
] using the Google MCP"
Setting Up Automated Follow-ups
Ensure Google Calendar is connected in the Tools section
After creating and sending an invoice, type: "Create a calendar event to chase up [client name] one week later"
Lutra will automatically create a calendar reminder with the invoice details
Creating Content from Web Research
Enable internet search in the Tools section
Connect Twitter if you want to post content directly
In the chat interface, type a command like: "Search the internet for the latest AI updates. Do some research on the last 7 days of AI news. Break that down into a quick bullet-pointed list."
Optionally add style instructions: "Write as [specific person/style]"
To post directly to Twitter, add: "Draft a tweet for me to send out based on this"
Review the draft and type "Tweet this out" to publish
Saving Workflows as Playbooks
After successfully completing a workflow, click on "Create Playbook"
Provide a name for the playbook
The workflow will be saved and accessible in the "Playbooks" section
To reuse a playbook, go to the Playbooks section and click "View" on the desired workflow
You can also share playbooks with others by copying the share link
Tips for Optimal Use
Be specific in your commands to get the best results
Connect all relevant tools before starting a complex workflow
Review automated content before sending/posting
Use the free plan strategically to maximize the 15 messages per day
Save frequently used workflows as playbooks to reduce message usage
Troubleshooting
If a connection fails, try disconnecting and reconnecting the service
Check that you've authorized all necessary permissions for each connected service
For tasks involving multiple applications, ensure all required services are connected
If Lutra misunderstands a command, try rephrasing with more specific details
Security Best Practices
Review the permissions requested by each integration
Only connect services that you actually need
Regularly audit connected applications
Log out when using Lutra on shared devices
