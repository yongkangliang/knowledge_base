# 8. Gemini 2.5 Pro

🧠
 SOP: How to Build a Deep Research AI Agent (Paid & Free Methods)
🎯
 Goal:
To build an AI agent that performs deep research using Google Gemini 2.5 Pro (paid) or 
VectorShift
 (free).
🧪
 Method 1: Using Gemini 2.5 Pro (Paid)
✅
 Step-by-step:
Log into Gemini (Advanced version required)
Go to 
gemini.google.com
 with a Pro subscription.
Switch to Deep Research Mode
Use the dropdown to select “Deep Research”.
Ideal for in-depth tasks like comparing IDEs, market analysis, or product launches.
Enter your prompt
Example: 
“Research the latest IDE with All Man Code Plus and how it differs from others.”
Edit the Research Plan (Optional)
You can tweak what Gemini will research before it starts.
If you're happy, click 
“Good to Go”
 to launch.
Wait 5–30 minutes for results
Gemini will research up to 140+ sites.
It’ll generate an executive summary, detailed analysis, insights, and sources.
Access results
You can see the sources, snippets, and insights broken down by topic.
🆓
 Method 2: Using 
VectorShift
 (Free)
✅
 Step-by-step:
Go to 
VectorShift
Sign up/log in and delete any old pipelines if needed.
Create a New Pipeline
Click 
“Create Pipeline”
.
Add a 
Chat Input
 block.
Add a Large Language Model (LLM)
Choose 
Gemini 2.5 Pro Experimental
 from the dropdown.
Skip the personal API key (or optionally add one via AI Studio for better limits).
Set the Prompt
Use:
css
CopyEdit
You are a deep research assistant. Create a beautifully formatted research report based on the Google search results from {{
GoogleSearch.urls
}} and {{
GoogleSearch.snippets
}}.
Add a Data Loader for Web Search
Select 
Google Search
 or another engine.
Link the input to the search query.
Deploy Your Chatbot
Test it: e.g., “Create a deep research report on Gemini 2.5.”
Review the response and refine if needed.
Export & Deploy Your Bot
Click 
“Export Chatbot”
.
Name it, customize branding, and embed it or deploy on Slack.
🧩
 Extra Tips:
Use Gemini for ultra-deep, comprehensive reports.
Use 
VectorShift
 for quicker, free, and customizable agents.
You can embed the chatbot on your site or deploy it in Slack channels.
