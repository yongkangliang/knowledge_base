Standard Operating Procedure: Trae AI Coding Assistant
1. Introduction
Trae AI is a free AI coding assistant that provides access to premium AI models including GPT-4.1, Claude 3.7, and Gemini 2.5 Pro without any usage limits or costs. This SOP outlines how to install, configure, and leverage Trae AI for efficient coding and project development.
2. Getting Started
2.1 Installation
Visit 
trae.ai
Download the application
Install and launch Trae AI
2.2 Initial Setup
Open Trae AI
Click "Start Coding" to begin using the platform
Familiarize yourself with the interface elements:
AI chat interface
File system viewer
Code editor
Terminal
Preview window
3. Key Features
3.1 Premium AI Models (Free Access)
Trae AI provides free access to premium AI models including:
Claude 3.5 Sonnet
Claude 3.7 Sonnet
Gemini 2.5 Pro
GPT-4.1
GPT-4
Additional models via Open Router integration
3.2 Custom AI Agents
Create specialized AI agents for different coding tasks:
Click on "Add Agent"
Configure agent settings:
Name your agent
Select allowed tools and MCPs
Create custom prompts and rules
Choose preferred AI model
3.3 Web Search Integration
Search the web directly while coding:
Use the built-in web search feature in the builder
Add specific URLs as context for your coding tasks
3.4 MCP (Machine Capabilities Provider) Integration
Enhance AI capabilities with various MCP services:
Navigate to "Builder with MCP"
Click "Add" in the MCP servers section
Available MCPs include:
Slack integration
Memory features
Brave Search (web connectivity)
Google Drive
Firebase
Context 7 (updated documentation)
4. Adding MCP Servers
4.1 Adding Context 7 MCP
Go to "Builder with MCP"
Click "Add" in the MCP servers section
Click "Configure Manually"
Visit the GitHub link provided in the add MCP server section
Copy the configuration JSON
Paste the configuration in Trae AI
Click "Confirm"
4.2 Adding Custom API Models via Open Router
Go to the model selection section
Click "Add API"
Select "Open Router"
Get an API key from 
Open Router
Copy and paste the API key into Trae AI
Select desired models from Open Router
For custom models, copy the model ID from Open Router and paste it into Trae AI
5. Building Projects
5.1 Starting a New Project
Click "Open Folder" to select project location
Trust folder when prompted
Return to AI chat by clicking "Trae" at the top
Select desired AI model
Describe your project requirements to the AI
5.2 Working with Project Files
Use the file explorer to navigate project files
Enable "Auto Run Commands" to streamline development
Use the preview function to test applications
5.3 Using AI for Code Generation
Provide clear instructions about what you want to build
Use specific prompts for better results
Check the generated code
Accept or modify changes as needed
Test functionality using the preview feature
6. Project Examples
6.1 Building a Thumbnail Generator
Describe the thumbnail generator requirements
Specify the API to use (e.g., "Use GPT Image One API")
Let Trae AI generate the HTML, CSS, and JavaScript
Test the functionality in the preview window
Make adjustments as needed
6.2 Creating a 3D Car Simulator
Select an appropriate model (e.g., Gemini 2.5 Pro)
Provide detailed requirements (e.g., "Create a simple 3D car simulator with Three.js")
Review and accept the generated code
Test in the preview window
7. Important Considerations
7.1 Privacy
Be aware that code or projects built within Trae AI might be used for data gathering
Exercise caution when building commercial or sensitive applications
7.2 Troubleshooting
If you encounter model limits, switch between different AI models

Check the changelog for updates and new features
