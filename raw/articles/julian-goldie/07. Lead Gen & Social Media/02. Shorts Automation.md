SOP for editing Shorts
Prompt for creating shorts:
Create 3 versions of a short
It shouoldn’t feel like an ad for the tool - I’m just trying to blow people’s minds
Stick strictly to the topic Include a hook, secondary hook, keep it all short + punchy + keep people guessing e.g. it's not x and it's not y
Split into 3 paragraphs so I can easily record bit by bit
Make it VERY actionable + include a hook + secondary hook.
Explain like here's how to do it in 3 simple steps...
Polarize people so it triggers them too + make it like a crazy rant that's funny.
Secondary hook should be really creating curiosity so people keep watching…Add a story into it too.
Lower the language to 3rd grade level or simpler
This should feel new, big, easy, safe: e.g. urgent, breaking news, just dropped etc.
HOOK EXAMPLE:
- Looking for X to help you do Y?
- 3 ways to…
- What if I told you…
- If you struggle with X, here’s 3 Y you can use…
- Are you (FEAR) to (OUTCOME)
SECONDARY HOOKS EXAMPLE:
- Don’t make this mistake…
- It’s crazy! And here’s why…
- Here’s 2 examples
- Here’s 2 reasons why…
FORMAT: Create the script using this 3 step process based on my title idea:
PART 1: Hook
We all know what a hook is these days. Should grab attention as quickly as possible. Try to keep short and delivered in a few seconds. (3-5 seconds)
- e.g. If a prospect says “that’s too expensive”, say this…
PART 2: Secondary Hook (Peaking Interest)
Should add context or further reason as to why they should continue to consume the content. 
- e.g. and 99% sales people do this SO WRONG.
PART 3: Deliver on Hook
Pretty straight forward, deliver what you mentioned in the hook. Try to cut all the fluff and get to the point as quickly as possible.
Make sure you use the hooks I’ve given you. Should be take 30 seconds to read out.
Include lots of fact about it too using the info below BUT keep it entertaining too.
