SOP: Automating Team Replies for Slack & Discord Using AI
Objective
Reduce emotional drain from constant problem-solving requests in Slack & Discord by automating responses that encourage solution-focused thinking.
Tools Needed
Claude AI (recommended for human-like responses & multimodal capabilities)
Slack/Discord for team communication
Screenshots for inputting messages into AI
Step-by-Step Process
1. Set Up a Claude Project
✅
 
Why Claude?
Best for humanized responses
Allows bookmarking for easy access
Accepts screenshots (multimodal capability)
✅
 
How to Set It Up?
Go to Claude
Start a new project
Save a prompt template for team replies
2. Create an AI Prompt for Team Replies
✅
 
Use this template:
"I need you to reply to my team because they often send me problems. I need you to get them focused on solutions. Here’s information about me, my company, and our core values: [Insert details].
Use ‘The Shit Sandwich Approach’ (positive start → critique → positive reinforcement) to keep motivation high."
✅
 
Core Message Goals:
Empower the team to find solutions instead of just presenting problems
Keep responses positive and motivating
Reduce emotional energy spent on unnecessary problem-solving
3. Automate Responses Using Claude
✅
 
When to Use It?
For challenging messages that require thoughtful responses
When you feel drained from constant problem-solving
✅
 
How to Use It?
Take a 
screenshot
 of a team member’s message from Slack/Discord
Paste the screenshot into Claude
 (no extra typing needed if the project is set up)
AI generates 
three response options
Choose the best response and 
copy-paste
 back into Slack/Discord
4. Structure of an Effective Response
✅
 
Example Response Format:
Start Positive:
 
"Love what you’re doing here!"
Redirect to Solutions:
 
"What solutions have you already brainstormed?"
Relate to Core Values:
 
"Remember, ‘Speed is King’ and ‘Solutions, Not Problems.’”
Empower Action:
 
"What specific actions will you take today?"
✅
 
Why This Works?
Prevents team members from dumping problems on you
Encourages independent thinking
Keeps morale high
Eliminates passive-aggressive responses
5. Optimize & Maintain
✅
 
Review Responses Weekly
Check if responses align with team culture
Edit prompts if needed for better engagement
✅
 
Train Your Team
Set a standard: 
"Solve it yourself first, then come to me."
Encourage self-reliance through AI-guided coaching
Final Thoughts
This system 
automates leadership
, saves emotional energy, and empowers your team to be solution-focused. With Claude handling the initial reply, you can keep communication positive and efficient!
