Overview
This guide walks you through setting up and using 
Bolt DIY
, a free alternative to 
Bolt New
, combined with 
Claude 3.7 Sonet
 for coding projects. You’ll learn how to install it, use AI APIs, and even deploy your projects online—all for free!
Step 1: Install Bolt DIY on GitHub
Go to GitHub
 and search for 
Bolt DIY
.
Follow the installation instructions
 listed in the repository.
Open your 
terminal
 (Command Prompt for Windows, Terminal for Mac/Linux).
Copy and paste
 the installation commands one by one, pressing 
Enter
 after each.
✅
 
Tip:
 If unsure, check the 
AI Profit Boardroom
 for additional setup details.
Step 2: Run Bolt DIY Locally
After installation, run the following command in the terminal:
npm run dev
This will generate a 
local address
 where Bolt DIY will run.
Copy the local address
 and open it in your browser.
🎉
 
Now you’re set up and ready to build apps for free!
Step 3: Connect to an AI API (Claude 3.7 Sonet)
Inside Bolt DIY
, go to the 
API selection dropdown
.
Select 
Anthropic (Claude 3.7 Sonet)
 under OpenRouter.
Click on 
"Get API Key"
 to generate an API key.
Sign up on 
OpenRouter.ai
 (if you haven't already).
Paste your API key
 into Bolt DIY.
💡
 
Claude 3.7 Sonet Modes:
Thinking Mode
 – More advanced responses (better quality).
Normal Mode
 – Faster responses (less reasoning).
Step 4: Start Coding with AI
Open 
Prompt Forge
 inside Bolt DIY to generate optimized prompts.
Enter your project idea (e.g., "Create a job board website").
Paste the generated prompt into Bolt DIY.
Click 
Enter
, and let the AI start coding for you!
✅
 
Pro Tip:
 Use the 
AI option
 in Bolt DIY to refine your prompts for even better results.

Step 7: Deploy Your Project (Free Hosting with Netlify)
Once coding is complete, go to the 
Code
 section in Bolt DIY.
Click 
Download Code
 (this will be a ZIP file).
Go to 
Netlify.com
 and select 
"New Site"
 → 
"Import Existing Project"
.
Upload your 
unzipped project folder
 to deploy your site.
Once deployed, you’ll get a 
free test domain
!
🎯
 
Want a Custom Domain?
Click 
"Add Domain"
 and purchase one directly inside Netlify.
Step 8: Track API Usage & Costs
In Bolt DIY, go to 
Activity
 to check API usage.
See how much you’ve spent (most projects cost 
just a few cents
).
Use 
free APIs
 if you want to avoid any costs.
