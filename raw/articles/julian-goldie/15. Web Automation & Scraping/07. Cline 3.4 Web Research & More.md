SOP: Setting Up and Using Cline 3.4 for AI Automation
Overview
Cline 3.4 is a powerful and 
free
 AI automation tool that integrates with various apps, conducts live web searches, builds AI agents, and even creates full websites based on research. This guide will walk you through installing, setting up, and using Cline 3.4 effectively.
Step 1: Install Visual Studio Code
✅
 Go to 
Visual Studio Code
✅
 Download and install it on your computer
✅
 Open VS Code and navigate to 
Extensions
✅
 Search for 
Cline
 and install it (1-click install, completely free)
Step 2: Set Up Cline 3.4
✅
 Open Cline inside VS Code
✅
 Go to 
Settings
✅
 Select 
API Provider
 → Choose 
OpenRouter
✅
 Get an 
API key
 from 
OpenRouter
✅
 Enter the key in 
Cline Settings
 and select "Free" API models if you want to keep costs down
Step 3: Use the MCP Marketplace
The 
MCP Marketplace
 allows you to connect Cline with various services (Google Calendar, Shopify, Discord, etc.) instantly.
✅
 Open the 
MCP Servers Marketplace
 inside Cline
✅
 Search for the app you want (e.g., Google Calendar)
✅
 Click 
Install
 – This sets up the server in one click
✅
 Click 
Run
 to activate the MCP server
Now, Cline can interact with that app autonomously!
Step 4: Conduct Live Web Research with Perplexity
Cline 3.4 can pull 
live data
 from the internet using Perplexity AI.
✅
 Go to 
MCP Servers
✅
 Search for 
Perplexity Research
✅
 Click 
Install
 → Click 
Run
✅
 Get an API key from 
Perplexity AI
 (if required)
✅
 Enter the API key in Cline and approve it
🔎
 Example Command:
"Do a deep research report on DeepSeek’s impact on AI, then create a beautifully designed landing page summarizing the research."
Cline will:
Research using Perplexity AI
Generate a full research report
Auto-build and design a 
landing page
 with key insights
Step 5: Build & Deploy AI-Powered Websites
Once the research is complete, Cline can generate 
code for a landing page
 automatically.
✅
 After generating content, go to the 
index.html file
✅
 To host the site, go to 
Netlify
✅
 Click 
Add a new site
 → 
Import existing project
✅
 Drag & drop the folder Cline generated
✅
 Deploy the website with one click
🔹
 
Optional:
 Buy a custom domain in Netlify's 
Domain Management
 section
Step 6: Automate SEO & Content Planning with Flowcharts
Cline 3.4 can 
visually map out projects
 with flowcharts.
✅
 Click 
Plan
 inside Cline
✅
 Type your request (e.g., "Plan my SEO content writing tool in a flowchart")
✅
 Cline will auto-generate a 
detailed workflow
You can then 
automate the entire project build
 by clicking "Build"!
Step 7: Advanced Settings & Personalization
Inside 
Settings > Advanced
, you can:
✅
 Set 
AI control level
 (Full Service, Only, or Off)
✅
 Adjust 
Reasoning Effort
 (Low, Medium, High)
✅
 Customize 
Branding Instructions
 (Logos, CTAs, Colors)
Now, every project Cline builds will 
follow your brand guidelines
 automatically!
Conclusion
Cline 3.4 is a 
game-changer
 for AI automation. You can:
✔
️ 
Integrate AI with real apps
 (Google Calendar, Discord, Shopify)
✔
️ 
Conduct live web research
 with Perplexity AI
✔
️ 
Auto-build and host websites
 in minutes
✔
️ 
Use free AI models
 with OpenRouter
✔
️ 
Generate flowcharts
 and auto-build AI projects
