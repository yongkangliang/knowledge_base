# 08. Google Ads to Airtable

Google Ads to 
Airtable
📋
 How to Use This Workflow
Overview
This workflow automates the process of fetching campaign data from Google Ads, processes the data, and then 
upserts
 it into 
Airtable
. It’s designed to be triggered manually.
🛠
️ Workflow Steps
Manual Trigger
Start the workflow by clicking “Execute Workflow” in the n8n editor.
Google Ads Node
Fetches all campaign data from your Google Ads account.
Make sure to provide your Google Ads credentials and specify the required Manager and Client Customer IDs.
Set Node
Processes the data from Google Ads.
Extracts and renames fields:
Metric is set from the total field.
Country is set from the 
ga:country
 field.
Airtable
 Node
Upserts
 the processed data into your 
Airtable
 base and table.
You’ll need to provide your 
Airtable
 API credentials, Base, and Table information.
⚠
️ Before You Start
Ensure you have valid credentials set up for both Google Ads and 
Airtable
.
Fill in all required parameters (like Customer IDs for Google Ads, and Base/Table for 
Airtable
).
Map the fields in the 
Airtable
 node to match your table’s schema.
🚀
 Running the Workflow
Click “Execute Workflow” in the n8n editor.
Monitor each node for successful execution.
Check your 
Airtable
 base for the new or updated records.
