Overview
This guide will walk you through setting up a 
one-click AI agent
 using 
GPT-4.5
 and 
n8n
, an automation tool. This AI agent can generate responses, automate email tasks, and more.
🔹
 
Best use cases for GPT-4.5:
✅
 Advice & short responses
✅
 Human-like interactions
✅
 Email automation & newsletters
🔹
 
What GPT-4.5 is NOT great for:
❌
 Long-form content
❌
 Complex workflows
❌
 Coding & logic-heavy tasks
Step 1: Set Up 
n8n
 & Create a Workflow
Go to n8n
 and start a 
new workflow
.
Click 
Overview > Create Workflow
 inside 
n8n
.
Add a new step:
 Select 
Chat Trigger
 (this starts the AI agent when a chat message is received).
Why not use Zapier or 
Make.com
?
Setting up AI agents is 
faster
 and 
easier
 with 
n8n
.
Step 2: Connect the AI Agent to Chat Trigger
Add a new module
 → Select 
AI Agent
.
Source for prompt
 = Chat.
The AI agent will take the 
first response
 from the chat trigger.
Step 3: Connect OpenAI & Get Your API Key
Go to OpenAI’s API platform:
 https://platform.openai.com
.
Log in
 and go to 
Settings > API Keys
.
Create a new secret key
 (each project can have a different API key).
Use GPT-4.5 Preview
 (
⚠
️ This model is more expensive than others).
Step 4: Enable Memory for Conversations
Select Window Buffer Memory
 in the settings.
Why?
 This allows the AI to remember past interactions, making conversations feel more natural.
Step 5: Add Additional Tools (Optional)
Want AI to send emails?
 Add the 
Gmail tool
 in 
n8n
.
How to connect Gmail:
Click 
Add Credentials
 → 
Sign in with Google
.
Set email type to 
HTML email
.
The AI will automatically select: 
Recipient, Subject, and Message
 based on chat instructions.
Step 6: Define the AI Agent’s Role
Go to System Message
 → Define what the AI agent does.
Examples:
Newsletter Assistant:
 Writes short, actionable emails.
Personal Email Assistant:
 Sends emails based on chat instructions.
SEO Research Assistant:
 Gathers SEO insights on command.
Step 7: Automate Newsletters with the AI Agent
Set up the AI agent to generate newsletters.
Use the following 
prompt settings
:
Max words:
 200
Tone:
 No fluff, actionable tips
Audience:
 AI & SEO enthusiasts
Example topic:
 “New GPT-4.5 Release”
Test it:
 Open chat → Type a topic → Let AI generate the newsletter.
Step 8: Automate Sending Emails with AI
Change AI agent role: 
“You are a personal email assistant.”
Test email automation:
Open chat and type:
"Send an email to [
email@example.com
] about the new GPT-4.5 release and say how excited I am."
AI will generate and send the email via Gmail.
Step 9: Monitor API Costs
Go to OpenAI API Dashboard
 → 
Check Usage
GPT-4.5 costs more per request.
 Keep an eye on spending.
Step 10: Save & Share Your AI Agent
Click 
Activate
 to make the AI agent live.
Copy the public URL
 → Share it with your team or clients.
