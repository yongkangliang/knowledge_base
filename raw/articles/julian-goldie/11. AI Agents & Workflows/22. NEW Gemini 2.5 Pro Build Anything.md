 SOP: How to Build Anything Using Google Gemini 2.5 (For Free)
1. 
Get Access to Gemini 2.5
Visit: 
https://astudio.google.com
Log in with your Google account.
Click the model dropdown (top-right).
Select 
Gemini 2.5 Pro Experimental
.
It's 
100% free
 (no input/output costs).
2. 
Build a Game with One Prompt
Prompt:
“Make me a captivating endless runner game. Key instructions on screen. Use p5.js, no HTML. Pixelated dinosaur and interesting backgrounds.”
Copy the code Gemini gives you.
Test it using 
editor.p5js.org
.
3. 
Generate Blog Posts from Video Transcripts
Prompt:
“Turn this YouTube transcript into a blog post. Make it human, SEO-optimized, include links to my funnel.”
Paste transcript in Gemini.
Gemini creates 1,500-word articles with catchy headlines & funnel links.
Copy and paste into your CMS (e.g. WordPress).
4. 
Create SEO Tools like Cost Calculators
Prompt example:
“Create a sleek modern SEO cost calculator with UI in HTML/CSS/JS.”
Test output using 
LiveWeave.com
.
Paste HTML (top-left), CSS (bottom-left), JS (top-right).
5. 
Build AI Agents with N8N
Step-by-step:
Go to 
N8N.io
 (host it locally or use cloud).
Create new workflow:
Add “Chat Trigger” → Add “AI Agent” block.
Choose “Google Gemini” as chat model.
Paste in your Gemini 2.5 API key from 
astudio.google.com
.
Set system message (e.g. “You are an SEO assistant”).
Test the chatbot with simple messages.
6. 
Automate Emails with Your AI Agent
Add Gmail tool in N8N.
Let AI auto-fill To, Subject, and Message fields.
Prompt:
“Send an email to [
you@example.com
] inviting them to the Gemini 2.5 launch party this Sunday.”
Agent sends fully formatted HTML emails for you.
7. 
Auto-Publish Content to WordPress
Use the Gemini agent to generate content.
Add “Create Post” WordPress block in N8N.
Gemini writes & auto-publishes content in HTML format.
8. 
Compare Models (Optional)
Gemini 2.5 = better at coding, speed, and reasoning.
DeepSeek V3 = better at writing human-like content.
Claude = great for writing and design (has built-in canvas).
9. 
Bonus Tools
Visual Studio Code + R Code
: Use free Gemini API inside to code websites.
Make.com
: Automate Google Sheets > Gemini > WordPress.
OpenRouter.ai
: Use it if Gemini’s native API isn’t working.

HOW TO SET IT UP?
1: Open Terminal and clone the repository:
cd ~
git clone 
https://github.com/coleam00/bolt.new-any-llm.git
cd 
bolt.new
-any-llm
2: Install PNPM (Package Manager):
npm install -g pnpm
3: Install project dependencies:
pnpm install
4: Save and exit nano:
Press Control + X
Press Y to save
Press Enter
5: Start the development server:
pnpm run dev
