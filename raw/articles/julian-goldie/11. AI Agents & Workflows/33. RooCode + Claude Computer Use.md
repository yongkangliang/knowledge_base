Setting up Visual Studio Code:
🧰
 Step-by-Step Setup
1. Install Visual Studio Code (Free)
Go to: 
https://code.visualstudio.com
Download and install it.
2. Install the RooCode Extension
Open VS Code → Go to Extensions (left sidebar).
Search for Roocode → Click install.
3. Add Your Claude API Key
Get your key from: 
https://console.anthropic.com
In RooCode settings, select Anthropic API > Paste the API key and select Claude 3.7 Sonnet.
Setting up computer Use:
STEP 1
: Close all instances of Chrome
STEP 2: Run this on Mac via Terminal:
On a new debug profile with no logins:
/Applications/Google\ 
Chrome.app/Contents/MacOS/Google\
 Chrome --remote-debugging-port=9222
On a new debug profile with your existing logins:
/Applications/Google\ 
Chrome.app/Contents/MacOS/Google\
 Chrome --remote-debugging-port=9222 --user-data-dir="/tmp/chrome-debug-profile"
On Windows, do this:
"C:\Program Files\Google\Chrome\Application\chrome.exe" ^
--remote-debugging-port=9222 ^
--user-data-dir="C:\chrome-debug"
