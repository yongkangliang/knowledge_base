 SOP: How to Build Anything Using DeepSeek V3.1 (Apps, Games, Websites & AI Agents)
Step 1: Get Started with DeepSeek V3.1 Chat
Go to
 
deepseek.com
Click "Start Now"
 to access the chat
Prompt example:
kotlin
CopyEdit
Make me a captivating endless runner game. Key instructions on screen, P5.js, no HTML. Like pixelated dinosaurs with fun backgrounds.
Copy the code output
Paste into:
 
editor.p5js.org
Click "Play"
 — Boom! Game done. Test it, press "R" to restart.

Try advanced prompts like:

Step 3: Build AI Agents in 47 Seconds with n8n
Go to:
 
n8n.io
 (host locally or self-host)
Create a new workflow
Add:
Chat Trigger
AI Agent (DeepSeek via OpenRouter)
API Key
System Message: "You're a helpful assistant"
Test it:
 Ask “Are you working?”
Add Gmail module to 
automate emails
 (e.g., send one to yourself!)
Total time: ~47 seconds
