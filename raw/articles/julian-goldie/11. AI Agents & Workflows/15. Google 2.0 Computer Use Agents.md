How to setup on mac?
Based on the documentation provided, I'll walk you through setting up the browser-use web UI on a Mac. Here are the step-by-step instructions:
First, ensure you have the prerequisites:
Python 3.11 or higher
Git
Open Terminal and clone the repository:
bash
Copy
git clone https://github.com/browser-use/web-ui.git cd web-ui
Set up the Python environment using uv:
bash
Copy
uv venv --python 3.11 source .venv/bin/activate
Install the required dependencies:
bash
Copy
uv pip install -r requirements.txt playwright install
Create and configure the environment file:
bash
Copy
cp .env.example .env
Configure your Mac-specific browser settings in the .env file (if you want to use your own Chrome browser):
Copy
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" CHROME_USER_DATA="/Users/YourUsername/Library/Application Support/Google/Chrome"
(Replace "YourUsername" with your actual Mac username)
Start the application:
bash
Copy
python webui.py --ip 127.0.0.1 --port 7788
Access the web interface by opening your browser (preferably Firefox or Edge if you're using your own Chrome instance) and navigating to:
Copy
http://127.0.0.1:7788
Optional settings:
If you want to keep the browser open between AI tasks, add CHROME_PERSISTENT_SESSION=true to your .env file
You can customize the theme by adding the --theme flag when starting the application (e.g., python webui.py --ip 127.0.0.1 --port 7788 --theme Ocean)
You can enable dark mode by adding the --dark-mode flag
Make sure to also add any necessary API keys to your .env file if you plan to use specific LLM services (OpenAI, Anthropic, Google, etc.).
