Building and Deploying Websites with Manus AI
Overview
This SOP outlines the process for creating, customizing, and deploying websites using Manus AI. With Manus, you can build fully functional, responsive websites with minimal prompting and zero coding knowledge.
Step 1: Starting a New Session
Log into your Manus AI account
Click "New Session" to start a fresh conversation
Choose "Standard" effort mode (or "High Effort" for more complex sites)
Step 2: Creating Your Website
Basic Website Creation Prompt
Use this template for your initial prompt:
Copy
Create and deploy a modern, beautiful website for [your business/topic]. Include: - A clean, responsive design - Navigation menu with [list pages you want] - [Any specific sections, features, or content] - [Any embedding requirements (videos, forms, etc.)] Make sure the website is mobile-friendly and has clear calls to action.
Example Prompt
Copy
Research Julian Goldie and his AI Profit Boardroom, then create a really modernized, beautiful website promoting his AI Profit Boardroom. Link to sign up is [URL]. Don't include any pricing on the website, but do include plenty of information on what it is, why to buy, write the copy like Alex Famosi. Include plenty of social proof about me. Here's the embeddable VSL that we can insert: [embed code]
Step 3: Watching the Build Process
Manus will research your topic (if applicable)
It will plan the website structure
You'll see it create HTML, CSS, and JavaScript files
It will provide regular updates as it builds the site
Step 4: Reviewing and Refining
Once deployed, Manus will provide a link to view the website (typically on 
manus.space
)
Review the site thoroughly
To request changes, use clear, specific instructions like:
Copy
Please make the following changes: - Update the hero section to be more impactful - Add more testimonials in the social proof section - Make the call-to-action buttons larger and brighter
Step 5: Deploying to Your Own Domain
Method 1: Download Files and Use Netlify
Ask Manus for the website files:
Copy
Give me the files to host as a folder on Netlify
Manus will create a zip file for download
Download and extract the zip file
Go to 
Netlify.com
 and create an account if needed
Click "Add new site" → "Import an existing project" → "Try Netlify Drop"
Drag and drop your extracted folder
Once deployed, go to "Domain management" in Netlify
Click "Add domain" or "Buy a new domain" and follow the prompts
Method 2: Direct Integration (if available)
Ask Manus to deploy directly to Netlify:
Copy
Deploy this website to Netlify using these credentials: [your credentials]
Follow Manus's instructions to complete the authentication
Additional Tips
For E-commerce Websites
Specify details about products, pricing structure, and payment integration:
Copy
Create an e-commerce website for my handmade jewelry business with product categories, individual product pages, and integration capabilities for [payment platform].
For Directory Websites
Copy
Create a local SEO directory website listing businesses in [industry] across [locations]. Include individual location pages optimized for SEO with the format "Best [business type] in [location]".
For Personal/Portfolio Websites
Copy
Create a personal portfolio website for me as a [profession]. Research my background at [LinkedIn/social profiles] and include sections for About, Portfolio, Services, and Contact.
Troubleshooting
If the website doesn't load properly:
 Ask Manus to troubleshoot and fix any errors in the code
If content is inaccurate:
 Provide specific corrections for Manus to implement
If design needs improvement:
 Give specific design feedback with examples if possible
Example High-Quality Prompt for Complex Website
Copy
Create and deploy a comprehensive real estate website with the following: 1. Home page with featured listings, about us section, and testimonials 2. Property listings page with filtering options (price, location, bedrooms) 3. Individual property page template 4. Agent profiles section 5. Contact form 6. Resources page with mortgage calculator Design should be modern, mobile-responsive, and follow real estate industry best practices. Use a color scheme of blue and white with gold accents. Include clear CTAs for "View Properties" and "Contact Us" on all pages.
Building SaaS Tools with Manus AI
Overview
This SOP outlines the process for creating functional SaaS (Software as a Service) tools using Manus AI. You can build interactive dashboards, utility applications, and other web-based tools without writing code.
Prerequisites
Access to Manus AI
Clear vision of the SaaS tool's purpose and functionality
Basic understanding of what features your tool should include
Step 1: Planning Your SaaS Tool
Before prompting Manus, define:
The core purpose of your tool
Primary features and functionality
Target users
Basic UI/UX requirements
Any integration needs (if applicable)
Step 2: Creating Your SaaS Tool
Basic SaaS Tool Creation Prompt
Copy
Create and deploy the best and most useful [type of tool] for [specific use case/industry]. The tool should include: - [Feature 1] - [Feature 2] - [Feature 3] Design it with a modern, user-friendly interface suitable for [target audience].
Example Prompt
Copy
Create and deploy the best and most useful tool you can for my SEO agency, Goldie Agency. This is for lead generation. It should include a dashboard to track leads, a section to discover new leads, ability to import leads, and lead scoring functionality. Make it professionally designed with an intuitive interface.
Step 3: The Development Process
Manus will proceed through these phases:
Planning the tool architecture
Designing the interface
Developing front-end components
Creating back-end functionality
Testing and debugging
Deployment
During this process, Manus will provide progress updates and may ask clarifying questions to ensure the tool meets your needs.
Step 4: Testing and Refining
When Manus provides a link to the deployed tool (typically on 
manus.computer
), test all features thoroughly
Identify any bugs or desired improvements
Provide specific feedback, such as:
Copy
The dashboard looks great, but the lead import functionality isn't working properly. Also, can we add a filter function to the lead list?
Step 5: Deployment Considerations
Temporary Deployment
Manus initially deploys SaaS tools on temporary URLs (
manus.computer
)
You'll need to ask Manus to redeploy the tool each time you want to access it again
Permanent Deployment Options
Request the source code:
Copy
Please provide all the code files for this SaaS tool so I can deploy it permanently.
Deploy to a permanent hosting service:
Download the provided files
Choose a hosting platform (Netlify, Vercel, Heroku, etc.)
Follow the hosting platform's deployment instructions
For integrating payment systems:
Copy
Can you modify this tool to integrate with [payment provider, e.g., Stripe]? Here are my API keys: [provide API keys]
SaaS Tool Examples by Category
Analytics Dashboard
Copy
Create a comprehensive analytics dashboard for tracking website performance. Include sections for traffic overview, user behavior, conversion tracking, and content performance. Use interactive charts and graphs for data visualization.
CRM System
Copy
Build a lightweight CRM system for a small business. Include contact management, deal tracking, task assignment, and basic reporting. Design it to be intuitive for non-technical users.
Content Management Tool
Copy
Create a content planning and management tool for a marketing team. Include a content calendar, idea repository, assignment tracking, and integration capabilities with popular platforms like WordPress and social media.
Project Management Tool
Copy
Develop a project management tool with Kanban boards, task assignment, deadline tracking, and progress visualization. Make it collaborative with the ability for multiple users to interact.
Tips for Success
For More Complex Tools
Break your request into phases:
Copy
Let's build this tool in phases: 1. First, create the core user interface and basic functionality 2. Once that's working, add the data visualization components 3. Finally, implement the reporting and export features
For Performance
Copy
Please ensure this tool is optimized for performance with fast loading times and responsive design that works well on both desktop and mobile devices.
For Future Expandability
Copy
Design this tool with a modular architecture so new features can be easily added in the future. Document the code structure clearly.
Troubleshooting Common Issues
If features don't work as expected:
 Ask Manus to debug specific functions with detailed error descriptions
If deployment fails:
 Request Manus to troubleshoot the deployment process and provide alternative deployment options
If the UI needs improvement:
 Provide specific feedback about UI elements that need enhancement
If you need to modify the tool later:
 You can return to Manus with the source code and request specific modifications
Security Considerations
Avoid sharing sensitive API keys or credentials in your initial prompts
For tools that handle sensitive data, request that Manus implement proper security measures:
Copy
Please ensure this tool implements proper data encryption, secure authentication, and follows GDPR compliance guidelines.
Review the code for security vulnerabilities before deploying to production

Creating Comprehensive Travel and Project Plans with Manus AI
Overview
This SOP outlines how to use Manus AI to create detailed travel itineraries, project plans, and other comprehensive planning documents. Manus can research, organize, and provide actionable information for various planning needs.
Step 1: Starting a Planning Session
Log into your Manus AI account
Start a new session
Select "Standard" effort mode (or "High Effort" for more complex plans)
Step 2: Crafting Effective Planning Prompts
Travel Itinerary Prompt Template
Copy
Create a [duration] trip plan for [destination] in [month/season]. Include: - Daily activities and attractions - Accommodation recommendations for different budgets - Transportation options - Estimated costs - Local dining recommendations - Packing suggestions - [Any specific interests or requirements]
Example Travel Prompt
Copy
Create a 30-day trip for Lower Manhattan in June. Include daily activities, accommodation options for different budgets, transportation details, estimated costs, local dining recommendations, and a packing list. I'm particularly interested in cultural attractions, food experiences, and some off-the-beaten-path locations.
Project Planning Prompt Template
Copy
Create a comprehensive project plan for [project type]. Include: - Project phases and milestones - Timeline with deadlines - Resource requirements - Budget estimation - Risk assessment - [Any specific methodologies or requirements]
Step 3: Watching the Planning Process
As Manus works on your plan, it will:
Research the destination or project requirements
Browse relevant websites for up-to-date information
Organize information into structured sections
Create downloadable files with the complete plan
Provide regular progress updates
Step 4: Reviewing and Refining the Plan
Once complete, Manus will provide links to download the plan documents
Review the plan thoroughly and request any adjustments:
Copy
This looks good overall, but could you add more budget-friendly dining options and include information about public transportation passes?
Step 5: Using the Planning Documents
Manus typically provides plans in multiple formats:
Markdown (.md) files
Text documents
Sometimes CSV or spreadsheet files for budgets/schedules
You can:
Download these files for offline use
Request specific file formats if needed
Ask Manus to email the documents to you or others
Travel Planning Examples by Type
City Exploration
Copy
Create a 7-day itinerary for exploring Rome, Italy in September. Focus on historical sites, local cuisine, and cultural experiences. Include accommodation options in the €100-200/night range and options for getting around the city efficiently.
Road Trip
Copy
Plan a 14-day road trip along the US West Coast from Seattle to San Diego. Include recommended stops, attractions, driving times between locations, accommodation suggestions, and notable roadside attractions. Budget is moderate.
Family Vacation
Copy
Create a 10-day family-friendly vacation plan for Orlando, Florida in April. We have two children (ages.7 and 10). Include theme park recommendations, entertainment options suitable for kids, family-friendly restaurants, and accommodation with pools. Budget is $5,000 total excluding flights.
Project Planning Examples by Type
Business Launch
Copy
Create a comprehensive business launch plan for a specialty coffee shop. Include market analysis, startup costs, staffing requirements, marketing strategy, and timeline from initial planning to grand opening. Assume a budget of $150,000 and a target launch in 6 months.
Event Planning
Copy
Create a detailed plan for organizing a 3-day professional conference for 200 attendees. Include timeline, venue requirements, speaker management, marketing strategy, budget breakdown, and logistics planning. Event is scheduled for 8 months from now.
Home Renovation
Copy
Create a detailed home renovation plan for updating a 2,000 sq ft home built in the 1980s. Focus on kitchen and bathroom modernization, flooring replacement, and painting. Include budget estimates, timeline, materials needed, and guidance on hiring contractors.
Tips for Better Planning Results
For More Detailed Plans
Copy
Please make this plan as detailed as possible with specific recommendations, addresses for attractions, opening hours, and tips for making reservations where needed.
For Budget-Conscious Planning
Copy
Optimize this plan for maximum value on a tight budget. Focus on free/low-cost attractions, budget accommodation, and money-saving tips.
For Accessibility Considerations
Copy
Please ensure this plan accounts for accessibility needs. One person in our group uses a wheelchair, so all recommendations should be wheelchair accessible.
For Business-Focused Planning
Copy
Make this plan business-focused with clear KPIs, accountability assignments, resource allocation, and ROI projections for each phase.
Troubleshooting
If Information Seems Outdated
Copy
Some of this information seems outdated. Please re-research [specific aspect] to ensure we have the most current details available.
If the Plan Lacks Detail
Copy
This is a good start, but I need more specific details for [aspect]. Please expand this section with more actionable information.
If Recommendations Don't Match Requirements
Copy
The accommodation recommendations are above my budget range. Please provide options that fall within my specified budget of [amount].
Exporting and Sharing
You can ask Manus to prepare the plan for sharing:
Copy
Please format this plan in a professional, shareable format that I can send to my team/travel companions.
Or request specific export options:
Copy
Can you provide this project plan as a timeline visualization that I can present to stakeholders?
