# Lesson 2 - AI Tool vs AI Agent

In the second lesson of the 6-Week AI Automation Masterclass, Vick goes over the differences between AI Tools & AI Agents.
It's quite common for a lot of people to not even realize if they're using an agent or a tool. There's a clear distinction and through this lesson you'll learn how to best understand what is what and which category it falls under.
As a key takeaway from this 
lesson
 you should be able to very easily tell if the software/page/thing you're using is an agent or a tool.

List all of your 
favorite
 tools and agents and post them in the community.
