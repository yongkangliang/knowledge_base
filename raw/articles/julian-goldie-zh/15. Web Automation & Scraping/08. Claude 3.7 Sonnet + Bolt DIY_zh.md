### 概述

本指南带你了解如何安装和使用 **Bolt DIY**（**Bolt New** 的免费替代方案），并结合 **Claude 3.7 Sonnet** 进行编码项目。你将学习如何安装它、使用 AI API，甚至将项目部署上线——全部免费！

### 第一步：从 GitHub 安装 Bolt DIY

前往 [GitHub](#) 搜索 **Bolt DIY**。

按照仓库中列出的安装说明操作。

打开你的 **终端**（Windows 用命令提示符，Mac/Linux 用 Terminal）。

**逐条复制粘贴** 安装命令，每条按 **回车**。

> 💡 **提示：** 如有疑问，可查看 **AI Profit Boardroom** 获取额外设置详情。

### 第二步：本地运行 Bolt DIY

安装完成后，在终端中运行以下命令：

```
npm run dev
```

这将生成一个 **本地地址**，Bolt DIY 会在该地址上运行。

复制本地地址并在浏览器中打开。

🎉 现在你已经设置好，可以免费构建应用了！

### 第三步：连接 AI API（Claude 3.7 Sonnet）

在 Bolt DIY 内，进入 **API 选择下拉菜单**。

选择 **Anthropic (Claude 3.7 Sonnet)**（在 OpenRouter 下）。

点击 **"获取 API 密钥"** 生成 API 密钥。

在 [OpenRouter.ai](https://openrouter.ai) 注册（如果还没有账号）。

将 API 密钥**粘贴到 Bolt DIY** 中。

💡 **Claude 3.7 Sonnet 模式：**
- **思考模式（Thinking Mode）** —— 更高级的响应（质量更高）
- **普通模式（Normal Mode）** —— 更快的响应（推理较少）

### 第四步：开始 AI 编码

在 Bolt DIY 内打开 **Prompt Forge** 以生成优化的提示词。

输入你的项目想法（例如："创建一个招聘网站"）。

将生成的提示词粘贴到 Bolt DIY。

点击 **Enter**，让 AI 开始为你编码！

> ✅ **专业技巧：** 使用 Bolt DIY 中的 **AI 选项** 进一步优化提示词，获得更好的效果。

### 第六步：同时运行多个编码项目

在 Bolt DIY 中打开**多个标签页**。

为不同项目运行不同的 AI 模型。

在**思考模式**和**普通模式**之间切换以获得更好的效率。

💡 **示例：**
- 标签页 1：构建**招聘网站**
- 标签页 2：生成**交互式 SEO 审计清单**

### 第七步：部署你的项目（Netlify 免费托管）

编码完成后，进入 Bolt DIY 的 **Code** 部分。

点击 **下载代码**（将是一个 ZIP 文件）。

前往 [Netlify.com](https://netlify.com)，选择 **"新建站点"** → **"导入现有项目"**。

上传你的**解压后的项目文件夹** 以部署网站。

部署完成后，你会获得一个**免费测试域名**！

🎯 **想要自定义域名？**
点击 **"添加域名"** 直接在 Netlify 中购买。
