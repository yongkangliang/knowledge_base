# 15. Google 2.0 Computer Use Agent

Google 2.0 Computer Use Agent

### 需要什么设置？

https://aistudio.google.com/apikey
https://github.com/browser-use/web-ui

### 在 Mac 上如何设置？

根据提供的文档，我将带你逐步在 Mac 上设置 browser-use web UI。

首先，确保你具备以下先决条件:
- Python 3.11 或更高版本
- Git

打开 Terminal 克隆仓库:
```bash
git clone https://github.com/browser-use/web-ui.git cd web-ui
```

使用 uv 设置 Python 环境:
```bash
uv venv --python 3.11 source .venv/bin/activate
```

安装所需依赖:
```bash
uv pip install -r requirements.txt playwright install
```

创建并配置环境文件:
```bash
cp .env.example .env
```

在 .env 文件中配置你 Mac 特定的浏览器设置（如果你想使用自己的 Chrome 浏览器）:
```
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
CHROME_USER_DATA="/Users/YourUsername/Library/Application Support/Google/Chrome"
```
（将"YourUsername"替换为你的实际 Mac 用户名）

启动应用:
```bash
python webui.py --ip 127.0.0.1 --port 7788
```

通过打开浏览器（最好使用 Firefox 或 Edge，因为你在用自己的 Chrome 实例）访问 Web 界面:
http://127.0.0.1:7788

可选设置:
- 如果想在使用 AI 任务之间保持浏览器打开，添加 CHROME_PERSISTENT_SESSION=true 到 .env 文件
- 可以通过添加 --theme 标志自定义主题（例如 python webui.py --ip 127.0.0.1 --port 7788 --theme Ocean）
- 可以添加 --dark-mode 标志启用暗色模式

确保也在 .env 文件中添加必要的 API Key（如你计划使用特定 LLM 服务：OpenAI、Anthropic、Google 等）。

### 如何在自己的 Chrome 浏览器中运行

让我帮你设置为使用你自己的 Chrome 浏览器而不是 Chromium。

首先，确保 Chrome 在你的 Mac 上完全关闭（Cmd+Q 完全退出）

编辑你的 .env 文件以指定你的 Chrome 安装路径:
```bash
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
CHROME_USER_DATA="/Users/YourUsername/Library/Application Support/Google/Chrome"
```
（将 YourUsername 替换为你的实际用户名）

重要：在 Firefox 或 Edge 中打开 Web UI（http://127.0.0.1:7788）—— 不要用 Chrome，因为 Chrome 将被用于自动化。

在 Web UI 界面中，你需要在 Browser Settings 部分勾选"Use Own Browser"选项。

这些步骤应该会让它使用你实际的 Chrome 安装而不是默认的 Chromium。如果你仍然看到它使用 Chromium 而不是 Chrome，请告知我看到的内容。可能有一个配置问题需要我们排查。

另外，如果你想在任务之间保持浏览器会话持久化（这很有用），请确保添加:
```bash
CHROME_PERSISTENT_SESSION=true
```
到你的 .env 文件。

### 如何编辑 env 文件？

让我帮你编辑 .env 文件。首先，检查你是否已从示例创建了它:
```bash
cp .env.example .env
```

然后你可以使用任何文本编辑器编辑它。这里有几种方法:

**使用 Terminal 中的 nano（最简单）:**
```bash
nano .env
```

**使用 TextEdit:**
```bash
open -e .env
```

**如果使用 VS Code:**
```bash
code .env
```

一旦打开文件，添加以下行:
```
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
CHROME_USER_DATA="/Users/YourUsername/Library/Application Support/Google/Chrome"
CHROME_PERSISTENT_SESSION=true
```
（记得将 YourUsername 替换为你的实际 Mac 用户名）

如果你使用 nano:
- 进行修改
- 按 Ctrl+X 退出
- 按 Y 保存
- 按 Enter 确认

需要以 debug 模式运行：

这个错误是因为 Chrome 需要在 debug 模式下启动，但仍然有 Chrome 进程在运行。让我们一步步解决:

首先，完全退出 Chrome:
- 点击 Chrome 菜单（⌘ + Q）
- 或在 Terminal 中运行: `pkill -a "Google Chrome"`

然后，我们需要以 debug 模式启动 Chrome。打开 Terminal 并运行:
```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --remote-debugging-port=9222
```

Chrome 以 debug 模式启动后，打开一个新的 Terminal 窗口/标签并启动 Web UI:
```bash
python webui.py --ip 127.0.0.1 --port 7788
```

使用 Firefox 或 Edge 访问 Web 界面 http://127.0.0.1:7788（不是 Chrome）

如果你仍然看到错误，你可能需要:
- 在活动监视器中检查是否还有剩余的 Chrome 进程并强制退出
- 确保你的 .env 文件有正确的 Chrome 路径
- 确保已在 Web UI 中勾选"Use Own Browser"选项

如有任何问题随时告诉我！
