🚀 **SOP：如何使用 Google Gemini 2.5（免费）构建任何东西**

### 1. 获取 Gemini 2.5 的访问权限

前往: https://aistudio.google.com
用你的 Google 账户登录
点击模型下拉菜单（右上角）
选择 Gemini 2.5 Pro Experimental
它是 100% 免费的（没有输入/输出费用）

### 2. 用一个提示词构建游戏

提示词:
"Make me a captivating endless runner game. Key instructions on screen. Use p5.js, no HTML. Pixelated dinosaur and interesting backgrounds."

复制 Gemini 给的代码
使用 editor.p5js.org 测试

### 3. 从视频转录稿生成博客文章

提示词:
"Turn this YouTube transcript into a blog post. Make it human, SEO-optimized, include links to my funnel."

将转录稿粘贴入 Gemini
Gemini 创建 1,500 字的文章，带有吸引人的标题和漏斗链接
复制并粘贴到你的 CMS（例如 WordPress）

### 4. 创建 SEO 工具如成本计算器

提示词示例:
"Create a sleek modern SEO cost calculator with UI in HTML/CSS/JS."

使用 LiveWeave.com 测试输出
粘贴 HTML（左上）、CSS（左下）、JS（右上）

### 5. 用 N8N 构建 AI Agent

逐步操作:

1. 前往 N8N.io（本地托管或使用云端）
2. 创建新 workflow
3. 添加"Chat Trigger" → 添加"AI Agent"块
4. 选择"Google Gemini"作为聊天模型
5. 从 aistudio.google.com 输入你的 Gemini 2.5 API Key
6. 设置 system message（例如"You are an SEO assistant"）
7. 用简单消息测试聊天机器人

### 6. 用 AI Agent 自动化邮件

在 N8N 中添加 Gmail 工具
让 AI 自动填充 To、Subject 和 Message 字段

提示词:
"Send an email to [you@example.com] inviting them to the Gemini 2.5 launch party this Sunday."

Agent 为你发送完全格式化的 HTML 邮件

### 7. 自动发布内容到 WordPress

使用 Gemini agent 生成内容
在 N8N 中添加"Create Post"WordPress 块
Gemini 编写并以 HTML 格式自动发布内容

### 8. 比较模型（可选）

- Gemini 2.5 = 编码、速度和推理方面更好
- DeepSeek V3 = 撰写人性化内容方面更好
- Claude = 写作和设计方面出色（有内置画布）

### 9. 附加工具

- Visual Studio Code + RooCode: 在里面使用免费 Gemini API 编码网站
- Make.com: 自动化 Google Sheets > Gemini > WordPress
- OpenRouter.ai: 如果 Gemini 原生 API 不起作用时使用

⚡ **高级技巧:**
想测试 AI 内容检测？使用 ZeroGPT 确保内容是免检测的。

### BOLT DIY 设置方法:

**1:** 打开 Terminal 并克隆仓库:
```bash
cd ~
git clone https://github.com/coleam00/bolt.new-any-llm.git
cd bolt.new-any-llm
```

**2:** 安装 PNPM（包管理器）:
```bash
npm install -g pnpm
```

**3:** 安装项目依赖:
```bash
pnpm install
```

**4:** 保存并退出 nano:
- 按 Control + X
- 按 Y 保存
- 按 Enter

**5:** 启动开发服务器:
```bash
pnpm run dev
```

**6:** 选择 Open Router > 选择 Gemini 2.5
