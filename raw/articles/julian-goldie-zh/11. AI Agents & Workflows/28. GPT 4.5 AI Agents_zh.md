## 概述

本指南将引导你使用 GPT-4.5 和 n8n（一个自动化工具）设置一键式 AI agent。这个 AI agent 可以生成回复、自动化邮件任务等。

🔹 GPT-4.5 的最佳用例：
✅ 建议与简短回复
✅ 类人交互
✅ 邮件自动化与新闻通讯

🔹 GPT-4.5 不擅长的领域：
❌ 长篇文章
❌ 复杂工作流
❌ 编码和逻辑密集型任务

## 第 1 步：设置 n8n 并创建工作流

前往 n8n 并开始新建工作流。

在 n8n 内点击 概览 > 创建工作流。

添加新步骤：选择 聊天触发器（这会在收到聊天消息时启动 AI agent）。

为什么不使用 Zapier 或 Make.com？
在 n8n 中设置 AI agent 更快更容易。

## 第 2 步：将 AI Agent 连接到聊天触发器

添加新模块 → 选择 AI Agent。

提示词来源 = 聊天。

AI agent 将获取聊天触发的首次回复。

## 第 3 步：连接 OpenAI 并获取你的 API 密钥

前往 OpenAI 的 API 平台：https://platform.openai.com。

登录 并前往 设置 > API 密钥。

创建新的密钥（每个项目可以有不同 API 密钥）。

使用 GPT-4.5 Preview（⚠️ 此模型比其他模型更昂贵）。

## 第 4 步：启用对话记忆

在设置中选择 窗口缓冲记忆。

为什么？
这让 AI 能够记住过去的互动，使对话更加自然。

## 第 5 步：添加附加工具（可选）

想让 AI 发送邮件？
在 n8n 中添加 Gmail 工具。

如何连接 Gmail：
点击 添加凭据 → 使用 Google 登录。

将邮件类型设置为 HTML 邮件。

AI 将自动选择：收件人、主题和消息，基于聊天指令。

## 第 6 步：定义 AI Agent 的角色

前往 系统消息 → 定义 AI agent 的功能。

示例：
- 新闻通讯助手：撰写简短、可操作的邮件。
- 个人邮件助手：根据聊天指令发送邮件。
- SEO 研究助手：按需收集 SEO 洞察。

## 第 7 步：使用 AI Agent 自动化新闻通讯

设置 AI agent 生成新闻通讯。

使用以下提示词设置：
- 最大字数：200
- 语气：没有废话，可操作的技巧
- 受众：AI 与 SEO 爱好者
- 示例主题："GPT-4.5 新功能发布"

测试：打开聊天 → 输入主题 → 让 AI 生成新闻通讯。

## 第 8 步：使用 AI 自动化发送邮件

更改 AI agent 角色："你是一个个人邮件助手"。

测试邮件自动化：
打开聊天并输入：
"给 [email@example.com] 发送一封关于 GPT-4.5 新功能发布的邮件，表达我的兴奋之情"。

AI 将通过 Gmail 生成并发送邮件。

## 第 9 步：监控 API 成本

前往 OpenAI API 仪表板 → 查看使用情况。

GPT-4.5 每次请求的成本更高。
留意支出。

## 第 10 步：保存并分享你的 AI Agent

点击 激活 使 AI agent 上线。

复制公开 URL → 与你的团队或客户分享。
