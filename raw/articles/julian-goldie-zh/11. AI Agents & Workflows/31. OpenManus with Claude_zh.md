# 31. 使用 OpenManus + Claude

https://youtu.be/O1tbusWsgCM

GitHub 地址

免费 API 方法？从 Hyperbolic 或 Groq 设置 API 密钥 = 免费！

## 操作指南：

第 1 步：
conda create -n open_manus python=3.12
conda activate open_manus

第 2 步：
git clone https://github.com/mannaandpoem/OpenManus.git
cd OpenManus

第 3 步：
pip install -r requirements.txt

第 4 步：
cp config/config.example.toml config/config.toml

第 5 步：
nano config/config.toml

第 6 步：
设置全局 LLM 配置 > 插入你的 API 密钥

第 7 步：
Control + X > Y > Enter

第 8 步：
python main.py

第 9 步：
测试一下

第 10 步：
有问题？截图问题 + 将其粘贴到终端中，附带 GitHub 的说明。

如何设置 API 密钥：
# 全局 LLM 配置
[llm]
model = "claude-3-7-sonnet-20250219"
base_url = "https://api.anthropic.com/v1"
api_key = "sk-ant-REDACTED"
max_tokens = 4096
temperature = 0.0

# 特定 LLM 模型的可选配置
[llm.vision]
model = "claude-3-7-sonnet-20250219"
base_url = "https://api.anthropic.com/v1"
