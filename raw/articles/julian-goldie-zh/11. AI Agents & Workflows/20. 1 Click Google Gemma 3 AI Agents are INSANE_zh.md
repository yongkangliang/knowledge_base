🔹 **概述**

本 SOP 引导你了解如何使用 Gemma 3 和 n8n 设置 AI Agent、自动化 workflow、连接 Google API 以及集成 OpenRouter 以实现无缝自动化。

🚀 **使用 n8n 设置 AI Agent 的分步指南**

### 1️⃣ 安装和设置 n8n

前往 n8n.io 并创建账户。
在 n8n 上本地安装或使用云端版本。
在 n8n 中创建新的 workflow。
添加 Webhook Trigger（如果使用聊天机器人或 API 请求）。

### 2️⃣ 连接 AI 模型（Gemma 3）

**选项 1：使用 Google API（如果可用）**

- 在 AI Studio Google 获取你的 API Key
- 复制 API Key
- 在 n8n 中添加 HTTP Request Node → 设置方法为 POST
- 输入 Google API 端点并粘贴你的 API Key
- 选择 Gemma 3 27B 作为 AI 模型

**选项 2：使用 OpenRouter（推荐，如果 Google API 不起作用）**

- 在 OpenRouter 注册
- 前往 Settings → API Keys 创建新密钥
- 在 n8n 中添加 HTTP Request Node → 设置方法为 POST
- 输入 OpenRouter API 端点并粘贴你的 API Key
- 从模型列表中选择 Gemma 3

### 3️⃣ 在 n8n 中自动化 AI 回复

- 添加 Function Node 处理用户输入
- 将其连接到 HTTP Request Node 以将输入发送到 AI 模型
- 使用 Set Node 格式化 AI 的回复
- 连接到 Telegram、Email 或其他平台以发送 AI 生成的回复

### 4️⃣ 启用记忆功能（可选）

在 n8n 中添加 Storage Node 存储聊天记录。
设置为保存最近 10 次交互以获得更好的上下文保留。

### 5️⃣ 测试和部署

- 运行测试 → 输入示例查询并检查 AI 的回复
- 调试（如需要）→ 调整 API 设置或模型选择
- 部署 AI Agent 并设置为 Active Mode

### 🔥 附加：使用 SEO 优化自动化博客写作

- 为博客输入设置 Webhook Trigger

### 📌 故障排除

❌ **Google API 不起作用？**
✅ 切换到 OpenRouter（免费且更可靠）

❌ **AI 回复太慢？**
✅ 使用较小的模型如 Gemma 7B 以获得更快的回复

❌ **n8n Workflow 报错？**
✅ 检查 API Key、节点连接和执行日志
