### 第一步：获取免费 API Key

前往 aistudio.google.com。

复制 API Key —— 稍后需要用到。

### 第二步：获取免费的 N8N 试用

进入后，你就可以访问 AI agent workflow。

### 第三步：在 N8N 中设置你的 AI Agent

**Start Fresh:** 在 AI workflow 中点击 Add New Step

**选择触发类型:**
- 如果要通过聊天触发，选择 Chat Trigger
- 如果要通过应用自动化，选择 AI Agent

**连接 AI Agent:**
- 点击 AI Agent 并将其连接到不同的应用/工具
- 这让 AI 可以自动拉取和处理数据

### 第四步：连接 Google Gemini API

在 N8N 中创建新的凭证
选择 Google Gemini Account
输入来自 AI Studio 的 API Key
设置 Model 为 Gemini 2.0（最新版本，例如 "Gemini 2.0 Flash Preview – Feb 5th"）
保存凭证以供将来使用

### 第五步：测试 AI Agent

在聊天中输入："Are you working?"
如果设置正确，它将回复："Yes, I'm an AI and ready to assist!"
如果有错误，请仔细检查你的 API Key 和模型设置

### 第六步：用 Gemini 2.0 自动化内容创作

在 N8N 中添加 AI Agent 用于内容写作
修改 system message 为:
```css
You are an SEO-optimized content writer.
Write a fully formatted article for the keyword: [Keyword]
```

用关键词测试:
输入："Keyword = What is SEO?"

AI 将生成一篇 1,000 字、SEO 优化的文章

### 第七步：自动化发布到 WordPress 或 Shopify

将 WordPress/Shopify/Webflow 连接到 N8N
选择 Create Post
设置字段:
- **Title** → AI 生成的关键词
- **Slug** → AI 生成的关键词
- **Content** → AI 生成的 HTML 格式文章

测试将内容发送到 WordPress
验证它在 Posts > Preview 中正确显示

### 第八步：完全自动化 SEO Workflow

添加另一个 AI agent 用于关键词生成
修改提示词:
```vbnet
Generate one long-tail, localized keyword for my niche.
Example: "SEO training Japan"
```

将 Keyword Agent → Content Writer Agent → WordPress 链接起来

现在，只需输入你的细分市场（例如 "SEO agency"），AI 就会:
- 选择一个关键词
- 写一篇文章
- 自动发布
