### 1️⃣ 在 Visual Studio Code 中安装 Cline

打开 Visual Studio Code
前往 Extensions 部分
在搜索栏中输入 Cline
点击 Install（免费的！）
重启 VS Code 以完成设置

### 2️⃣ 在 Cline 中激活 Claude 3.7 Thinking Mode

打开 Cline Settings
选择 Anthropic 作为提供商
选择 Claude 3.7 Sonnet
启用 Extended Thinking Mode
根据项目复杂度调整 token 限制:
- 简单项目：较少 tokens
- 复杂项目：较多 tokens

💡 Plan Mode vs. Act Mode:
- Plan Mode: 在执行之前规划项目
- Act Mode: 积极编码项目

### 3️⃣ 示例：构建 AI 驱动的审计工具

打开 Cline
输入以下项目提示词:
"为 Goldie Agency 创建一个 AI 驱动的商业审计工具，分析业务运营并提出自动化建议，使用 HTML。用户输入业务详情和工作流痛点。AI 分析回复并生成个性化 AI 自动化计划。生成带有操作步骤和实施 CTA 的报告。"

在 Plan Mode 中运行提示词（AI 在编码之前规划）
切换到 Act Mode 开始开发
