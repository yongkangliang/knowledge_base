## 设置 Visual Studio Code：

🧰 逐步设置

### 1. 安装 Visual Studio Code（免费）

前往：https://code.visualstudio.com

下载安装。

### 2. 安装 RooCode 扩展

打开 VS Code → 前往扩展（左侧边栏）。

搜索 Roocode → 点击安装。

### 3. 添加你的 Claude API 密钥

从以下地址获取密钥：https://console.anthropic.com

在 RooCode 设置中，选择 Anthropic API > 粘贴 API 密钥并选择 Claude 3.7 Sonnet。

## 设置电脑使用：

步骤 1：关闭所有 Chrome 实例

步骤 2：在 Mac 上通过终端运行此命令：

在没有任何登录的新调试配置文件中：
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222

在你的现有登录信息的新调试配置文件中：
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222 --user-data-dir="/tmp/chrome-debug-profile"

在 Windows 上，执行以下操作：
"C:\Program Files\Google\Chrome\Application\chrome.exe" ^
--remote-debugging-port=9222 ^
--user-data-dir="C:\chrome-debug"

（如有任何问题，截图 > 询问 Claude 帮你。）

步骤 3：
- 登录到你想要使用的任何服务

步骤 4：开始自动化：

示例：
- 前往 Google Docs 并撰写关于 SEO 的文章
- 前往 ChatGPT 并撰写关于 SEO 的文章
- Ahrefs
- Bolt.NEW
