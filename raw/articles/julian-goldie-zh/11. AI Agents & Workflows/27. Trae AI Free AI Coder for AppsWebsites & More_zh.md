## 第 1 步：下载和安装 Trae.AI

前往 https://trae.ai

下载 macOS 版本。

一键安装。

## 第 2 步：启动新项目

打开 Trae.AI

点击"打开新文件夹"

为你的项目命名（例如，"待办事项列表"）。

点击"信任文件夹并继续"。

通过点击"是"批准任何安全弹出窗口。

## 第 3 步：选择你的 AI 模式

聊天模式 → 使用 Claude 3.5 Sonnet 提供无限 AI 辅助。

构建模式 → 用于动手编码和开发。

## 第 4 步：生成一个简单的待办事项列表应用

在右下角选择 Claude 3.5 Sonnet。

输入提示词："构建一个简单的待办事项列表应用"。

等待 AI 生成：
- index.html
- style.css
- script.js

点击"审查"查看文件。

接受所有更改。

## 第 5 步：预览和测试项目

点击"预览"

在 Python 上运行

打开网页预览

通过添加任务测试应用。

## 第 6 步：从截图克隆网站

在 Trae.AI 中打开新文件夹

上传网站的截图。

输入提示词："克隆这个网站"。

等待 AI 生成网站。

预览克隆的站点。

## 第 7 步：使用扩展和 API

导航到扩展商店。

安装工具，例如：
- Recode
- VS Code LM API
- Open Router

插入 API 密钥（可选）以获得扩展功能。

## 第 8 步：在线部署你的项目

在 Trae.AI 内右键点击项目文件夹。

将文件夹拖放到 Netlify 中进行免费托管。

立即获得实时的自定义域名。

## 第 9 步：自动化内容创作

打开聊天模式

输入提示词："创建一篇关于 [主题] 的 SEO 优化文章"。

转换为落地页：
"使用这些品牌颜色 [颜色代码] 将这个文章设计成美观的落地页"。

接受所有更改

预览并发布
