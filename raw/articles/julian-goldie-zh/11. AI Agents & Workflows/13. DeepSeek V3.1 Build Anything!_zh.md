# 13. DeepSeek V3.1 构建任何东西！

https://youtu.be/lhY_qTv5sIc
🚀
SOP：如何使用 DeepSeek V3.1 构建任何东西（应用、游戏、网站和 AI Agent）

### 第一步：开始使用 DeepSeek V3.1 Chat

前往 deepseek.com
点击"Start Now"进入聊天界面

提示词示例:
```kotlin
做一个令人上瘾的无尽跑酷游戏。屏幕上有关键操作指示，使用 P5.js，不需要 HTML。比如像素化的恐龙和有趣的背景。
```

复制代码输出
粘贴到:
editor.p5js.org
点击"Play" —— 搞定！游戏完成。测试一下，按"R"重新开始。

### 第二步：在 Hugging Face 上使用 AnyChat 构建应用

访问:
huggingface.co/spaces/Akhaliq/anychat
选择模型:
DeepSeek V3.1（或最新版本）

提示词示例:
```pgsql
创建一个简单的待办事项列表，支持添加和删除功能。
```

点击 Generate —— 测试一下。

尝试高级提示词:
```pgsql
创建一个精美的 SEO 成本计算器，带有干净的 UI。
```

### 第三步：在 47 秒内用 n8n 构建 AI Agent

前往:
n8n.io
（本地托管或自托管）

创建一个新的 workflow
添加:
- Chat Trigger
- AI Agent（通过 OpenRouter 使用 DeepSeek）
- API Key
- System Message: "You're a helpful assistant"

测试:
问"Are you working?"

添加 Gmail 模块来自动化邮件（例如，给自己发送一封！）
总耗时约 47 秒

### 第四步：使用 VS Code + RooCode 本地构建

安装 VS Code:
code.visualstudio.com
安装 RooCode 插件
连接 DeepSeek API（在设置中搜索 v3）

提示词示例:
```css
为我的 SEO 机构创建一个精美的着陆页 —— 设计现代美观。
```

免费在本地构建和预览。

### 第五步：使用 Make.com 自动化 workflow

在 make.com 注册
创建新的 Scenario
添加:
- OpenRouter（DeepSeek）
- Google Sheets（输入）
- WordPress（输出）

示例：从 Sheets 获取关键词 -> 生成博客 -> 发布到 WP
在 AI Profit Boardroom 中有现成模板可用！

### 附加技巧

- 在本地编辑前先备份项目
- 手动检查内容质量
- 你可以使用当前内容 + AI 提示词重建整个网站
- 升级到 Gemini 2.5 Pro 以获得更好的自动化效果
