标准操作流程：如何在 Vector Shift 中使用 Claude 3.7 Sonnet 构建免费 AI Agent

本指南将引导你使用 Vector Shift 内的 Claude 3.7 Sonnet 构建一个免费 AI agent。有了这个，你可以创建 AI 驱动的聊天机器人、内容生成器和自动化工具——而且一分钱都不用花！

## 第 1 步：访问 Vector Shift

前往 VectorShift

如果没有账户，请注册或登录。

## 第 2 步：设置你的 AI Agent

删除现有节点（如有必要）
如果你有现有的工作流，请先删除它们从头开始。

添加新 LLM 模块
点击"添加新模块"。

选择 "AI" → 选择 Anthropic 作为 LLM 提供商。

将模型设置为 Claude 3.7 Sonnet。

输入 AI 的系统指令。

## 第 3 步：连接模块

创建输入字段
这将获取聊天机器人的用户输入。

将输入连接到 Claude 3.7 Sonnet
使用大括号 {} 标记聊天记忆和输入字段。

添加知识库（可选但推荐）
前往 Vector Shift 的知识库。

点击"添加文档"上传文件或添加 URL。

这有助于 AI 学习你的特定内容。

启用聊天记忆
这确保 AI 能记住过去的对话。

选择"聊天记忆"并将其链接到 LLM。

设置输出节点
将 Claude 3.7 Sonnet 的响应连接到输出节点。

这决定了结果的展示方式。

## 第 4 步：测试和部署你的 AI Agent

运行测试
前往"运行" → 选择 聊天机器人。

输入测试提示词（例如，关键词 = 日本 SEO 培训）。

等待 AI 响应 —— 它应该返回格式化的、可直接使用的内容。

部署 AI Agent
点击"部署" → "导出"。

选择使用方式：
- 作为聊天机器人（收藏以便快速访问）。
- 嵌入到你的网站（复制代码并粘贴到 WordPress）。
- 通过与 Google Sheets、WordPress、Gmail 等集成来自动化任务。

附加功能：自动化内容发布
如果你想直接将内容发布到 WordPress：
前往集成 → 选择 WordPress。

连接你的 WordPress 账户。

启用 AI agent 的自动发布功能。
