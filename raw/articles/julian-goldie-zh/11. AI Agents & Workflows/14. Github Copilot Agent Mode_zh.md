### 概述

GitHub Copilot 的新 Agent Mode 允许你免费构建网站、应用和自动化工具，并获得 AI 辅助。本指南将带你逐步完成设置和有效使用。

### 第一步：安装 Visual Studio Code Insiders

✅ 前往 Visual Studio Code Insiders
✅ 下载并安装适用于你操作系统的软件

### 第二步：安装所需扩展

打开 Visual Studio Code Insiders
前往 Extensions（Ctrl + Shift + X）
安装:
- GitHub Copilot
- GitHub Copilot Chat
- Klein（用于构建应用、网站和工具）

点击 Trust Publisher 和 Install

### 第三步：在 GitHub Copilot 中启用免费 AI 模型

在 Visual Studio Code 中前往 Settings
选择 Visual Code LM API
启用免费模型的访问权限:
- GPT-3.5 Mini Preview
- Claude 3.5 Sonnet
- Gemini 2.0 Flash

🚀 你每月可免费获得 2,000 次补全 + 50 次聊天请求

### 第四步：开始使用 GitHub Copilot Agent 模式

#### 切换模式

- Edit Mode（手动控制）
- Agent Mode（自动化编码和自动修复）

打开 VS Code 中的 Copilot Chat
选择 Agent Mode
输入你的提示词（例如，"创建一个 AI 咨询机构的着陆页"）
让 Copilot 自动生成和优化代码

### 第五步：用 AI 构建网站或应用

使用 Prompt Forge AI（可选）生成高质量提示词
将提示词输入 Copilot Chat
Copilot 将会:
- 生成 HTML、CSS 和 JavaScript
- 自动修复任何问题
- 改进 UI 设计（使用 Claude 3.5 Sonnet）

🚀 示例提示词: "创建一个看起来像 eBay 的网站。"
Copilot 将生成并结构化文件
点击 Explorer（左上角）查看项目文件
保存文件并在浏览器中运行

### 第六步：改进和定制网站

#### 后端开发:
使用 GPT-3.5 Mini 高效生成代码

#### 前端设计:
使用 Claude 3.5 Sonnet 获得更好的 UI 样式
提示词示例："改进设计，使其现代化和简洁。"

### 第七步：运行和测试项目

点击 Run This 在浏览器中预览
使用 LiveWeave.com 测试简单的 HTML/CSS/JavaScript 项目
通过添加图片、社交媒体链接和额外页面来自定义网站

### 第八步：自动化和扩展开发

通过启动新的 VS Code 窗口打开多个项目
AI 将在后台同时编写不同页面的代码
使用 Agent Mode 进行持续改进和 bug 修复

### 总结

- 零成本使用 AI 驱动编码（在限制范围内）
- Agent Mode = AI 为你工作
- 最佳编码模型:
  - 后端: GPT-3.5 Mini
  - 前端: Claude 3.5 Sonnet
