# 10. Gemini 全新更新！

https://youtu.be/ZcpQ_9o2mh4
Gemini: 全新更新！
42:13

**1. 个人上下文与临时聊天**

Gemini 现在可以从你过去的对话中学习，提供更个性化和上下文感知的回复。这个"个人上下文"功能默认开启，但你可以随时关闭。与此同时，**临时聊天**模式让你可以进行一次性对话，不会被保存也不会影响未来的回复——非常适合保护隐私或实验。

[The Times of India](+4) [Tom's Guide](+4) [Android Central](+4)

官方博客解释了如何在应用中切换设置来管理这些功能。临时聊天将于 2025 年 8 月 13 日开始推出。

[blog.google](https://blog.google)

**2. 引导式学习模式**

2025 年 8 月 6 日左右推出的 **引导式学习** 是 Gemini 的新交互教学模式。它不只是给出答案——而是通过问题、可视化、测验、视频和丰富的回复一步步带你学习主题。就像有一个个性化的 AI 导师。

[X (原 Twitter)](+3) [TechRadar](+) [blog.google](+3)
https://g.co/gemini/share/419f9dcc7309

部分国家的学生现在可以将引导式学习作为免费 AI Pro 计划的一部分使用。

[Tom's Guide](+5) [Lifewire](+5) [Android Central](+5)

**3. Android Google Docs 中的图片生成**

Gemini 的图片生成功能现在可以直接在 **Android** 上的 **Google Docs** 移动应用中工作。你可以在不离开应用的情况下从文本提示词创建自定义图片。此功能面向订阅了 Business、Gemini Education、AI Pro 或 AI Ultra 计划的 Android 用户推出——特别是在 Pixel 9 等较新设备上，很快也将支持 Pixel 10。

[Cinco Días](+2) [Gemini](+2)

**4. Oracle Cloud 中的 Gemini**

Google 与 Oracle Cloud 达成协议，通过 Oracle 的基础设施提供 Gemini AI 模型。这意味着开发人员可以利用 Gemini 的生成式 AI 进行文本、图像、视频和音频处理，使其更容易被企业采用。

[reuters.com](https://reuters.com)

**5. Gemini API：Imagen 4 全面上线**

2025 年 8 月 14 日，Google 在 Gemini API 中将 **Imagen 4**（Ultra、Standard 和 Fast 模型）全面上线。

[ai.google.dev](https://ai.google.dev)

### 直播演示方案，让你的观众惊艳

以下是如何将这些更新融入你的直播——根据你的高影响力、解决方案导向的风格量身定制：

**A. 用"心灵感应"上下文演示个人上下文**

**直播设置：** 开启一个新的直播。向 Gemini 提出一个关于你之前分享过的偏好的问题（例如，"基于我们过去的聊天，什么主题最适合我的受众？"）。

**为什么惊艳：** 展示真正了解 **你** 的 AI——大胆的个人化让观众惊叹不已。

**B. 用临时聊天做实验**

**直播设置：** 使用临时聊天询问一个问题，如"有什么有趣的阴谋论提示词？"然后重置。接着用一个与你直播主题相关的个人聊天继续。

**为什么惊艳：** 强调控制和隐私——人们喜欢看到自己的数据被认真对待。

**C. 实时展示引导式学习**

**直播设置：** 使用引导式学习为自己或观众教授一些东西，比如"SEO 外链基础"。Gemini 会提出问题、展示可视化材料并对你进行测验。

**为什么惊艳：** 沉浸式学习感觉新鲜、动态且极具吸引力。你不是在讲课——你是在一起探索发现。

**D. 在 Android Docs 中创建图片**

**直播设置：** 在你的 Android 设备上打开 Google Docs，输入一个标题，然后请 Gemini 在那里直接生成一张图形。

**为什么惊艳：** 在不离开工作区的情况下增加即时视觉亮点——干净、有创意且实用。

**E. 展示 Oracle Cloud 的企业级集成**

**直播设置：** 解释企业现在如何利用 Gemini 在 Oracle Cloud 内打造营销内容或内部工具。

**为什么惊艳：** 增加了战略性、懂商业的层次。你不只是一个外链建设者——你懂得企业价值。

**F. 通过 API 展示 Imagen 4**

**直播设置：** 使用 Gemini API 生成一张图片——也许是一个网页或品牌概念的视觉呈现，展示 API 控制台或代码的实际操作。

**为什么惊艳：** 技术与创意实时交汇——非常适合程序员、创作者和好奇的人。
