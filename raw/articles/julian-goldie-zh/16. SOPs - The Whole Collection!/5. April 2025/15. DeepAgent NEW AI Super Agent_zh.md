### SOP：

#### 🛠️ SOP：如何使用和测试 Abacus AI 的 Deep Agent

#### 🚀 目标：

探索如何使用 Abacus AI 的 Deep Agent 自动化构建网站、创建游戏和发送电子邮件等任务——然后将它与 GenSpark 和 Manus 等其他工具进行比较。

#### ✅ 第一步：访问 Deep Agent

前往 Abacus AI

登录并点击左下角 Tools 部分下的"Deep Agent"。

#### ✅ 第二步：了解它能做什么

Deep Agent 可以：

- 构建网站（例如 Next.js 或 Tailwind）
- 创建 SaaS 工具
- 生成技术报告、仪表板（例如 Jira）
- 摘要 Gmail 邮件（连接后）
- 在子域上托管应用
- 在执行任务之前进行研究

#### ✅ 第三步：运行你的第一个任务（例如，一个游戏）

1. 进入"Tasks"部分
2. 粘贴一个 prompt，例如："创建一个 2D 太空入侵者游戏"
3. 点击运行，让代理处理
4. 审查输出（可能需要 5-25 分钟）

#### ✅ 第四步：测试网站构建

使用类似 prompt："为 Julian Goldie 创建一个 5 页的 SEO 机构网站。"

让它进行研究并生成计划。

等待代码构建和部署。

评估结果。

#### ✅ 第五步：检查 Gmail 集成（可选）

1. 导航到"Connect App"设置
2. 尝试连接你的 Gmail 或 Google Drive
3. 测试命令："总结过去 24 小时的 Gmail 活动"

#### ✅ 第六步：了解局限性

- 最多同时 2 个活跃任务
- 每个任务消耗计算积分（每个任务 5 万-10 万）
- 复杂任务可能失败或耗尽资源
- 不能直接导出到 Wix 或 WordPress

#### ✅ 第七步：与其他工具比较

| 工具 | 优点 | 缺点 |
|------|------|------|
| GenSpark | 快速，多任务，优秀输出 | 不易导出到 Wix |
| Manus | 不错的构建器，限制少 | 更通用的结果 |
| Deep Agent | 联网，自动研究 | 慢，有限制，仍在测试中 |

#### ✅ 最终结论

- Deep Agent 有前景但尚未准备好投入使用
- GenSpark 在速度和可靠性方面获胜，特别适合需要更好任务处理和更流畅输出的创作者
