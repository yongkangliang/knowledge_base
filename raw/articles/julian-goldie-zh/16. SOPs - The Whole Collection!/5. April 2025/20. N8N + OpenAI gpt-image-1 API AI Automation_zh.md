# 20. N8N + OpenAI gpt-image-1 API AI 自动化

https://platform.openai.com/docs/guides/image-generation?image-generation-model=gpt-image-1

详见附带的 workflow 导入文件！

### SOP：在 N8N 工作流中使用 GPT Image One API

### 概述

本 SOP 指导你通过 N8N 设置自动化工作流，使用 OpenAI 的新 GPT Image One API 生成高质量图像。工作流允许你通过聊天输入 prompt 并自动生成、转换和下载图像。

### 前置条件

- N8N 账号
- OpenAI API 密钥（来自 platform.openai.com）

### 第一步：创建新的 N8N 工作流

1. 登录你的 N8N 账号
2. 创建一个新的工作流
3. 命名你的工作流（例如"GPT Image Generator"）

### 第二步：设置聊天触发器

1. 点击"+"按钮添加新模块
2. 选择"Chat Message"或"Trigger on Click"作为初始触发器
3. 配置模块以接收你的文本输入

### 第三步：配置 HTTP 请求

1. 点击"+"添加一个新的 HTTP Request 模块
2. 将其连接到触发器模块
3. 用以下设置配置 HTTP Request：

**方法：** POST

**URL：** https://api.openai.com/v1/images/generations

**头部：** 添加授权头，Bearer YOUR_API_KEY（替换为你的实际 API 密钥）

**切换"Send Body"为 ON

**Body 格式：** JSON

**Body 内容：**

```json
{
  "model": "gpt-image-1",
  "prompt": "{{$node["Chat Message"].json["message"]}}",
  "size": "1024x1024",
  "quality": "standard"
}
```

注意：你可以自定义"size"参数以获得不同的尺寸（例如用于 YouTube 缩略图）

### 第四步：将 JSON 转换为图像文件

1. 添加"Convert to File"模块
2. 将其连接到 HTTP Request 模块
3. 配置设置：
   - Base Input Field：从下拉菜单选择"b64_json"
   - Operation："Move base64 string to file"

### 第五步：查看或下载图像

工作流运行后，点击 Convert to File 模块中的"View"查看生成的图像。

点击"Download"将图像保存到电脑。

### 第六步（可选）：添加 AI 代理以增强 Prompt

在你的触发器和 HTTP Request 之间插入一个 AI agent 模块。

配置系统消息："你是一个 YouTube 视频的创意设计缩略图设计师。将团队的想法转化为惊人的图像生成 prompt。"

将输入消息设置为使用来自聊天触发的内容。

将其输出连接到 HTTP Request 模块。

更新 HTTP Request 以使用 AI 代理的输出作为 prompt。

### 第七步：测试你的工作流

1. 激活你的工作流
2. 在聊天中输入你的图像创意（例如"SEO link building thumbnail"）
3. 等待约 30-45 秒生成图像
4. 查看并下载你的图像

### 更好结果的提示

- 在 prompt 中具体描述
- 添加风格信息（例如"photorealistic"、"cartoon"等）
- 指定你想要的构图（例如"person looking shocked at chart"）
- 使用 AI 代理将基本创意增强为详细 prompt

### 可选：让你的工作流公开

1. 将工作流切换为"Active"
2. 点击"Share"并设为公开可用
3. 与团队成员或客户分享聊天 URL
