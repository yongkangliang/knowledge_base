### SOP：

**利用 ChatGPT 03 模型升级的标准操作程序**

**目的**

本 SOP 概述如何有效利用 ChatGPT 03 模型的最新升级，重点关注三大改进：消息限额增加、增强的带推理功能的调度能力，以及新的图像生成功能。

**范围**

本程序适用于所有 ChatGPT 03 和 04 mini 模型的用户。

**职责**

- 终端用户负责根据自身需求实施这些功能
- 团队成员应了解如何利用 03 的高级推理功能

**定义**

- **ChatGPT 03**：具有记忆功能的高级推理模型
- **ChatGPT 04 mini**：较新的测试版模型，但比 03 慢
- **记忆功能**：允许 ChatGPT 记住以前对话的功能
- **Playground**：OpenAI 的各种 AI 功能测试环境

**程序**

#### 1. 利用 03 的消息限额增加

**1.1 概述**

- 03 的消息限额已从每周 50 条增加到 100 条
- 03 和 04 mini 现在可用于所有 API 使用层级

**1.2 利用更高的限额**

1. 从下拉菜单中选择 ChatGPT 03 模型
2. 对于高级推理任务，利用 03 的 thinking mode 功能
3. 充分利用 100 条消息限额来处理更复杂的任务
4. 对于 API 用户，调整你的实施以利用扩大的限额

#### 2. 使用 03 实现个性化任务调度

**2.1 设置流程**

1. 导航到 ChatGPT 并选择 03（避免 04 mini，因为它对于此用途较慢且效果较差）
2. 使用以下 prompt 结构：

"基于你对我的了解，你能用 ChatGPT 定时任务为我计划和自动化哪些任务？"

3. 审查 ChatGPT 03 提供的建议
4. 为最佳结果，要求 03 识别高影响力任务：

"基于你对我的了解，分析这些任务中哪些能帮我节省最多的时间（80/20 原则是什么）？"

**2.2 创建定时任务**

1. 从建议中选择一个任务或指定你自己的
2. 使用类似 prompt 请求自动化：

"自动化 [任务名称]"

3. 审查定时任务详情
4. 根据需要调整：
   - 通过说"改为 [时间]"更改时间
   - 按要求添加其他指示

**2.3 管理定时任务**

1. 通过 Settings → Tasks 访问任务
2. 查看已完成和待处理的任务
3. 点击删除按钮删除不需要的任务
4. 根据需要修改现有任务

**2.4 用于任务更新电子邮件管理**

为 ChatGPT 通知创建单独的 Gmail 文件夹：

1. 为 ChatGPT 的邮件创建过滤器
2. 应用标签以便于组织
3. 设置过滤器以自动排序这些邮件

#### 3. 使用 Playground 中的增强图像功能

**3.1 访问图像 Playground**

前往 platform.openai.com/playground/images

从菜单中选择 Images 部分。

**3.2 自定义图像生成**

设置图像格式偏好：

- 尺寸：方形、竖屏或横屏
- 质量：高、中或低
- 图像数量：1-10（根据需求调整）

**3.3 创建图像**

1. 输入你的图像 prompt 或描述
2. 上传参考图像（如需）
3. 点击 Generate
4. 使用箭头按钮预览多个版本
5. 下载你偏好的图像

**3.4 相对于 ChatGPT 直接图像生成的优势**

- 尺寸更一致，没有文字截断
- 一次请求生成多个版本
- 更好的质量控制选项
- 更适合缩略图创建和营销内容

### Gmail 过滤器步骤，将 ChatGPT 邮件放在自己的文件夹中。

1. 在电脑上打开 Gmail。点击齿轮图标然后选择 See all settings。
2. 选择 Filters and Blocked Addresses。点击 Create new filter。
3. 在 From 框中输入你 ChatGPT 邮件使用的地址。示例：no-reply@chat.openai.com
4. 点击 Create filter。
5. 勾选 Skip the Inbox。
6. 勾选 Apply the label，选择 New label，输入 ChatGPT，然后 Create。
7. 如果需要将旧消息也移入，勾选 Also apply filter to matching conversations。
8. 点击 Create filter 完成。

所有未来的 ChatGPT 邮件将绕过收件箱，生活在 ChatGPT 标签下，所以你的主收件箱保持整洁。

#### 🛠️ 第二步：启用必要的设置

在 ChatGPT 中前往 Settings > Personalization。

打开：

- ✅ Save memories（保存记忆）
- ✅ Reference chat history（引用聊天记录）

（可选）清除与当前目标不相关的旧记忆。

#### 📅 第三步：调度任务

使用此 prompt：

"请调度每隔 [X 时间] 从 [开始时间] 到 [结束时间] 每天向我发送 [主题] 的更新。"

示例：

"请调度每 1 小时从 9 点到 5 点每天向我发送 VGT 价格的更新。"

你可以在 ChatGPT 右上角的"Tasks"菜单中查看/编辑/暂停任务。

#### 💡 第四步：问 ChatGPT 该自动化什么

使用此 prompt：

"基于你对我的了解，你能给我 4-5 个你应该调度的任务建议，以及它们应该运行的频率吗？"

这使用了 ChatGPT 对你目标和偏好的记忆。
