### ✅ 优点

**1. 原生工具已添加**

现在你不需要自己托管了。

MCP 触发器和客户端工具已内置于 n8n 中。

**2. 更容易的设置**

只需将 n8n 更新到 1.88 版本。

不再需要安装额外的东西。

**3. Claude 现在可以使用 n8n 工具**

你可以将 Claude Desktop 连接到 n8n。

Claude 可以运行你创建的工作流。

**4. 实时工具访问**

Claude 可以看到你所有的 MCP 工具。

你可以让它做诸如创建活动或发送消息等操作。

**5. 与其他应用兼容**

你可以与 Cursor 等 IDE 连接。

Claude 可以触发自定义工作流。

### ❌ 缺点

**1. 灵活性不足**

你目前无法构建一个"超级代理"。

Claude 同时理解的服务器或工具数量仍然有限。

**2. 仅支持 SSE**

它只能通过 SSE（Server Sent Events）工作。

某些工具不支持此方式。

其他工具需要命令行或不同的连接方式。
