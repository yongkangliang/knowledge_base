# 17. NEW Make.com AI 代理更新

Make.com 的新 AI 更新太可怕的好用了——看我现场构建代理！🤯

### SOP：如何在 Make.com 上设置 AI 代理并自动化你的工作流

#### 🎯 目标

在 Make.com 上创建你自己的 AI 代理，自动执行任务（如发送邮件、检索 Google Docs 或在 Telegram 中聊天），使用简单的工作流。

#### 🛠️ 第一步：在 Make.com 上设置

1. 在 Make.com 上创建账号
2. 升级到 $10/月的计划（你需要这个才能访问 AI 代理——目前处于测试阶段）
3. 前往 Organization → Subscription，确保你在正确的计划上

#### 🧠 第二步：创建你的第一个 AI 代理

1. 点击"Create Agent"
2. 选择一个 AI 模型（例如 Gemini、Claude、ChatGPT）
3. 为你的代理命名（例如"Julian Goldie 的 SEO 助手"）
4. 添加一个系统 prompt，例如："你是 Julian Goldie 的有帮助的助手。"
5. 点击 Save

#### 🔗 第三步：连接工具和流程

你可以连接什么：

- Gmail
- Google Docs
- WordPress
- Telegram

如何连接工具：

1. 创建一个新 Scenario（例如"发送邮件"）
2. 添加一个模块（例如 Gmail →"发送一封邮件"）
3. 设置输入：
   - 电子邮件地址
   - 主题
   - 内容

⚠️ 确保你的 scenario：

- Active（活跃）
- 设置为"on demand"（按需）（不是调度或监听表格）

通过 System Tools → Add Scenario 将此 scenario 链接到你的 AI 代理。

#### 📄 第四步：构建和连接 Scenarios（示例）

**示例 1：发送邮件**

1. 创建 scenario → Gmail →"发送邮件"
2. 添加必需输入（邮件、主题、内容）
3. 将此 scenario 链接到你的 AI 代理

**示例 2：Google Docs 自动化**

1. 创建 scenario → Google Docs →"获取内容"
2. 将输出作为文本添加
3. 将输出链接到你的代理的操作

#### 💬 第五步：与 Telegram 集成

1. 在 Telegram 中通过 BotFather 创建一个 Telegram bot
2. 使用 /newbot，命名它，获取 token
3. 在 Make.com 中：
   - 添加 Telegram → Watch Updates
   - 添加你的 Telegram bot token
4. 创建一个新 scenario：
   - Telegram Watch Update → Make AI Agent → Telegram Reply
5. 使用来自 Telegram 的 chat ID 和 message text 作为输入
6. 添加你的 AI 代理 scenario 作为响应

#### 🚀 第六步：运行它！

1. 通过 Telegram 发送消息
2. 你的 AI 代理实时处理和回复
3. 它现在可以访问 Gmail、Google Docs 和你连接的任何其他东西！
