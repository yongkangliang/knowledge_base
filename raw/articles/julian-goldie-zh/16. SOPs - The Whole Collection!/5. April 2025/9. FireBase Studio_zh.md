# 9. Firebase Studio

### SOP：如何使用 Firebase Studio 构建 AI 应用（无需编码！）

#### 第一步：Firebase Studio 是什么？

Firebase Studio 是 Google 全新的 AI 驱动应用构建器。

可以把它看作是 Project IDX 的重生版——而且更厉害。

与 Bolt 或 Lovable 等平台竞争。

完全免费，无需编码。

#### 第二步：如何获取访问权限

访问：studio.firebase.google.com

使用你的 Gmail 账号登录。

搞定，进去了！🎉

#### 第三步：开始构建你的第一个应用

在 prompt 框中输入你的想法（例如"SEO 抽认卡应用"）。

点击"Prototype with AI"。

Firebase Studio 会自动构建蓝图、布局、颜色，甚至过渡效果！

#### 第四步：自定义你的应用

你可以：

- 更改应用名称
- 使用你的品牌颜色
- 修改布局

如果某处出错了？点击"Fix Error"——它会像魔法一样自动纠正问题 🪄

#### 第五步：发布并分享你的应用

点击"Publish"。

Firebase 给你一个托管的子域名链接。

你可以：

- 分享链接
- 通过电子邮件添加团队成员
- 生成二维码以供访问

#### 第六步：使用高级功能

- 切换到代码视图手动调整你的应用
- 版本控制：随时恢复早期版本
- 绘图工具和其他有趣的 UI 调整
- 还与 Gemini 2.5 Flash 集成以提供更多高级功能

#### 第七步：加入社区（可选但很棒）

- 在 AI Profit Boardroom 中访问 100+ 应用创意和模板
- 每周 Q&A 会议
- 发布你自己的构建并获得反馈

### 专业提示：

如果它要求 API 密钥：

前往 studio.google.com

点击"Get API Key"

粘贴进去就好了！
