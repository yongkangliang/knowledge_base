### SOP：如何使用 Optimus Alpha 进行编码、构建应用和 AI 代理

#### 步骤 1：访问 Optimus Alpha

前往 Optimus-Alpha.org

使用 OpenRouter 访问——只需在聊天模型下拉菜单中选择"Optimus Alpha"。

没有速率限制，免费使用——尽情编码！

#### 步骤 2：开始编码应用或游戏

尝试以下 prompts：

- "构建一个 Duolingo 风格的应用来教授泰语"
- "创建一个名为 Tariff Pong 的乒乓球游戏"

Optimus Alpha 处理代码、UI 设计等——超快且完全免费。

#### 步骤 3：在 Visual Studio Code 中使用

通过使用你的 OpenRouter API 密钥将 Optimus Alpha 连接到 VS Code。

在你的开发环境中直接编码——无使用限制，体验流畅。

#### 步骤 4：设置 Open Web UI（可选）

在终端中输入：

```
pip install open-webui && open-webui serve
```

将其连接到 OpenRouter 并选择 Optimus Alpha。

现在你拥有了一个 ChatGPT 风格的界面来使用这个模型。

#### 步骤 5：在 NA10 中构建 AI 代理

打开 NA10 并创建一个新工作流。

添加一个 Chat Node——命名为"Optimus Alpha AI Agent"之类的。

选择 OpenRouter 并选择 Optimus Alpha 模型。

添加你的系统 prompt 并点击"Activate"。

现在你有了一个运行中的聊天机器人/AI 工具。

#### 附加：使用可视化提示和修复 bug

Optimus Alpha 是多模态的——你可以上传截图，它会帮你调试 UI！

只需调整 prompt 就能构建完全可用的工具。
