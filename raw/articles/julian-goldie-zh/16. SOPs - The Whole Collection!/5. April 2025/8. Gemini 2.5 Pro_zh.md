# 8. Gemini 2.5 Pro

### SOP：如何构建深度研究 AI 代理（付费和免费方法）

### 目标：

构建一个使用 Google Gemini 2.5 Pro（付费）或 VectorShift（免费）进行深度研究的 AI 代理。

#### 方法 1：使用 Gemini 2.5 Pro（付费）

**分步：**

1. 登录 Gemini（需要高级版）
   前往 gemini.google.com，需要 Pro 订阅。

2. 切换到深度研究模式
   使用下拉菜单选择"Deep Research"。

3. 适合深入任务，例如比较 IDE、市场分析或产品发布。

4. 输入你的 prompt
   示例："调研最新的 IDE，比较 All Man Code Plus 与其他 IDE 的区别。"

5. 编辑研究计划（可选）
   你可以在 Gemini 开始之前调整它将研究的内容。
   如果满意，点击"Good to Go"启动。

6. 等待 5-30 分钟获取结果
   Gemini 将调研 140+ 个网站。
   它将生成执行摘要、详细分析、洞察和来源。

7. 访问结果
   你可以按主题查看来源、摘要和洞察。

#### 方法 2：使用 VectorShift（免费）

**分步：**

1. 前往 VectorShift
   注册/登录，如有需要可删除旧的 pipeline。

2. 创建新 Pipeline
   点击"Create Pipeline"。

3. 添加 Chat Input 模块

4. 添加大型语言模型（LLM）
   从下拉菜单中选择 Gemini 2.5 Pro Experimental。

5. 跳过个人 API 密钥（或者可选择通过 AI Studio 添加以获得更好的限额）。

6. 设置 Prompt
   ```
   你是一个深度研究助理。基于 Google 搜索结果 {{GoogleSearch.urls}} 和 {{GoogleSearch.snippets}} 创建一个格式精美的研究报告。
   ```

7. 添加 Web 搜索的数据加载器
   选择 Google Search 或其他搜索引擎。

8. 将输入链接到搜索查询。

9. 部署聊天机器人
   测试：例如"创建一个关于 Gemini 2.5 的深度研究报告。"

10. 审查响应并根据需要微调

11. 导出和部署你的 Bot
    点击"Export Chatbot"。
    命名它，自定义品牌，嵌入或部署到 Slack。

#### 额外提示：

- 使用 Gemini 进行超深度、全面的报告
- 使用 VectorShift 进行更快、免费和可定制的代理
- 你可以将聊天机器人嵌入你的网站或部署到 Slack 频道
- 适合营销人员、研究人员和需要自动化重复研究任务的团队
