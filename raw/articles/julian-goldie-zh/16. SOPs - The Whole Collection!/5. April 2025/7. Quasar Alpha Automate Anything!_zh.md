# 7. Quasar Alpha 自动化一切！

SOP for Bolt Local

### SOP：如何使用 Quasar Alpha 免费构建和自动化任何东西

#### 什么是 Quasar Alpha？

这可能是 OpenAI 的新模型（可能是 GPT-4.5 甚至 GPT-5）。

通过 OpenRouter.ai **免费**提供。

拥有 **百万 token 上下文窗口**（超大上下文 = 更强大的工作流）。

 trending、快速、强大，非常适合自动化。

#### 使用 Quasar Alpha 的分步指南

**1. 免费访问**

前往 OpenRouter.ai。

选择 Quasar Alpha 作为你的模型。

选择你的提供商："Auto"或"Stealth"。

**2. 运行测试 Prompt**

运行任何基本 prompt（例如草莓测试）以确认正常工作。

#### 在 Visual Studio Code (VSC) 中使用

**3. 下载 Visual Studio Code**

前往 code.visualstudio.com 并安装。

**4. 设置 OpenRouter 集成**

打开扩展 > 安装"Client"或"Roo"扩展。

在设置中：

- 选择 OpenRouter
- 添加你的 OpenRouter API 密钥
- 选择 Quasar Alpha 作为模型

#### 连接 Perplexity MCP 服务器

**5. 使用实时信息进行自动化研究**

使用 Perplexity 连接到互联网。

生成实时数据（AI 新闻、近期研究等）。

包含免费 API 使用。

#### 使用 Bolt Local 构建项目

**6. 安装 Bolt Local**

加入 AI Profit Boardroom 获取脚本。

在终端中运行：它设置 Bolt Local 与 GitHub。

**7. 快速创建应用**

在 Bolt 中：

使用 Quasar Alpha 构建待办事项列表或小测验游戏等应用。

你可以导出代码，通过 GitHub/Netlify 托管，并进行可视化调整。

#### 使用 NA10 创建 AI 代理

**8. 设置 AI 代理**

前往 NA10（如果本地托管则免费）。

创建工作流：

- 添加聊天触发器
- 使用"有帮助的助手"系统消息
- 通过 OpenRouter 选择 Quasar Alpha

几秒钟完成！

#### 自动化社交媒体内容

**9. 创建 SEO 或社交内容**

添加来自 AI Profit Boardroom 的 prompts。

将你的视频脚本/新闻粘贴到 prompt 中。

即时生成推文或社交平台内容。

#### 总结

你现在知道了如何：

- 通过 OpenRouter 免费使用 Quasar Alpha
- 使用 VSC + Perplexity + Bolt Local 构建和自动化
- 使用 NA10 创建 AI 代理和自动化内容
- 发布代码到线上并轻松管理旧项目
