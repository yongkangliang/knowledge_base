### 标准操作程序：使用 OpenAI 的 GPT Image One API 构建图像生成应用

### 概述

本 SOP 引导你通过 OpenAI 的 GPT Image One API 创建一个简单的图像生成 Web 应用。此过程大约需要 20-30 分钟，需要基本的编码知识。

### 第一步：设置开发环境

1. 从 code.visualstudio.com 下载并安装 Visual Studio Code
2. 从 VS Code 扩展市场安装"Client"扩展
3. 获取 API 密钥：
   - OpenAI：在 platform.openai.com 注册（需要信用卡）
   - 替代方案：使用 ai.google.dev 上的 Google Gemini API（免费）

### 第二步：创建你的项目

1. 在 VS Code 中为你的项目创建一个新文件夹
2. 在 VS Code 中打开该文件夹
3. 启动 Client 扩展

### 第三步：构建你的图像生成应用

在 Client 中创建一个新任务并使用此 prompt：

"创建一个应用，让我可以插入来自 OpenAI 的 GPT image one API 来构建图像生成应用。"

"不要使用 DALL-E 3，使用 GPT image one。"

**需要避免的常见错误：**

- 使用 context 7 加上 API 文档主动预防
- 留意"API 请求失败，状态 400"错误
- 记得对 quality 值使用"low"、"medium"或"high"
- 确保正确的图像尺寸（缩略图为横屏）

粘贴 OpenAI 关于 GPT Image One 的文档。

让 Client 生成初始代码。

通过运行预览来测试你的应用。

通过将错误粘贴回 Client 来解决任何问题。

### 第四步：改善你的 UI（可选）

1. 在 Client 设置中，切换到 Anthropic API 提供商
2. 创建新 prompt："让 UI 变得更美观、更现代"
3. 等待 Claude 更新你的 HTML、CSS 和 JavaScript

### 第五步：部署你的应用

1. 前往 Netlify.com
2. 点击"Add new site"→"Import an existing project"
3. 拖放你的项目文件夹
4. 你的应用将通过 Netlify URL 部署
5. 与他人分享链接，他们可以用自己的 API 密钥使用它

### 使用说明

- 用户需要自己的 OpenAI API 密钥来使用此应用
- 可能需要组织验证才能获得图像生成访问权限
- 每次图像生成大约花费 $0.02-$0.05
- 图像大约需要 30-45 秒生成

### 故障排除

- 如果出现 API 错误，检查你是否使用了正确的参数值
- 确保为你的用途指定正确的尺寸
- 如果遇到访问问题，验证你的 OpenAI 组织
