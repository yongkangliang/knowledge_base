### 标准操作程序：Trae AI 编程助手

#### 1. 简介

Trae AI 是一款免费的 AI 编程助手，提供对高级 AI 模型的免费访问，包括 GPT-4.1、Claude 3.7 和 Gemini 2.5 Pro，无任何使用限制或费用。本 SOP 概述如何安装、配置和利用 Trae AI 进行高效编码和项目开发。

#### 2. 入门

**2.1 安装**

1. 前往 trae.ai
2. 下载应用程序
3. 安装并启动 Trae AI

**2.2 初始设置**

1. 打开 Trae AI
2. 点击"Start Coding"开始使用平台
3. 熟悉界面元素：
   - AI 聊天界面
   - 文件系统查看器
   - 代码编辑器
   - 终端
   - 预览窗口

#### 3. 核心功能

**3.1 高级 AI 模型（免费访问）**

Trae AI 提供免费访问以下高级 AI 模型：

- Claude 3.5 Sonnet
- Claude 3.7 Sonnet
- Gemini 2.5 Pro
- GPT-4.1
- GPT-4
- 通过 Open Router 集成的其他模型

**3.2 自定义 AI 代理**

为不同的编码任务创建专门的 AI 代理：

1. 点击"Add Agent"
2. 配置代理设置：
   - 为代理命名
   - 选择允许的工具和 MCP
   - 创建自定义 prompt 和规则
   - 选择首选 AI 模型

**3.3 网页搜索集成**

在编码时直接搜索网页：

1. 在 builder 中使用内置的网页搜索功能
2. 添加特定 URL 作为编码任务的上下文

**3.4 MCP（机器能力提供者）集成**

通过各种 MCP 服务增强 AI 能力：

1. 前往"Builder with MCP"
2. 在 MCP 服务器部分点击"Add"

可用的 MCP 包括：

- Slack 集成
- 记忆功能
- Brave Search（网页连接）
- Google Drive
- Firebase
- Context 7（更新文档）

#### 4. 添加 MCP 服务器

**4.1 添加 Context 7 MCP**

1. 前往"Builder with MCP"
2. 在 MCP 服务器部分点击"Add"
3. 点击"Configure Manually"
4. 前往添加 MCP 服务器部分提供的 GitHub 链接
5. 复制配置 JSON
6. 粘贴到 Trae AI
7. 点击"Confirm"

**4.2 通过 Open Router 添加自定义 API 模型**

1. 前往模型选择部分
2. 点击"Add API"
3. 选择"Open Router"
4. 从 Open Router 获取 API 密钥
5. 将 API 密钥复制粘贴到 Trae AI
6. 从 Open Router 选择所需的模型
7. 对于自定义模型，从 Open Router 复制模型 ID 并粘贴到 Trae AI

#### 5. 构建项目

**5.1 开始新项目**

1. 点击"Open Folder"选择项目位置
2. 信任文件夹（出现提示时）
3. 回到顶部点击"Trae"进入 AI 聊天
4. 选择所需的 AI 模型
5. 向 AI 描述你的项目需求

**5.2 处理项目文件**

1. 使用文件浏览器导航项目文件
2. 启用"Auto Run Commands"以简化开发
3. 使用预览功能测试应用

**5.3 使用 AI 生成代码**

1. 清楚说明你想要构建的内容
2. 使用具体的 prompt 以获得更好的结果
3. 检查生成的代码
4. 接受或修改更改
5. 使用预览功能测试功能

#### 6. 项目示例

**6.1 构建缩略图生成器**

1. 描述缩略图生成器的需求
2. 指定使用的 API（例如"使用 GPT Image One API"）
3. 让 Trae AI 生成 HTML、CSS 和 JavaScript
4. 在预览窗口中测试功能
5. 根据需要调整
