#### 🔍 什么是 Context7 + MCP？

Context7 是一个不断更新的大型语言模型（LLM）和 AI 编码工具的文档中心。把它想象成一个永远新鲜的科技手册图书馆。

MCP 服务器部分？那就是魔法所在。它将 Context7 直接集成到你的本地 AI 代理设置中。所以你的模型不再依赖过时的训练数据或抓取过时文档，而是获得**实时的、结构化的原生文档访问**。

MCP = Model Context Protocol（模型上下文协议）。

它像一个本地知识工具，你的 AI 可以在任务中途查询——用真实可信的信息超强赋能其推理能力。

#### 💡 使用场景

**实时开发研究**

Prompt AI 获取并存储关于任何框架或 API 的最新信息。

编写代码时不再有幻觉或过时信息。

**自动化错误调试**

当 AI 遇到错误时，它可以在建议修复之前通过 MCP 查阅最新文档。

**自动更新的上下文记忆**

对于处理长任务（例如全栈构建）的 AI 代理，它可以通过为每个添加的工具或依赖项 ping Context7 MCP 来保持自身上下文的新鲜。

**快速原型设计**

使用前沿工具（例如 Next.js 更新、AI SDK）构建时，你可以确信 AI 引用的是最新的语法和使用示例。

**个人 API/工具集成**

添加你自己的文档（如内部 API、SEO SOP、外链检查清单）以赋予 AI 即时的原生访问权限。

**AI 编码代理（Cline/RooCode 兼容）**

使用 Context7 MCP 帮助 Rue 等 LLM 在每一个决策点都有准确文档的情况下自动导航复杂的多步编码任务。

#### ⚙️ 优势

- **大幅提高生产力**：每周节省数小时查找更新文档的时间
- **防止幻觉**：强制模型在假设它"知道"之前先检查来源
- **适合 SEO/开发工作流**：添加你自己的玩法或 SOP 作为本地 MCP
- **代理兼容**：适用于 Claude、GPT-4、Gemini 2.5 等——任何可以访问外部函数的都可以

#### 🧠 SOP：如何设置和使用 Context7 MCP 以获得更好的 AI 编码输出

#### 🎯 目标：

将 Context7 MCP 集成到你的编码环境中，获取最新的 API 文档，减少使用 AI 编码时的幻觉。

#### 🔧 分步设置

**1. 为什么 Context7 很棒**

它自动获取最新的 API 文档（例如 Next.js、Supabase、NodeJS）。

减少代码中的幻觉和错误。

让你的代码跟上最新的示例。

适用于 Cursor、Windsurf、Claw Desktop 和 Visual Studio Code 等工具。

**2. 通过 Klein 安装 Context7**

1. 打开 Klein
2. 前往 MCP Marketplace
3. 找到 Context7 并点击 Install
4. 搞定——一键安装魔法

**3. 在编码中使用 Context7**

在编辑器（如 Cursor 或 VS Code）中，进入聊天部分。

输入类似：

"使用 Context7 API 获取 Next.js 中 useRouter 的最新文档"

让 AI 从 MCP 服务器获取新文档。

与 Claude 3.7 或 Sonic（Anthropic 首选）配合得很好，你也可以试试 Google Gemini（免费）。

**4. Windsurf 中的高级设置**

1. 打开 Windsurf 设置
2. 搜索 MCP
3. 前往 Model Context Protocol Server > 点击 Add Config Server
4. 粘贴来自 Context7 GitHub 的 JSON 配置
5. 确认并测试它是否获取了正确的 API 文档

**5. 获取免费 API 密钥（可选）**

1. 前往 Google AI Studio
2. 创建一个免费 API 密钥
3. 将其粘贴到 Klein 的 API 密钥部分

**6. 如需卸载**

在 Klein 中，前往 Installed MCPs 部分。

找到 Context7，然后关闭、删除或重启。
