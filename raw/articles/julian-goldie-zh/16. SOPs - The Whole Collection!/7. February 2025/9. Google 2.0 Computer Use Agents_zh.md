如何在 Mac 上设置？
根据提供的文档，我将逐步指导你在 Mac 上设置 browser-use web UI。

首先，确保你具备前置条件：

Python 3.11 或更高版本
Git

打开终端并克隆仓库：

bash
Copy
git clone https://github.com/browser-use/web-ui.git
cd web-ui

使用 uv 设置 Python 环境：

bash
Copy
uv venv --python 3.11
source .venv/bin/activate

安装所需的依赖：

bash
Copy
uv pip install -r requirements.txt
playwright install

创建并配置环境文件：

bash
Copy
cp .env.example .env

为你的 Mac 专用浏览器配置在 .env 文件中（如果你想使用自己的 Chrome 浏览器）：

Copy
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
CHROME_USER_DATA="/Users/YourUsername/Library/Application Support/Google/Chrome"

（将 "YourUsername" 替换为你的实际 Mac 用户名）

启动应用：

bash
Copy
python webui.py --ip 127.0.0.1 --port 7788

通过打开浏览器（如果你使用自己的 Chrome 实例，推荐 Firefox 或 Edge）访问 Web 界面并导航至：

Copy
http://127.0.0.1:7788

可选设置：

如果你想在不同 AI 任务之间保持浏览器打开，请在你的 .env 文件中添加 CHROME_PERSISTENT_SESSION=true

你可以通过在启动应用时添加 --theme 参数来自定义主题（例如，python webui.py --ip 127.0.0.1 --port 7788 --theme Ocean）

你可以添加 --dark-mode 参数启用深色模式

如果你计划使用特定的 LLM 服务（OpenAI、Anthropic、Google 等），请确保也在你的 .env 文件中添加任何必要的 API 密钥。

## 如何在自己的 Chrome 浏览器中运行

让我帮你设置为使用你自己的 Chrome 浏览器而不是 Chromium。

首先，确保你的 Chrome 在 Mac 上完全关闭（Cmd+Q 以完全退出）

编辑你的 .env 文件以指定你的 Chrome 安装：

bash
Copy
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
CHROME_USER_DATA="/Users/YourUsername/Library/Application Support/Google/Chrome"

（将 YourUsername 替换为你的实际用户名）

重要：在 Firefox 或 Edge 中打开 Web UI（
http://127.0.0.1:7788
）——不要用 Chrome，因为 Chrome 将用于自动化。

在 Web UI 界面中，你需要勾选"浏览器设置"部分的"使用自己的浏览器"选项。

这些步骤应该让它使用你实际的 Chrome 安装而不是默认的 Chromium。如果你仍然看到它使用 Chromium 而不是 Chrome，请告诉我你看到的内容。可能有一个我们需要排查的配置问题。

另外，如果你想在不同任务之间保持浏览器会话持久化（这可能有用），请确保添加：

bash
Copy
