### 第二步：一条提示即可构建网站

1. 打开 Manus AI
2. 输入简单命令
   示例：
   ```
   Research Julian Goldie, then build and deploy the best possible website about him.
   ```
3. 等待 AI 执行 – AI 将：
   - 从 LinkedIn、网站和社交媒体等来源研究数据
   - 生成完整的网站结构
   - 编写网站代码（HTML、CSS、JavaScript）
   - 部署到 **Manus 子域名**
4. 测试网站 – 点击页面并检查错误

### 第三步：将 Manus AI 网站部署到 Netlify

1. 在 Manus AI 中请求网站文件：
   ```
   Give me the HTML, CSS, and JavaScript files for this project so I can host it on Netlify.
   ```
2. 下载 ZIP 文件
3. 前往 **Netlify** → 点击 "Deploy a New Site"
4. 上传 ZIP 文件
5. （可选）添加自定义域名 – 在 Netlify 的 Domain Management 中注册新域名
