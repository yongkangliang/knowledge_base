## Manus AI 介绍：什么是 Manus 及其核心功能

### 概述

Manus AI 是由 Monica（一家中国初创公司）开发的自主 AI 智能体，能够控制网页浏览器、创建和部署内容，并以极少监督执行深度研究。Manus 于 2025 年 3 月发布，代表了 AI 智能体能力的重大进步，将浏览器控制、深度研究、编码和部署整合到一个界面中。

### 核心功能

**自主网页浏览**
- 完全浏览器控制，可导航网站
- 可滚动页面并与网站元素交互
- 视觉能力分析和理解网页内容
- 可同时处理多个窗口

**文件创建与管理**
- 直接在聊天中创建可下载的文件
- 根据指令编辑文件
- 提供创建内容的预览功能

**部署能力**
- 将网站部署到子域名（如 manus.space）
- 部署 SaaS 工具和应用程序
- 创建可转移到其他托管平台的代码

**深度研究**
- 对任何主题执行全面网络研究
- 分析和综合多个来源的信息
- 创建带图表等视觉元素的报告

**多任务处理**
- 可同时处理多个任务
- 在你做其他事情时在后台工作
- 定期提供任务进度更新

### Manus 与其他 AI 工具的比较

**对比 ChatGPT**
- 比 ChatGPT 更自主
- 可部署功能和工具（不仅仅提供代码）
- 主动解决问题，无需持续指导

**对比 Claude**
- 虽然 Manus 似乎使用了 Claude 的 API，但大幅扩展了其功能
- 增加了终端使用、部署能力和文件管理
- 更自主的问题解决

**对比 Perplexity**
- 比 Perplexity 更能执行超出研究的复杂任务
- 可创建和部署功能网站与应用
- 更强的编码和开发能力

### 基准测试

据 GAIA 基准（评估通用 AI 辅助的基准）显示，Manus 在多项指标上超越了 OpenAI 的深度研究能力。

## 使用 Manus AI 构建和部署网站

### 概述

本 SOP 概述了使用 Manus AI 创建、定制和部署网站的流程。借助 Manus，你可以通过少量提示构建功能完整、响应式的网站，无需任何编码知识。

### 第一步：开启新会话

1. 登录你的 Manus AI 账号
2. 点击 "New Session" 开始新对话
3. 选择 "Standard" 努力模式（或 "High Effort" 用于更复杂的站点）

### 第二步：创建你的网站

**基本网站创建提示词模板**
```
Create and deploy a modern, beautiful website for [your business/topic]. Include:
- A clean, responsive design
- Navigation menu with [list pages you want]
- [Any specific sections, features, or content]
- [Any embedding requirements (videos, forms, etc.)]
Make sure the website is mobile-friendly and has clear calls to action.
```

**示例提示词**
```
Research Julian Goldie and his AI Profit Boardroom, then create a really modernized, beautiful website promoting his AI Profit Boardroom. Link to sign up is [URL]. Don't include any pricing on the website, but do include plenty of information on what it is, why to buy, write the copy like Alex Hormozi. Include plenty of social proof about me. Here's the embeddable VSL that we can insert: [embed code]
```

### 第三步：观察构建过程

- Manus 会研究你的主题（如适用）
- 它会规划网站结构
- 你将看到它创建 HTML、CSS 和 JavaScript 文件
- 构建过程中它会定期提供更新

### 第四步：审核与优化

部署后，Manus 会提供一个链接供你查看网站（通常在 manus.space）。
仔细审核网站。
如需修改，使用清晰具体的指令：
```
Please make the following changes:
- Update the hero section to be more impactful
- Add more testimonials in the social proof section
- Make the call-to-action buttons larger and brighter
```

### 第五步：部署到你自己的域名

**方法一：下载文件并使用 Netlify**
1. 向 Manus 请求网站文件：
   ```
   Give me the files to host as a folder on Netlify
   ```
2. Manus 会创建一个可下载的 zip 文件
3. 下载并解压 zip 文件
4. 前往 Netlify.com 如需则创建账号
5. 点击 "Add new site" → "Import an existing project" → "Try Netlify Drop"
6. 拖放解压后的文件夹
7. 部署后，在 Netlify 的 "Domain management" 中
8. 点击 "Add domain" 或 "Buy a new domain" 并按提示操作

**方法二：直接集成（如可用）**
向 Manus 请求直接部署到 Netlify：
```
Deploy this website to Netlify using these credentials: [your credentials]
```
按 Manus 的指示完成身份验证

### 附加技巧

**电商网站**
指定产品、定价结构和支付集成的细节：
```
Create an e-commerce website for my handmade jewelry business with product categories, individual product pages, and integration capabilities for [payment platform].
```

**目录网站**
```
Create a local SEO directory website listing businesses in [industry] across [locations]. Include individual location pages optimized for SEO with the format "Best [business type] in [location]".
```

**个人/作品集网站**
```
Create a personal portfolio website for me as a [profession]. Research my background at [LinkedIn/social profiles] and include sections for About, Portfolio, Services, and Contact.
```

### 故障排除

- 如网站无法正常加载：让 Manus 排查并修复代码中的任何错误
- 如内容不准确：提供具体更正供 Manus 实施
- 如设计需要改进：提供具体设计反馈，尽可能附上示例

### 复杂网站的高质量提示词示例

```
Create and deploy a comprehensive real estate website with the following:
1. Home page with featured listings, about us section, and testimonials
2. Property listings page with filtering options (price, location, bedrooms)
3. Individual property page template
4. Agent profiles section
5. Contact form
6. Resources page with mortgage calculator

Design should be modern, mobile-responsive, and follow real estate industry best practices. Use a color scheme of blue and white with gold accents. Include clear CTAs for "View Properties" and "Contact Us" on all pages.
```

## 使用 Manus AI 构建 SaaS 工具

### 概述

本 SOP 概述了使用 Manus AI 创建功能性 SaaS（软件即服务）工具的流程。你可以构建交互式仪表板、实用工具和各类 Web 工具，无需编写代码。

### 前提条件

- 有 Manus AI 访问权限
- 明确 SaaS 工具的目的和功能
- 基本了解你的工具应具备哪些功能

### 第一步：规划你的 SaaS 工具

在提示 Manus 之前，定义：
- 工具的核心目的
- 主要功能和功能
- 目标用户
- 基本 UI/UX 要求
- 任何集成需求（如适用）

### 第二步：创建你的 SaaS 工具

**基本 SaaS 工具创建提示词**
```
Create and deploy the best and most useful [type of tool] for [specific use case/industry]. The tool should include:
- [Feature 1]
- [Feature 2]
- [Feature 3]
Design it with a modern, user-friendly interface suitable for [target audience].
```

**示例提示词**
```
Create and deploy the best and most useful tool you can for my SEO agency, Goldie Agency. This is for lead generation. It should include a dashboard to track leads, a section to discover new leads, ability to import leads, and lead scoring functionality. Make it professionally designed with an intuitive interface.
```

### 第三步：开发过程

Manus 将经历以下阶段：
1. 规划工具架构
2. 设计界面
3. 开发前端组件
4. 创建后端功能
5. 测试和调试
6. 部署

在此过程中，Manus 会提供进度更新，并可能提出澄清问题以确保工具符合你的需求。

### 第四步：测试与优化

当 Manus 提供已部署工具的链接（通常在 manus.computer）后，彻底测试所有功能。
识别任何 bug 或需要的改进。
提供具体反馈，例如：
```
The dashboard looks great, but the lead import functionality isn't working properly. Also, can we add a filter function to the lead list?
```

### 第五步：部署考虑

**临时部署**
- Manus 最初在临时网址（manus.computer）上部署 SaaS 工具
- 每次想再次访问时需让 Manus 重新部署

**永久部署选项**
1. 请求源代码：
   ```
   Please provide all the code files for this SaaS tool so I can deploy it permanently.
   ```
2. 部署到永久托管服务：
   - 下载提供的文件
   - 选择托管平台（Netlify、Vercel、Heroku 等）
   - 按照托管平台的部署说明操作

3. 集成支付系统：
   ```
   Can you modify this tool to integrate with [payment provider, e.g., Stripe]? Here are my API keys: [provide API keys]
   ```

### 各类 SaaS 工具示例

**分析仪表板**
```
Create a comprehensive analytics dashboard for tracking website performance. Include sections for traffic overview, user behavior, conversion tracking, and content performance. Use interactive charts and graphs for data visualization.
```

**CRM 系统**
```
Build a lightweight CRM system for a small business. Include contact management, deal tracking, task assignment, and basic reporting. Design it to be intuitive for non-technical users.
```

**内容管理工具**
```
Create a content planning and management tool for a marketing team. Include a content calendar, idea repository, assignment tracking, and integration capabilities with popular platforms like WordPress and social media.
```

**项目管理工具**
```
Develop a project management tool with Kanban boards, task assignment, deadline tracking, and progress visualization. Make it collaborative with the ability for multiple users to interact.
```

### 成功技巧

**更复杂的工具**
分阶段提出需求：
```
Let's build this tool in phases:
1. First, create the core user interface and basic functionality
2. Once that's working, add the data visualization components
3. Finally, implement the reporting and export features
```

**性能优化**
```
Please ensure this tool is optimized for performance with fast loading times and responsive design that works well on both desktop and mobile devices.
```

**未来可扩展性**
```
Design this tool with a modular architecture so new features can be easily added in the future. Document the code structure clearly.
```

### 常见问题的故障排除

- 如功能未按预期工作：让 Manus 用详细的错误描述调试特定功能
- 如部署失败：请求 Manus 排查部署过程并提供替代部署选项
- 如 UI 需要改进：提供需要增强的 UI 元素的具体反馈
- 如后续需要修改工具：你可以带着源代码回到 Manus 请求具体修改

### 安全考虑

- 避免在初始提示词中分享敏感 API 密钥或凭据
- 对于处理敏感数据的工具，要求 Manus 实施适当的安全措施：
  ```
  Please ensure this tool implements proper data encryption, secure authentication, and follows GDPR compliance guidelines.
  ```
- 部署到生产环境前审查代码的安全漏洞

## 使用 Manus AI 创建全面的旅行与项目计划

### 概述

本 SOP 概述了如何使用 Manus AI 创建详细的旅行行程、项目计划和其他综合规划文档。Manus 可以研究、组织并提供各种规划需求的可操作信息。

### 第一步：开始规划会话

1. 登录你的 Manus AI 账号
2. 开始新会话
3. 选择 "Standard" 努力模式（更复杂的计划选 "High Effort"）

### 第二步：制定有效的规划提示词

**旅行行程提示词模板**
```
Create a [duration] trip plan for [destination] in [month/season]. Include:
- Daily activities and attractions
- Accommodation recommendations for different budgets
- Transportation options
- Estimated costs
- Local dining recommendations
- Packing suggestions
- [Any specific interests or requirements]
```

**旅行提示词示例**
```
Create a 30-day trip for Lower Manhattan in June. Include daily activities, accommodation options for different budgets, transportation details, estimated costs, local dining recommendations, and a packing list. I'm particularly interested in cultural attractions, food experiences, and some off-the-beaten-path locations.
```

**项目计划提示词模板**
```
Create a comprehensive project plan for [project type]. Include:
- Project phases and milestones
- Timeline with deadlines
- Resource requirements
- Budget estimation
- Risk assessment
- [Any specific methodologies or requirements]
```

### 第三步：观察规划过程

Manus 在处理你的计划时会：
- 研究目的地或项目需求
- 浏览相关网站获取最新信息
- 将信息组织到结构化章节中
- 创建包含完整计划的下载文件
- 定期提供进度更新

### 第四步：审核与优化计划

完成后，Manus 会提供下载计划文档的链接。
仔细审核计划并要求任何调整：
```
This looks good overall, but could you add more budget-friendly dining options and include information about public transportation passes?
```

### 第五步：使用规划文档

Manus 通常提供多种格式的计划：
- Markdown (.md) 文件
- 文本文档
- 有时为 CSV 或电子表格文件（用于预算/日程）

你可以：
- 下载这些文件供离线使用
- 请求特定文件格式
- 让 Manus 将文档通过电子邮件发送给你或他人

### 各类旅行规划示例

**城市探索**
```
Create a 7-day itinerary for exploring Rome, Italy in September. Focus on historical sites, local cuisine, and cultural experiences. Include accommodation options in the €100-200/night range and options for getting around the city efficiently.
```

**公路旅行**
```
Plan a 14-day road trip along the US West Coast from Seattle to San Diego. Include recommended stops, attractions, driving times between locations, accommodation suggestions, and notable roadside attractions. Budget is moderate.
```

**家庭度假**
```
Create a 10-day family-friendly vacation plan for Orlando, Florida in April. We have two children (ages 7 and 10). Include theme park recommendations, entertainment options suitable for kids, family-friendly restaurants, and accommodation with pools. Budget is $5,000 total excluding flights.
```

### 各类项目规划示例

**创业启动**
```
Create a comprehensive business launch plan for a specialty coffee shop. Include market analysis, startup costs, staffing requirements, marketing strategy, and timeline from initial planning to grand opening. Assume a budget of $150,000 and a target launch in 6 months.
```

**活动策划**
```
Create a detailed plan for organizing a 3-day professional conference for 200 attendees. Include timeline, venue requirements, speaker management, marketing strategy, budget breakdown, and logistics planning. Event is scheduled for 8 months from now.
```

**房屋装修**
```
Create a detailed home renovation plan for updating a 2,000 sq ft home built in the 1980s. Focus on kitchen and bathroom modernization, flooring replacement, and painting. Include budget estimates, timeline, materials needed, and guidance on hiring contractors.
```

### 获得更佳规划结果的技巧

**更详细的计划**
```
Please make this plan as detailed as possible with specific recommendations, addresses for attractions, opening hours, and tips for making reservations where needed.
```

**预算友好型规划**
```
Optimize this plan for maximum value on a tight budget. Focus on free/low-cost attractions, budget accommodation, and money-saving tips.
```

**无障碍需求**
```
Please ensure this plan accounts for accessibility needs. One person in our group uses a wheelchair, so all recommendations should be wheelchair accessible.
```

**业务focused 规划**
```
Make this plan business-focused with clear KPIs, accountability assignments, resource allocation, and ROI projections for each phase.
```

### 故障排除

**如信息看似过时**
```
Some of this information seems outdated. Please re-research [specific aspect] to ensure we have the most current details available.
```

**如计划缺乏细节**
```
This is a good start, but I need more specific details for [aspect]. Please expand this section with more actionable information.
```

**如推荐不符合需求**
```
The accommodation recommendations are above my budget range. Please provide options that fall within my specified budget of [amount].
```

### 导出与分享

你可以要求 Manus 准备分享的计划：
```
Please format this plan in a professional, shareable format that I can send to my team/travel companions.
```

或请求特定的导出选项：
```
Can you provide this project plan as a timeline visualization that I can present to stakeholders?
```
