# 23. DeepSeek V3.1 构建任何东西！

🚀 **SOP：如何使用 DeepSeek V3.1 构建任何东西（应用、游戏、网站和 AI 智能体）**

### 第一步：开始使用 DeepSeek V3.1 Chat

前往 [deepseek.com](#)
点击 "Start Now" 进入聊天

**提示词示例：**
```kotlin
Make me a captivating endless runner game. Key instructions on screen, P5.js, no HTML. Like pixelated dinosaurs with fun backgrounds.
```

复制代码输出，粘贴到：
[editor.p5js.org](#)
点击 "Play" —— 搞定！游戏完成。测试它，按 "R" 重启。

### 第二步：在 Hugging Face 上使用 AnyChat 构建应用

访问：
[huggingface.co/spaces/Akhaliq/anychat](#)
选择模型：
- DeepSeek V3.1（或最新版）

**提示词示例：**
```pgsql
Create a simple to-do list with add/remove functionality.
```
点击 **Generate** —— 测试它。

尝试高级提示词：
```pgsql
Create a beautiful SEO cost calculator with a clean UI.
```

### 第三步：使用 n8n 在 47 秒内构建 AI 智能体

前往：[n8n.io](#)（本地托管或自托管）
1. 创建新工作流
2. 添加：
   - Chat Trigger
   - AI Agent（DeepSeek via OpenRouter）
   - API 密钥
   - System Message: "You're a helpful assistant"
3. 测试：问 "Are you working?"
4. 添加 Gmail 模块来**自动化邮件**（例如，发一封给自己！）

总耗时：约 47 秒

### 第四步：使用 VS Code + RooCode 本地构建

1. 安装 VS Code：[code.visualstudio.com](#)
2. 安装 RooCode 插件
3. 连接 DeepSeek API（在设置中搜索 v3）

**示例提示词：**
```css
Create a landing page for my SEO agency — beautifully designed, modern.
```
免费在本地的构建和预览。

### 第五步：使用 Make.com 自动化工作流

1. 在 [make.com](#) 注册
2. 创建新 Scenario
3. 添加：
   - OpenRouter（DeepSeek）
   - Google Sheets（输入）
   - WordPress（输出）
4. 示例：从 Sheets 获取关键词 → 生成博客 → 发布到 WP
