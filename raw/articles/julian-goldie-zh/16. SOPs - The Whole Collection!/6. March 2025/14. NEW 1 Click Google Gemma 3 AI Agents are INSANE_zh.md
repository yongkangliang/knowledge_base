### 🔹 概述

本 SOP 带你了解如何使用 **Gemma 3** 和 **n8n** 设置 AI 智能体、自动化工作流、连接到 Google API，以及集成 OpenRouter 以实现无缝自动化。

### 🚀 设置 AI 智能体的分步指南（在 n8n 中）

#### 1️⃣ 安装和设置 n8n

1. 前往 **n8n.io** 并创建账号
2. **本地安装** n8n 或使用**云版本**
3. 在 n8n 内创建**新工作流**
4. 添加 **Webhook Trigger**（如使用聊天机器人或 API 请求）

#### 2️⃣ 连接 AI 模型（Gemma 3）

**方案一：使用 Google API（如可用）**
1. 在 AI Studio Google 获取你的 API 密钥
2. 复制 API 密钥
3. 在 n8n 中添加 **HTTP Request Node** → 将方法设为 **POST**
4. 输入 Google API 端点并**粘贴你的 API 密钥**
5. 选择 **Gemma 3 27B** 作为 AI 模型

**方案二：使用 OpenRouter（如 Google API 不可用则推荐）**
1. 在 OpenRouter 注册
2. 前往 **Settings → API Keys** 创建新密钥
3. 在 n8n 中添加 **HTTP Request Node** → 将方法设为 **POST**
4. 输入 **OpenRouter API 端点**并粘贴你的 API 密钥
5. 从模型列表中选择 **Gemma 3**

#### 3️⃣ 在 n8n 中自动化 AI 回复

1. 添加 **Function Node** 处理用户输入
2. 将其连接到 **HTTP Request Node** 将输入发送到 AI 模型
3. 使用 **Set Node** 格式化 AI 的回复
4. 连接到 **Telegram、Email 或其他平台** 发送 AI 生成的回复

#### 4️⃣ 启用记忆（可选）

在 n8n 中添加 **Storage Node** 来存储聊天记录。
设置为**保存最后 10 次交互**以更好地保留上下文。

#### 5️⃣ 测试与部署

1. 运行测试 → 输入示例查询并检查 AI 回复
2. 如有需要调试 → 调整 API 设置或模型选择
3. 部署 AI 智能体并设置为 **Active Mode**（活跃模式）

### 🔥 附加：使用 SEO 优化自动化撰写博客

1. 为博客输入设置 **Webhook Trigger**
2. 添加 **Function Node** 结构化查询
3. 通过 OpenRouter 连接到 **Gemma 3 AI 模型**
4. 将 AI 回复格式化为 **SEO 优化博客文章**
5. 自动发布到 **WordPress、Medium 或 Google Docs**

### 📌 故障排除

❌ **Google API 不工作？**
✅ 切换到 **OpenRouter**（免费且更可靠）

❌ **AI 回复太慢？**
✅ 使用**较小模型**如 **Gemma 7B** 以获得更快回复

❌ **n8n 工作流出错？**
✅ 检查 API 密钥、节点连接和执行日志
