# 26. Cursor + Gemini 2.5

## SOP：如何使用 Gemini 2.5 Pro 和 Cursor 构建并部署 AI 驱动的工具

### 第一步：设置 Cursor 和 Gemini 2.5 Pro

1. **下载 Cursor** – 安装 Cursor AI 编码助手
2. **启用 Gemini 2.5 Pro** – 在 Cursor 中选择**实验版本**以获得更好的 AI 编码
3. **测试它** – 尝试一个简单的提示词：
   "Create a Tetris game."
4. **检查输出** – 在浏览器中打开生成的 index.html 文件以验证功能

### 第二步：在 Netlify 上托管你的项目

1. 前往 **Netlify** – 在 Netlify 登录
2. **添加新项目** – 点击 "Import an existing project"
3. **上传文件** – 拖放你的项目文件夹
4. **部署** – Netlify 将提供指向你托管项目的子域名链接

### 第三步：构建 SEO 关键词研究工具

1. **在 Cursor 中提示 Gemini 2.5 Pro** – 使用结构化命令：
   - "Create a sleek and modern keyword research tool for SEO."
   - "Use Alex Hormozi-style sales copy and include CTA links."
2. **生成代码** – 让 Cursor 自动构建工具
3. **使用 Visual Studio Code（可选）** – 在 Gemini API 旁边侧边测试结果

### 第四步：API 集成以获取实时数据

1. **修改后端** – 在 Cursor 中提示：
   - "Create backend API integration with OpenAI's ChatGPT API."
   - "Allow users to enter their own API key."
2. **测试 API 连接**：
   - 前往 **OpenAI 的 API 面板**
   - 生成一个密钥
   - 将密钥插入工具并测试关键词生成

### 第五步：为专业外观改进 UI/UX

1. **提示更好的设计** –
   - "Make the UI modern and sleek like Airbnb."
   - "Add animations, relevant SEO icons, and better spacing."
2. **测试新设计** – 在浏览器中打开更新后的文件并检查改进
3. **确保用户友好的布局** –
   - 添加搜索量和关键词难度
   - 确保关键词结果格式清晰

### 第六步：最终部署与优化

1. **复制项目文件** – 将它们存储在新文件夹中（例如 Keyword-Tool）
2. **部署到 Netlify** – 按照**第二步**中的相同步骤操作
3. **测试在线版本** – 确保托管站点正常工作
4. **优化性能** –
   - 检查 API 限制并提高效率
   - 确保设计对移动端友好
