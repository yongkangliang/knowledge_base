### 概述

本指南将引导你使用 GPT-4.5 和 n8n（一款自动化工具）设置一键式 AI 智能体。该 AI 智能体能够生成回复、自动化邮件任务等。

🔹 **GPT-4.5 最佳适用场景：**
✅ 建议与简短回复
✅ 拟人化互动
✅ 邮件自动化与通讯简报

🔹 **GPT-4.5 不适用场景：**
❌ 长篇文章创作
❌ 复杂工作流
❌ 编程与重度逻辑任务

### 第一步：设置 n8n 并创建工作流

前往 n8n 并开始新建工作流。
点击 **Overview > Create Workflow**（概览 > 创建工作流）。

添加新步骤：
选择 **Chat Trigger**（聊天触发器），这将在收到聊天消息时启动 AI 智能体。

为什么不使用 Zapier 或 Make.com？
在 n8n 中设置 AI 智能体更**快速**且更**简单**。

### 第二步：将 AI 智能体连接到聊天触发器

添加新模块 → 选择 **AI Agent**。
提示来源 = Chat。
AI 智能体将采用聊天触发器的**首个回复**。

### 第三步：连接 OpenAI 并获取 API 密钥

前往 OpenAI API 平台：https://platform.openai.com 。
登录并进入 **Settings > API Keys**。
创建一个新密钥（每个项目可以使用不同的 API 密钥）。
使用 **GPT-4.5 Preview**（⚠️ 此模型比其他模型更贵）。

### 第四步：启用对话记忆

在设置中选择 **Window Buffer Memory**（窗口缓冲记忆）。
原因：这让 AI 能够记住过去的交互，使对话更加自然。

### 第五步：添加额外工具（可选）

想让 AI 发送邮件？在 n8n 中添加 **Gmail 工具**。
连接 Gmail 的方法：
点击 **Add Credentials** → 用 Google 登录。
设置邮件类型为 **HTML 邮件**。
AI 将根据聊天指令自动选择：收件人、主题和内容。

### 第六步：定义 AI 智能体的角色

进入 **System Message**（系统消息）→ 定义 AI 智能体的职责。
示例：
- **通讯助手：** 撰写简短、可操作的邮件。
- **个人邮件助手：** 根据聊天指令发送邮件。
- **SEO 研究助手：** 按需收集 SEO 洞察。

### 第七步：使用 AI 智能体自动化通讯简报

设置 AI 智能体生成通讯简报。
使用以下提示设置：
- **最大字数：** 200
- **语气：** 无废话，提供可操作的建议
- **目标受众：** AI 与 SEO 爱好者
- **示例主题：** "GPT-4.5 新发布"

测试方法：打开聊天 → 输入主题 → 让 AI 生成通讯。

### 第八步：使用 AI 自动化发送邮件

更改 AI 智能体角色："你是一个个人邮件助手。"

测试邮件自动化：
打开聊天并输入：
"给 [email@example.com] 发送一封关于 GPT-4.5 发布的邮件，表达我的兴奋之情。"
AI 将通过 Gmail 生成并发送邮件。

### 第九步：监控 API 成本

前往 OpenAI API 面板 → 检查使用情况。
GPT-4.5 每次请求成本较高，请留意支出。

### 第十步：保存并分享你的 AI 智能体

点击 **Activate** 使 AI 智能体上线。
复制公开链接 → 分享给你的团队或客户。
