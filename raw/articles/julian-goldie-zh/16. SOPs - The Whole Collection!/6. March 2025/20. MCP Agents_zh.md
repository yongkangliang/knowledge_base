### 1. MCP AI 智能体简介

MCP AI 智能体允许你**自动化任务**并将 AI 无缝集成到不同应用中。本指南将帮助你使用 **Visual Studio Code (VSC)** 和 **Cline** 设置 MCP AI 智能体以实现高效自动化。

### 2. 了解 MCP AI 智能体

**MCP = Model Context Protocol** → 像一个通用 AI 适配器。
**为何使用？**
- 消除复杂的 AI 集成
- 减少冗余工作流
- 通过一次设置连接多个工具

### 3. 在 Visual Studio Code 中设置 MCP AI 智能体

**第 1 步：安装 Visual Studio Code**
- 从 [Visual Studio Code](#) 下载（免费）
- 安装到你的系统

**第 2 步：安装 Cline 扩展**
1. 打开 **VSC**，进入 **Extensions**（Ctrl+Shift+X）
2. 搜索 **Cline** 并点击 **Install**

**第 3 步：为 MCP AI 智能体配置 Cline**
1. 在 VSC 中进入 **Cline Settings**
2. 选择 **Google Gemini**（免费 API 可用）或 **OpenRouter**（更多灵活性）

**第 4 步：安装 MCP 服务器**
1. 在 Cline 中进入 **MCP Marketplace**
2. 选择你需要的工具（例如：**Google Drive、Stripe、Shopify、Notion、Perplexity**）
3. 点击 **Install**，让 Cline 处理设置

### 4. 将 MCP AI 智能体连接到应用

- **Google Gemini** → 实时 AI 驱动工作流
- **Stripe** → 自动化发票和支付
- **Shopify** → AI 驱动的电商自动化
- **Perplexity** → 实时数据检索和研究

### 5. 故障排除与优化

- 如安装失败，重启 VSC 并重试
- 启用 **Auto Approve** 以简化设置
- 使用 **Cline 的高级设置**进行更深度的自定义
