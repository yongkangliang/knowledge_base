### 概述

本指南带你了解设置和使用 **Bolt DIY**（Bolt New 的免费替代品），搭配 **Claude 3.7 Sonnet** 进行编码项目。你将学习如何安装、使用 AI API，甚至免费部署项目。

### 第一步：在 GitHub 上安装 Bolt DIY

前往 GitHub，搜索 **Bolt DIY**。
按照仓库中列出的安装说明操作。
打开你的 **终端**（Windows 为命令提示符，Mac/Linux 为 Terminal）。
逐条**复制粘贴**安装命令，每条命令后按 **Enter**。

✅ **提示：** 如有不确定之处，可查看 AI Profit Boardroom 中的额外设置详情。

### 第二步：本地运行 Bolt DIY

安装完成后，在终端中运行以下命令：

```
npm run dev
```

这将生成一个**本地地址**，Bolt DIY 将在此地址运行。
复制本地地址并在浏览器中打开。

🎉 现在已设置完毕，可以免费构建应用了！

### 第三步：连接 AI API（Claude 3.7 Sonnet）

在 Bolt DIY 内部，进入 **API 选择下拉菜单**。
选择 **Anthropic (Claude 3.7 Sonnet)**（位于 OpenRouter 下）。
点击 **"Get API Key"** 生成 API 密钥。
在 **OpenRouter.ai** 上注册（如尚未注册）。
将你的 API 密钥**粘贴**到 Bolt DIY 中。

💡 **Claude 3.7 Sonnet 模式：**
- **思考模式：** 更高级的回复（质量更高）。
- **普通模式：** 更快的回复（推理较少）。

### 第四步：使用 AI 开始编码

在 Bolt DIY 中打开 **Prompt Forge** 以生成优化提示。
输入你的项目构想（例如："创建一个招聘网站"）。
将生成的提示粘贴到 Bolt DIY 中。
点击 **Enter**，让 AI 为你编码！

✅ **专业提示：** 在 Bolt DIY 中使用 **AI 选项**来优化你的提示，获得更好的结果。

### 第五步：使用免费 AI API 实现无限使用

如果你想**避免付费 API**，可使用免费选项：
- Google Flash 2.0（实验性）
- Misra AI
- DeepSeek Light / DeepSeek Go

🎯 **好处：** 无令牌限制，免费无限编码！

### 第六步：同时运行多个编码项目

在 Bolt DIY 中打开**多个标签页**。
为不同项目同时运行不同的 AI 模型。
在**思考模式**和**普通模式**之间切换以提高效率。

💡 示例：
- **标签页 1：** 构建招聘网站
- **标签页 2：** 生成互动式 SEO 审计清单

### 第七步：部署你的项目（使用 Netlify 免费托管）

编码完成后，进入 Bolt DIY 的 **Code** 部分。
点击 **Download Code**（这将是一个 ZIP 文件）。
前往 **Netlify.com**，选择 "New Site" → "Import Existing Project"。
上传你的**解压后的项目文件夹**以部署网站。
部署成功后，你将获得一个**免费测试域名**！

🎯 **想要自定义域名？**
点击 "Add Domain"，直接在 Netlify 内购买。

### 第八步：追踪 API 使用情况与成本

在 Bolt DIY 中，进入 **Activity** 查看 API 使用情况。
查看你花费了多少（大多数项目仅需**几美分**）。
如果你希望完全避免成本，请使用**免费 API**。
