🚀 **SOP：如何使用 Google Gemini 2.5 免费构建任何东西**

### 1. 获取 Gemini 2.5 的访问权限

1. 访问：[https://astudio.google.com](#)
2. 用你的 Google 账号登录
3. 点击模型下拉菜单（右上角）
4. 选择 **Gemini 2.5 Pro Experimental**
5. 它**100% 免费**（无输入/输出成本）

### 2. 用一条提示词构建游戏

**提示词：**
"Make me a captivating endless runner game. Key instructions on screen. Use p5.js, no HTML. Pixelated dinosaur and interesting backgrounds."

复制 Gemini 给出的代码。
使用 [editor.p5js.org](#) 测试。

### 3. 从视频转录稿生成博客文章

**提示词：**
"Turn this YouTube transcript into a blog post. Make it human, SEO-optimized, include links to my funnel."

将转录稿粘贴到 Gemini 中。
Gemini 会创建 1,500 字的文章，带有吸引人的标题和漏斗链接。
复制并粘贴到你的 CMS（如 WordPress）。

### 4. 创建 SEO 工具（如成本计算器）

**提示词示例：**
"Create a sleek modern SEO cost calculator with UI in HTML/CSS/JS."

使用 [LiveWeave.com](#) 测试输出。
粘贴 HTML（左上）、CSS（左下）、JS（右上）。

### 5. 使用 N8N 构建 AI 智能体

分步：
1. 前往 [N8N.io](#)（本地托管或使用云端）
2. 创建新工作流：
   - 添加 "Chat Trigger" → 添加 "AI Agent" 模块
3. 选择 "Google Gemini" 作为聊天模型
4. 粘贴你的 Gemini 2.5 API 密钥（来自 astudio.google.com）
5. 设置系统消息（例如 "You are an SEO assistant"）
6. 用简单消息测试聊天机器人

### 6. 使用 AI 智能体自动化邮件

在 N8N 中添加 Gmail 工具。
让 AI 自动填充收件人、主题和内容字段。

**提示词：**
"Send an email to [you@example.com] inviting them to the Gemini 2.5 launch party this Sunday."

智能体会为你发送完全格式化的 HTML 邮件。

### 7. 自动将内容发布到 WordPress

使用 Gemini 智能体生成内容。
在 N8N 中添加 "Create Post" WordPress 模块。
Gemini 写入并自动以 HTML 格式发布内容。

### 8. 比较模型（可选）

- **Gemini 2.5** = 更好的编码、速度和推理
- **DeepSeek V3** = 更好的人类化写作
- **Claude** = 优秀的写作和设计（内置画布）

- **Make.com**：自动化 Google Sheets > Gemini > WordPress
- **OpenRouter.ai**：如果 Gemini 原生 API 不工作则使用它

### Bolt DIY 设置

**如何设置？**
1. 打开终端并克隆仓库：
   ```
   cd ~
   git clone https://github.com/coleam00/bolt.new-any-llm.git
   cd bolt.new-any-llm
   ```
2. 安装 PNPM（包管理器）：
   ```
   npm install -g pnpm
   ```
3. 安装项目依赖：
   ```
   pnpm install
   ```
4. 保存并退出 nano：
   - 按 Control + X
   - 按 Y 保存
   - 按 Enter
5. 启动开发服务器：
   ```
   pnpm run dev
   ```
6. 选择 Open Router > 选择 Gemini 2.5
