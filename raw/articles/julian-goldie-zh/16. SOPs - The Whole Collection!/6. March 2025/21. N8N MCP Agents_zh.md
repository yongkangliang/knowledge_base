本 SOP 将指导你设置 **N8N MCP 智能体**，使用 AI 自动化任务，连接多个服务（如 **Airbnb、Brave Search**），并执行实时网络搜索。

- 如何设置带 MCP 的**自托管 N8N**
- 如何集成 **Airbnb 和 Brave Search** 等工具

- 创建**公共 AI 驱动聊天机器人**

### 第一步：在 Elestio 上部署 N8N（需自托管）

1️⃣ 前往 **Elest.io** 并**登录**
2️⃣ 导航到 **Services** > **Create New Service**
3️⃣ 选择 **N8N** 并选择一个**位置**（例如，选择新加坡以使用 SGD 货币）
4️⃣ 点击 **Next**，选择 **Medium package**（推荐），然后继续
5️⃣ 完成设置，包括**添加信用卡**（但除非升级否则不会收费）
6️⃣ 部署完成后，复制你的 **CNAME URL**（自托管 N8N 工作区）

### 第二步：为 MCP 智能体配置 N8N

1️⃣ 进入 **N8N Settings** > **Community Nodes**
2️⃣ 安装 MCP 包：
   - 点击 **Install**
   - 输入：`n8n-nodes-mcp`
   - 再次点击 **Install**
3️⃣ **重启 N8N** 以应用更改

### 第三步：创建你的 AI 智能体工作流

1️⃣ 在 **N8N** 中创建**新工作流**：
   - 点击 **Create Workflow** > **Add Node**
   - 选择 **MCP Client**

2️⃣ 添加 **MCP List Available Tools**：
   - 为 MCP 服务器添加凭据（例如 Airbnb、Brave Search）
   - **Command：** `npx`
   - **Arguments：**
     ```sql
     -y @openbnb-org/mcp-server-airbnb --ignore-robots-txt
     ```
   - **Environment：** （Airbnb 留空；Brave Search 需要 API 密钥）

### 第四步：执行 MCP 工具（运行 AI 搜索）

1️⃣ 添加 **MCP Execute Tool Node**：
   - 设置 **Tool Name：**
     ```bash
     {{ $json.tools[0].name }}
     ```
   - 设置 **Parameters：**
     ```json
     { "location": "Manchester" }
     ```

2️⃣ 连接到 AI 智能体：
   - 添加 **ChatGPT/OpenAI** API 密钥
   - 将其链接到 **MCP 工具执行节点**

### 第五步：设置 Brave Search 以实现实时网络搜索

1️⃣ 前往 **Brave API 面板**：
   - 访问：Brave API
   - 生成**免费 API 密钥**

2️⃣ 在 N8N 中添加 Brave Search MCP 节点：
   - **Command：** `npx`
   - **Arguments：**
     ```sql
     -y @modelcontextprotocol/server-brave-search
     ```
   - **Environment：**
     ```ini
     BRAVE_API_KEY=你的密钥
     ```

3️⃣ 测试搜索查询：
   - 示例："Tell me about Gemini 3"
   - AI 将获取**最新网络搜索结果**（实时数据）

### 第六步：发布并自动化你的 AI 智能体

✅ **为公众使用激活 AI 聊天机器人：**
1️⃣ 进入 AI Agent Settings > **Activate Workflow**
2️⃣ 分享**公共聊天机器人链接**或**嵌入到你的网站**

### 🎯 你可以运行的示例 AI 查询

- "Find me a 2-bedroom apartment in Manchester"
- "Show me the best Airbnbs for New Year's Eve"
- "Search the web for the latest news on Gemini 3"
