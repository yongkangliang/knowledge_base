### 设置步骤

**第 1 步：**
```
git clone https://github.com/camel-ai/owl.git
cd owl
```

**第 2 步：**
```
pip install uv
```

**第 3 步：**
```
uv venv .venv --python=3.10
```

**第 4 步：**
```
source .venv/bin/activate
```

**第 5 步：**（Windows）
```
.venv\Scripts\activate
```

**第 6 步：**
```
python owl/webapp.py
```

**第 7 步：**
```
uv pip install -e .
```

**第 8 步：** 访问 http://127.0.0.1:7860/

**第 9 步：** 添加 API 密钥 > 点击保存
