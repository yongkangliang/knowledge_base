# 19. 全新中国 AI Ernie X1 & 4.5 击败 DeepSeek？

https://youtu.be/G1XKGu1DV7k

## SOP：如何访问和使用百度文心一言 Ernie X1 & Ernie 4.5 AI 模型

### 概述

百度发布了两个全新的 AI 模型：
- **Ernie X1** —— 深度推理模型，是 **DeepSeek R1** 的替代品，但**便宜 50%**。
- **Ernie 4.5** —— 更快的模型，是 **DeepSeek V3** 的替代品，价格仅为 **GPT-4.5 的 1%**。

两款模型均可**免费访问**，但设置过程可能有些棘手。以下是你的分步指南。

### 第一步：访问模型

1. 前往 **百度文心一言（Baidu Yiyan）**
2. 网站是**中文**的。点击**右上角的 Google Chrome 翻译按钮**进行翻译
3. 注册：
   - 你必须使用**电话号码**进行验证
   - 如果你是**国际用户**，注册时选择"**outsider**"选项
4. 登录后，前往**左上角菜单**并选择：
   - **X1**（深度推理）
   - **4.5**（速度和通用性能）

### 第二步：运行测试与基准测试

百度声称 **Ernie 4.5 在关键基准测试中表现优于 GPT-4.5 和 DeepSeek V3**。让我们来验证：

**测试 1：自玩蛇游戏（编码挑战）**

使用提示词：
```html
Create a self-playing snake game using HTML with a simple GUI.
```

比较以下模型的输出：
- Ernie X1
- Ernie 4.5
- DeepSeek R1 & V3
- ChatGPT-4.5

**结果：**
- DeepSeek R1 生成了最佳代码
- **Ernie X1 排名第二**，执行速度快
- Ernie 4.5 可用但较慢
- DeepSeek V3 生成了错误的输出

**测试 2：逻辑推理测试**

使用提示词：
```
There is a tree on the other side of the river in winter. How can I pick an apple?
```

期望答案：
- 认识到苹果**冬天不生长**
- 提供到达树的**创造性解决方案**

**结果：**
- **DeepSeek V3 获胜**，因为 Ernie 模型未能生成任何有意义的回复
- Ernie X1 和 4.5 在逻辑推理方面遇到困难

### 第三步：比较 API 定价

| 模型 | 定价 |
|------|------|
| GPT-4.5 API | $75 / 百万令牌 |
| Ernie X1 API | $0.28 / 百万令牌（比 DeepSeek R1 便宜 50%） |
| Ernie 4.5 API | GPT-4.5 成本的 1% |

如果你需要**负担得起的 AI API**，**Ernie 是最便宜的选择**。

### 第四步：开源计划与限制

- 百度**计划在 2025 年 6 月 30 日**将这些模型开源
- 目前**未在 OpenRouter 或 LLaMA 上提供**用于本地托管
- **DeepSeek 模型**更容易访问和开源

### 第五步：最终推荐

| 特性 | Ernie X1 | Ernie 4.5 | DeepSeek R1 | DeepSeek V3 | GPT-4.5 |
|------|----------|-----------|-------------|-------------|---------|
| **最佳用途** | 深度推理 | 快速回复 | 代码最佳 | SEO & 写作 | 最准确 |
| **性能** | 良好（较慢） | 快但不稳定 | 快且代码最佳 | 平均 | 优秀 |
| **定价** | 💰 比 DeepSeek R1 便宜 50% | 💰 GPT-4.5 的 1% | $$$ | $$ | $$$$$ |
| **可用性** | 难访问 | 难访问 | 容易（开源） | 容易 | 容易 |

**结论：**
- **编码方面：** DeepSeek R1 胜出
- **推理方面：** DeepSeek V3 比 Ernie 更好
- **定价方面：** Ernie 4.5 最便宜
- **可访问性方面：** DeepSeek 模型更容易使用

👉 如果你需要**免费 AI**，Ernie**值得尝试**，但它仍然**不稳定且难以访问**。
