# 17. Firebase Studio Gemini 2.5 Pro 更新

## 标准操作流程（SOP）：使用 Firebase Studio 中的 Gemini 2.5 Pro 构建无代码 AI 应用

欢迎使用简化版的分步指南，教你使用 Firebase Studio 中免费的 Gemini 2.5 Pro 工具创建 AI 驱动的应用！

### 第 1 步：访问 Firebase Studio

前往 firebase.studio
如有需要，使用你的 Google 账户登录

### 第 2 步：了解它的功能

你只需一条提示词就可以构建完全可用的应用
不需要编码技能
它支持多个框架：Go、Python Flask、Java、.NET、Android Studio、Flutter 等

### 第 3 步：获取应用创意

打开 ChatGPT 并问：
"给我一个 [你的利基市场] 业务的 3 个有趣且快速构建的应用创意。"

示例：
- 金融仪表板
- SEO ROI 计算器
- SEO 烤机生成器
- 问答游戏

### 第 4 步：编写你的提示词

按以下方式写出你的应用创意：
"构建一个小费计算器来帮助计算与朋友账单的小费。使用粉色和紫色配色方案。"
包括它应该做什么
添加样式或功能（可选）

### 第 5 步：生成应用

将你的提示词粘贴到 Firebase Studio
点击 "Prototype This App"
等待工具创建你的蓝图和代码

### 第 6 步：添加你的免费 Gemini API 密钥

前往 astudio.google.com
生成一个 API 密钥（100% 免费）
复制并粘贴到 Firebase Studio 中当被提示时

### 第 7 步：测试和调整

尝试使用你的应用：输入值看它是否工作
如果 UI 或功能不够完美：
使用 "Fix Error" 或调整生成的代码
点击 UI 元素更改文本或样式（"vibe code"）

### 第 8 步：分享你的应用

点击 "Copy Link" 或 "Make Preview Public"
与应用链接分享给朋友、团队或测试者

### 可选：与付费工具比较

尝试在 Bolt.new 或 Loveable.dev 中使用相同的提示词
Firebase 在这些工具中通常表现更好，而且是免费的

### 最终提示

- 免费版最多允许 10 个工作区——如果需要，删除旧的工作区
- 不要依赖 AI 生成的数据用于关键应用（插入你自己的数据集）
- 非常适合团队培训、原型设计和内部工具
