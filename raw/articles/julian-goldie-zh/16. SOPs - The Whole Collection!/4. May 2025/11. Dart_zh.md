### 使用 Dart AI 的分步 SOP

#### 1. 为什么要使用 Dart AI？

不仅仅是像 Trello 或 Notion 那样组织任务，Dart AI 实际上使用 AI 来：
- 从简单想法生成项目需求
- 检测重复任务
- 将大项目分解为较小步骤
- 可以自主完成任务

#### 2. 注册并开始使用

前往 👉 itsdart.com
点击 "Sign Up For Free"
使用 Google 或任何邮箱注册
登录后，浏览主页面板：
- 显示分配给你的任务
- 即将到期的截止日期
- AI 驱动的性能报告

#### 3. 创建空间并组织项目

点击 "Spaces" 旁边的 +
设置你的空间：
- 选择图标和缩写
- 添加描述
- 启用/禁用冲刺
- 安排自动生成的每日站会和变更日志
- 与团队共享空间或保持私密

在每个空间内：
- 添加 Dart 看板来组织阶段
- 添加 Doc 文件夹存放信息/文档

#### 4. 创建 AI 驱动的任务

点击空间内的 "Tasks" 标签
点击 "Create New Task"
输入你的提示词（例如"为产品发布创建数字营销计划"）
为任务命名
启用 Task AI 功能：
- 分解为子任务
- 改进描述
- Do this task for me（让 AI 完成它）
点击 "Create Task"
Dart 将自动开始工作——查看结果！

#### 5. 使用高级 AI 功能

点击 "Project AI" 用于：
- 头脑风暴任务
- 生成报告
- 工作区分析：查看已完成、待定和总体进度
- 多种任务视图：看板、列表、瀑布

#### 6. 与其他工具集成

前往 设置 > 集成 并连接：
- ChatGPT
- Claude
- Notion
- Slack
- Discord
- GitHub

示例：
- GitHub 更新 > 自动更新任务
- 通知自动发送到 Discord
