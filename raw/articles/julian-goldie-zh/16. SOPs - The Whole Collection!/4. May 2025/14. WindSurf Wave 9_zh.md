### Windsurf 是什么？

Windsurf 是一个 AI 驱动的应用开发平台，让你可以：
- 使用多种 AI 模型（如 Claude、GPT-4、Gemini、DeepSeek）编码应用
- 通过 Netlify 一键部署前端应用
- 在一个干净、无多余功能的界面中工作
- 无需自己的 API 密钥——全部预集成

### 使用 Windsurf 的分步 SOP

#### 1. 访问 Windsurf

前往：https://codium.com
登录或创建账户。

#### 2. 开始新项目

点击 "New Folder" 或 "New Project"。
给它起个名字，如 todo-app、seo-calculator 等。
Windsurf 将自动为你创建项目环境。

#### 3. 使用聊天生成代码

在聊天中输入你想构建的内容：
```
Create a simple to-do list app using React.
```
选择你的 AI 模型（Claude、GPT-4、Gemini 等）。
Windsurf 将为你的项目生成代码。

#### 4. 运行和预览应用

接受代码建议。
使用内置终端运行应用。
点击 "Open Preview" 实时查看你的应用。

#### 5. 部署你的应用

输入：
```
Deploy my app.
```
Windsurf 将连接到 Netlify 并处理部署。
立即获得一个实时子域名（如 yourapp.wi.build）。

#### 6. 编辑并重新部署

编辑代码、样式或逻辑。
点击 "Redeploy" 将更改推送到线上。
你可以在本地开发环境或实时 URL 上预览更新。

#### 7. 使用附加功能

- 一键生成提交信息
- 访问基于记忆的设置（如保存的颜色方案）
- 处理更长对话 + Jupyter 笔记本支持
- 多应用窗口 = 并行构建/测试
