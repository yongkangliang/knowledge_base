## 如何设置和使用 Claude MCP 超级代理（无需技术技能！）

欢迎使用终极快速参考指南，教你将 Claude 变成一个连接数千个应用的超级代理 AI。如果你曾梦想过通过 AI 运行你的业务、日历、电子邮件、社交媒体等——那么你要走运了。以下是分步入门指南！

### Claude MCP 是什么？

MCP（模块化能力提供商）是 Anthropic 推出的一个新系统，让 Claude 可以访问和使用其他应用——如 PayPal、Google Calendar、WordPress 等。就像 ChatGPT 的插件，但容易得多、快得多。

### 分步设置

#### 第 1 步：升级到 Claude Max 计划

前往 Claude 设置。
确保你使用的是 Max 计划（约 $150/月，首月通常有折扣）。
这解锁了 Claude Research + 自定义集成。

#### 第 2 步：通过 Zapier MCP 创建 MCP 服务器

前往 Zapier MCP。
点击 "Create new MCP server"。
选择 Claude 作为客户端。
为你的服务器命名并点击 "Create"。

#### 第 3 步：连接你的第一个工具（例如 PayPal）

在 Zapier MCP 中搜索 "PayPal"。
添加 https://mcp.paypal.com 作为集成 URL。
回到 Claude → 设置 → 个人资料 → 添加集成 URL。
点击 "Connect" 并登录 PayPal。
就是这样——你现在可以直接在 Claude 中创建 PayPal 发票！

#### 第 4 步：连接 Google Calendar（或任何其他工具）

在 Zapier MCP 中，添加 Google Calendar。
授权你的账户。
回到 Claude，点击 ⚙️ 并打开 "Google Calendar"。
尝试一个提示词如：
→ "为周日下午 5 点创建一个日历事件：'MCP 派对与 Vic'"

#### 第 5 步：将 Claude 变成个人助理

尝试这个提示词：
"查看我的日历周日的安排，总结即将到来的事件，获取曼彻斯特的天气，并通过电子邮件发送我每日简报。"
确保 Gmail、Google Calendar 和 Web Search 在 Claude 中已启用。

#### 第 6 步：内容创作管道（WordPress + 社交媒体）

在 Zapier MCP 中，连接 WordPress + Facebook Pages。
尝试一个提示词如：
→ "创建一篇关于'Gemini 2.5 Ultra 泄露'的 SEO 优化文章并发布到 WordPress。然后为 Facebook 创建一个简短的社交媒体帖子。"
（注意：WordPress 集成可能需要调试；不是所有帖子都会自动上线——可能需要复制/粘贴。）

#### 第 7 步：使用 Google Docs 进行研究报道

启用 Google Docs 集成。
尝试：
→ "研究 AI 代理的最新更新。创建一个 Google Docs 报告并发给我链接。"
完美适用于创建文档、打包清单等。

#### 第 8 步：在 Claude 中使用 DALL·E 生成图像

在 Zapier MCP 中，添加 DALL·E（通过 OpenRouter 或类似图像工具）。
提示 Claude：
→ "使用 DALL·E 生成一张猫的图像。"
完成！你会在 Claude 内部收到一个图像 URL。

### 附加提示

当你向 Zapier MCP 添加新工具时，在 Claude 中断开并重新连接以刷新。
你可以将一个 MCP 服务器内的多个工具堆叠在一起（如 Gmail + Calendar + Docs）。
跨浏览器 + 桌面版同步。
