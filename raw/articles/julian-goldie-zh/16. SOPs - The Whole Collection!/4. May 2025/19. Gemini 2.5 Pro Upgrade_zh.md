# 19. Gemini 2.5 Pro 升级

## 标准操作流程（SOP）：如何使用 Google Gemini 2.5 Pro 在几分钟内编码 AI 工具

### 第 1 步：免费获取 Google Gemini 2.5 Pro 的访问权限

前往 Google AI Studio
从右上角菜单中选择 Gemini 2.5 Pro Preview。
你不需要输入信用卡详情（它是免费的，有使用限制）。
附加：你也可以通过 Gemini Advanced 或 Canvas 访问 Gemini 以获得更好的视觉体验。

### 第 2 步：设置编码（多种构建方式）

选择你的工具：
**选项 A：AI Studio（推荐最简单）**
开始一个新的聊天。
选择 Gemini 2.5 Pro。
输入你的提示词（例如，"用 HTML 构建一个 CRM 仪表板"）。
点击运行。

**选项 B：Visual Studio Code**
在 AI Studio 中创建一个 API 密钥。
使用 0325 模型获取最新的 Gemini Pro 版本。
通过 Klein 扩展将密钥插入 Visual Studio Code。
开始编码和测试结果。

**选项 C：Bolt DIY**
使用 CLI 在本地设置。
从 OpenRouter 获取 API 密钥。
选择 Gemini 2.5 Pro Preview。
开始编码（例如，"构建一个 SEO 计算器"）。

### 第 3 步：尝试这些示例项目

只用一条提示词且几乎不需要编码技能你就能构建什么：
- ✅ CRM 仪表板（简单 HTML + Canvas）
- ✅ 罗马市场游戏（3JS，互动模拟）
- ✅ AI 关键词研究工具（API 驱动）
- ✅ SEO 跑步游戏（为营销人员设计的游戏化学习）
- ✅ 化学游戏、花园规划器、书籍寻找器（来自 Google 演示）

### 第 4 步：测试和改进输出

如果某些东西不起作用，总是在聊天中给予反馈。
示例："让标签可点击" 或 "在市场摊位添加更多细节"。
使用 Canvas 进行视觉测试或使用 LiveWeave 快速预览 HTML 输出。

### 第 5 步：比较性能（可选）

在 Claude 和 Gemini 中运行相同的提示词来比较速度和输出质量。
来自视频的判断：Gemini 明显更好更快，特别是在编码方面。

### 第 6 步：探索附加工具

- NA10：用于代理创建和自动化工作流（Google API 免费）
- Windsurf：新版本可用，但在此测试中不稳定
- AI 利润董事会：获取完整模板、工作流和专业工具访问

### 最后 thoughts

你不需要编码技能。只需提示、调整、构建。Gemini 2.5 Pro 速度极快、免费可用、对开发者和营销人员都很强大。
