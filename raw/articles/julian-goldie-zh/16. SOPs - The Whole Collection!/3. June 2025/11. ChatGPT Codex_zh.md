🧠 Codex 是什么？

Codex 是一款**基于云的 AI 代理**，专为**软件工程任务**设计。它可以：

- 编写功能
- 修复 Bug
- 提出拉取请求
- 回答有关代码库的问题

它不是用来替代 Cursor 或 Windsurf 这类工具的，而更像是一个智能的、基于云的编码合作伙伴。

✅ 逐步 SOP：如何使用 Codex

1. 访问 Codex

- 首先面向 ChatGPT Pro、Enterprise 和 Team 用户开放
- Plus 和教育用户将稍后获得访问权限

2. 与 GitHub 集成

- 链接一个 GitHub 仓库
- 选择要工作的分支
- 你将能够：
  - 查看开放/已合并的 PR
  - 检查 diff 和变更
  - 使用**自然语言**与 Codex 交互

3. 分配任务

- 输入提示词，然后点击 **"Code"**
- 或者直接**询问**关于你的代码库的**问题**
- 每个任务在隔离环境中运行，预加载了所需依赖
- 包含对你的代码库、环境变量、终端、测试套件的访问权限

4. 任务执行

- Codex 读取并编辑文件
- 可以运行终端命令和测试
- 任务可能需要 **1-30 分钟**
- 可以**并行运行多个任务**

5. 审查与验证

- Codex 直接提交变更
- 它提供：
  - 终端日志
  - 测试结果
- 你将能够**验证工作成果**，就像在 Cursor 等工具中一样

6. 打开拉取请求

- Codex 可以直接打开 PR
- 对于"AI 写代码，开发者做代码审查"的团队特别有用

7. 使用 agents.md 自定义行为

- 在你的仓库的**根目录**放置一个 agents.md 文件
- 用它来：
  - 定义项目规则
  - 指定测试命令
  - 指导 Codex 了解代码结构和最佳实践

8. 性能洞察

- Codex 1 基于 OpenAI 的 03 模型
- 使用真实编码任务进行 RL 训练
- 在 SweetBench 基准测试中表现优异
- 特别适用于**减少尝试次数**的场景

9. 移动端访问

- Codex 可通过 **ChatGPT 应用**访问
- 非常适合随时快速修复或调试
