### 概述

Gemini CLI 是一个免费的开源 AI 编程助手，可直接在你的终端中运行。它可以编写代码、自动化任务、操作本地文件，甚至生成演示文稿或 Web 应用——全部使用自然语言完成。

### 分步安装说明

**1. 安装 Node.js v18+**

你需要安装 Node.js 版本 18 或更高版本。在此下载：https://nodejs.org/en

**2. 安装 Gemini CLI**

打开终端并粘贴以下命令：

```bash
npx @google/gemini-cli@latest
```

💡 这将在你的机器上全局安装 Gemini CLI。

**3. 认证你的账号**

你可以使用以下方式登录：
- Google 账号（推荐）
- Google AI Studio 的 API 密钥（https://aistudio.google.com/app ）

你将获得：
✅ 每天 1000 次请求
✅ 每分钟 60 次请求
✅ 免费使用

**4. 选择主题**

按提示选择你喜欢的主题（例如 Dracula、Default）。

### 测试与使用 Gemini CLI

✅ 试试这些简单命令：
- `gemini new`：创建一个新项目
- `gemini summarize`：总结最近的 GitHub 变更
- `gemini describe`：描述你的系统架构
- `gemini write`：构建机器人、Web 应用或其他任何内容
- `gemini convert`：转换本地文件（例如 PNG、PDF）

### 示例项目

✨ 从 GitHub 构建幻灯片演示文稿
```bash
gemini describe git history from last 7 days and create a slide deck
```

🎯 用 HTML 创建一个 ROI 计算器
```bash
gemini code ROI calculator web app in HTML
```

🎨 改进 UI 设计
```bash
make UI more beautiful with rainbow colors and dopamine-inducing layout
```

### 🛠️ 故障排除

| 问题 | 解决方案 |
|------|----------|
| Gemini CLI 切换到 Flash | Pro API 过载。等待或重启 CLI |
| App 崩溃 | 按 Ctrl+C 取消请求并重启 |
| 响应太慢 | Flash 更快但功能较弱。考虑等待 Pro |
| HTML/UI 效果不好 | 让 Gemini "改进 UI" 或 "添加动画/颜色" |
