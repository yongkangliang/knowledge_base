# 2. AI 自动回复草稿 — 自动撰写邮件回复

AI Auto-Responder Draft Replies incoming emails
👉
 
[在此免费试用 N8N](https://www.skopeo.io/)（推荐链接）
此流程会在 Gmail 中自动生成回复草稿。
适用于管理大量邮件或经常面临写作障碍的用户。
由于它不会直接发送生成的消息，你仍然可以在邮件发出之前编辑和审批。

## 工作原理

**Email Trigger（邮件触发器）**：当新邮件到达 Gmail 收件箱时激活。

**Assessment（评估）**：使用 OpenAI gpt-4o 和 JSON 解析器判断是否需要回复。

**Reply Generation（生成回复）**：由 OpenAI GPT-4 Turbo 撰写回复。

**Draft Integration（草稿集成）**：将文本转换为 HTML 后，以回复首条消息的形式将草稿放入 Gmail 线程中。

## 设置概览（约 10 分钟）

**OAuth 配置**（[参考此处 n8n 说明](https://docs.n8n.io/integrations/builtin/credentials/google/)）：
- 在 Google Cloud Console 中设置 Google OAuth。确保添加 Gmail API 的 modify 权限范围。
- 在 n8n 中添加 Google OAuth 凭据。确保将 n8n 重定向 URI 添加到 Google Cloud Console 的同意屏幕设置中。

**OpenAI 配置**：在凭据中添加 OpenAI API Key。

**调整提示词**：编辑"Generate email reply"节点中的系统提示词以满足你的需求。
