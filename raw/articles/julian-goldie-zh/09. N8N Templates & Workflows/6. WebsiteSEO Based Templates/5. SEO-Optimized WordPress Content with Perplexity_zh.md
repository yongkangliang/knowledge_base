## 利用 Perplexity Research 生成 SEO 优化的 WordPress 内容

### 适用人群

此 workflow 适合希望精简 WordPress SEO-optimized 博客文章创作流程的内容创作者、营销人员和企业主。尤其适合 AI 咨询和工作流自动化行业的专业人士。

### 解决的问题

创建高质量、SEO-friendly 的博客文章可能既耗时又充满挑战，尤其是需要在研究、格式化和发布之间取得平衡。此 workflow 整合了研究能力、AI 驱动的内容创作和无缝的 WordPress 发布流程，实现了自动化。它在减少人工操作的同时，确保输出达到专业水准。

### Workflow 功能

**研究：**
基于用户提供的查询，从 Perplexity AI 收集详细见解。

**内容生成：**
使用 OpenAI models 创建结构化的博客文章，包括标题、slug、meta description 和针对 WordPress 优化的 HTML content。

**图片处理：**
自动获取图片并上传为 WordPress 文章的 featured image。

**发布：**
直接在 WordPress 中起草博客文章，包含所有必要的格式化和 metadata。

**通知：**
完成后通过 Telegram 发送成功消息。

### 设置指南

**前提条件：**

- 具有 API 访问权限的 WordPress 账户
- OpenAI API 凭据
- Perplexity AI API 凭据
- 用于通知的 Telegram bot 凭据

**步骤：**

1. 在 n8n 实例中导入此 workflow
2. 配置 WordPress、OpenAI、Perplexity AI 和 Telegram 的 API 凭据
3. 自定义 Form Trigger 中的表单以定义研究查询
4. 使用示例查询测试 workflow，确保顺利执行

### 如何自定义

- 在 Form Trigger node 中修改研究查询 prompt，使其适配你的行业或细分领域
- 在 Copywriter AI Agent node 中调整内容生成指南，以满足特定的格式偏好
- 在 Set Image URL node 中替换图片 URL，使用你自己的图片来源或动态图片选择逻辑
