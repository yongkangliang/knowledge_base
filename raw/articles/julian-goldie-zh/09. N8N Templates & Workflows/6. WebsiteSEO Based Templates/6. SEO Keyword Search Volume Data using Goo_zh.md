# 6. 利用 Google API 获取 SEO 关键词搜索量数据

SEO Keyword Search Volume Data —— 使用 Google API
👉
 
在此获取 N8N 免费试用（affiliate 链接）

### 应用场景

为 SEO keyword research 生成准确的搜索量数据：

- 你有一份潜在关键词列表想要 targeting，但不知道它们的实际 search volume
- 你需要历史数据来识别关键词流行度的 seasonal trends
- 你想评估 keyword difficulty 以 prioritise 你的 content strategy
- 你需要 data-driven insights 来规划你的 SEO campaigns

### Workflow 功能

此 workflow 连接到 Google Keyword Planner API，为你的 SEO research 检索 keyword metrics：

- 获取每个 keyword 的 monthly search volume
- 提供过去 12 个月的 historical trends 数据
- 计算 keyword difficulty scores
- 交付来自 Google Ads 的 competition metrics

### 设置

1. 在 Set 20 Keywords 节点中填入最多 20 个你想要的关键词，格式为 array，例如：["keyword 1", "keyword 2", ...]
2. 创建 Google Ads API 账户，并将凭据添加到 Get Search Data node
3. 将 Connect to your own database 替换为你自己的数据库作为输出

### 如何调整

- 将 Set 20 Keywords 节点的输入源更改为你选择的来源，例如包含 20 个关键词的 Airtable database
- 连接到你选择的 output source
