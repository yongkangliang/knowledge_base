此 workflow 自动化创建完整 SEO-optimized blog post 的流程，包括生成内容、标题、图片和 meta tags，并发布到 WordPress。它利用 AI models（如 DeepSeek 和 OpenRouter）进行内容生成和 SEO 优化，并集成 Google Sheets、WordPress 和 OpenAI 进行图片生成。

这是一个强大的工具，可自动化博客文章的创建和优化，节省时间并确保高质量的 SEO-friendly 内容。它整合了多个工具和 AI models，带来无缝的内容创作体验。

以下为此 workflow 的详细拆解：

## 1. 工作原理

此 workflow 旨在简化 SEO-friendly 博客文章的创建流程，具体如下：

**触发：** 由 Manual Trigger node 启动 workflow，用户点击 "Test workflow" 时触发流程。

**获取上下文：** Google Sheets node 从预定义的 Google Sheet 中检索博客文章上下文（如主题、关键词）。

**生成内容：**

- Generate Article node 使用 AI model（DeepSeek）根据获取的上下文创建 SEO-friendly 博客文章。
- Generate Title node 为博客文章生成一个引人入胜、富含关键词的标题。

**发布到 WordPress：**

- Add Draft to WP node 使用生成的内容和标题在 WordPress 中创建草稿文章。

**生成并上传图片：**

- Generate Image node 使用 OpenAI 创建真实的、适合博客的图片。
- Upload Image node 将图片上传至 WordPress 媒体库。
- Set Image node 将上传的图片设为博客文章的 featured image。

**SEO 优化：**

- SEO Expert node 分析博客文章，并使用 AI model（OpenRouter）生成优化后的 meta title 和 description。
- Set Metatag node 使用生成的 meta tags 更新 WordPress 文章。

**更新 Google Sheets：**

- Update Sheet 和 Finish Work node 用文章详情（包括 URL、标题和 metadata）更新 Google Sheet。

## 2. 设置步骤

要在 n8n 中设置和使用此 workflow，请按照以下步骤操作：

**Google Sheets 设置：**

创建一个 Google Sheet，包含以下列：ID POST、PROMPT、TITLE、URL、METATITLE 和 METADESCRIPTION。

通过提供 Document ID 和 Sheet Name 将 Google Sheet 连接到 Get Context node。

**WordPress 集成：**

在 n8n 中为 Add Draft to WP、Upload Image 和 Set Image nodes 设置 WordPress 凭据。

确保 WordPress 站点可通过 REST API 访问。

**AI Model 配置：**

在 n8n 中配置 DeepSeek 和 OpenRouter 凭据，用于 Generate Article、Generate Title 和 SEO Expert nodes。

确保 AI models 正确设置以生成内容和 meta tags。

**图片生成：**

为 Generate Image node 设置 OpenAI 凭据，以创建博客文章配图。

**Meta Tag 优化：**

SEO Expert node 使用 OpenRouter 生成 meta title 和 description，确保该 node 配置为分析博客文章内容并输出 SEO-friendly 的 tags。

**Workflow 执行：**

点击 "Test workflow" 按钮触发 workflow。

流程将执行以下操作：

- 从 Google Sheets 获取博客文章上下文
- 生成文章、标题和图片
- 将草稿发布到 WordPress
- 上传并设置 featured image
- 生成并应用 meta tags
- 用文章详情更新 Google Sheet

**可选自定义：**

可修改 workflow 以包含额外 SEO 优化，如内链、关键词密度分析或社交媒体分享。
