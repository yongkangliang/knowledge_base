# 01. 从文档/图片中解析和提取数据

Mistral OCR 是一种利用 AI 从多页 PDF 或单张图片中解析和提取数据的便捷方式。

它的独特之处在于与竞品不同的是，Mistral OCR 还能执行文档页面拆分和 Markdown 转换。这有助于减少文档解析工作流中对 StirlingPDF 等工具的依赖。

在此阅读 Mistral OCR API 的官方文档：
https://docs.mistral.ai/capabilities/document/#tag/ocr/operation/ocr_v1_ocr_post

## 工作原理

要访问 Mistral-OCR，你需要通过 HTTP request 节点使用 Mistral Cloud API。

Mistral OCR 仅接受两种文件格式：PDF 和图片。这里我们使用两个不同的 request 向 Mistral-OCR API 发送请求，分别解析银行账户对账单 PDF 和银行账户对账单截图以提取表格。

接下来，我们探索一种更安全的上传文档到 Mistral OCR API 的方法——使用 Mistral 的云存储。在示例 2 中，我们首先将文档副本存储到 Mistral 云端，然后生成一个签名 URL 来取回文件，再将其发送到 Mistral OCR。这确保了文件不会被公开访问，从而保护其免受未授权访问。

最后，另一种使用 Mistral-OCR 的方式是通过文档理解（document understanding）。你可以向文档提问而不是从中提取内容。在示例 3 中，我展示了这一用例：向 Mistral-small 提问，让它告诉我银行账户对账单中显示了多少笔存款。

## 使用方法

确保你的文档要么可以通过公共访问供 Mistral-OCR 使用，要么上传到 Mistral 云端。另外，AWS S3 或 Cloudflare R2 的签名 URL 也可以正常工作。

## 需求

- Mistral Cloud 账号和 API Key。你的账户中还需要有余额才能使用 Mistral-OCR。

## 自定义工作流
