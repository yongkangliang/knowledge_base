## 此模板适合谁

- Web developers
- SEO specialists
- Digital marketers

## 此工作流解决了什么问题？

- 自动化从网页中提取内部链接（internal links）
- 消除手动收集链接的繁琐和易出错过程
- 促进网站结构分析和优化

## 此工作流的功能

- 使用 HTTP request 节点从指定网页获取 HTML 内容
- 解析 HTML 以识别和提取内部链接
- 编译指向同一域内页面的 URL 列表

## 设置

配置 Set Base URL 节点：
- 在 url 字段中设置你要分析的 URL（analyze）。

## 如何根据你的需求自定义此工作流

- 在 Set Base URL 节点中更改目标 URL 以分析（analyze）不同的网页。
- 添加节点以：
  - 过滤或分类提取的链接
  - 将列表导出到数据库或 CSV
  - 通过电子邮件发送链接或与其他工具集成

此工作流可以作为用于管理内部链接提取过程的工作流的基础，帮助进行网站优化和 SEO 工作。
