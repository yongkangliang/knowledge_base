# 09. 通过 Upwork 自动化求职

## 工作流概述

这个前沿的 n8n 自动化是一个 sophisticated 的工作发现和通知工具，旨在将自由职业求职转化为一个无缝、智能的流程。通过智能连接 Apify、OpenAI、Google Sheets 和 Gmail，此工作流实现：

### 发现工作机会

- 自动爬取 Upwork 的工作列表
- 跟踪最新的自由职业机会
- 消除手动搜索工作的精力消耗

### 智能数据处理

- 过滤和提取关键工作细节
- 结构化工作信息
- 确保全面的机会跟踪

### AI 驱动摘要

- 生成简洁的工作摘要
- 创建易读的工作摘要
- 提供快速、可操作的见解

### 无缝通知

- 自动将工作记录到 Google Sheets
- 发送个性化邮件摘要
- 实现对机会的快速评估

## 核心优势

- 🤖 **全自动：** 零人工的工作发现
- 💡 **智能过滤：** 定向的工作机会
- 📊 **全面跟踪：** 详细的市场洞察
- 🌐 **多平台同步：** 无缝的数据流

## 工作流架构

### 🔹 阶段 1：工作发现

- **定时触发器：** 每日扫描工作
- **Apify 集成：** Upwork 工作爬取
- **智能过滤：**
  - 最近发布的工作
  - 特定关键字
  - 相关机会

### 🔹 阶段 2：数据提取

- 全面的工作元数据解析
- 关键信息获取
- 结构化数据准备

### 🔹 阶段 3：AI 摘要

- OpenAI GPT 处理
- 专业摘要生成
- 上下文化的工作洞察

### 🔹 阶段 4：多平台分发

- Google Sheets 记录
- Gmail 集成
- 自动工作摘要发送

## 潜在用例

- **Freelancers：** 机会跟踪
- **Job Seekers：** 自动化工作发现
- **Recruitment Agencies：** 市场情报
- **Skill Development Professionals：** 趋势监控
- **Career Coaches：** 客户机会识别

## 设置需求

**Apify**
- Upwork 爬取 actor
- API token
- 配置的爬取参数

**OpenAI API**
- GPT 模型访问
- 摘要配置
- API key 管理

**Google Sheets**
- 连接的 Google 账号
- 准备好的工作跟踪电子表格
- 适当的共享设置

**Gmail 账号**
- 连接的邮箱
- 工作摘要配置
- 适当的发送权限

**n8n 安装**
- 云或自托管实例
- 工作流配置
- API 凭据管理
