# 2. AI 驱动的短视频生成器

👉
在此获取 N8N 免费试用（aff 链接）

**适合谁？**
面向希望自动化制作 TikTok、YouTube Shorts 和 Instagram Reels 等平台的短视频的内容创作者、数字营销人员和社交媒体经理，无需丰富的视频剪辑技能。

**此工作流解决什么问题？**
持续制作吸引人的短视频既耗时又需要多种工具和技能。此工作流自动化从创意构思到发布的全部流程，大幅减少人工操作的同时保持内容质量。

**此工作流的功能**
这个一站式方案通过 5 步流程将创意转化为完整的短视频：

1. 从 Google Sheet 中存储的创意生成视频文案（captions）
2. 使用 Flux 和 OpenAI API 生成 AI 图像
3. 使用 Kling 的 API 将图像转换为视频
4. 使用 ElevenLabs 为你的内容添加配音
5. 使用 Creatomate 完成视频制作 —— 添加模板、转场并合成所有元素

工作流处理从获取创意到渲染最终视频的一切事务，并在视频准备好时通过 Discord 通知你。

**设置（预计时间：20-30 分钟）**

开始前你需要：
- n8n 安装（已在 1.81.4 版本测试）
- OpenAI API Key（可免费试用）
- PiAPI（可免费试用）
- Eleven Labs（免费账户）
- Creatomate API Key（可免费试用）
- 在 Google Cloud Console 中启用 Google Sheets API
- 在 Google Cloud Console 中启用 Google Drive API
- 从 Google Cloud Console Credentials 获取 OAuth 2.0 Client ID 和 Client Secret

**如何自定义此工作流以满足你的需求**
- 调整 Google Sheet 结构以包含更多数据，如视频时长、风格等
- 修改每个 AI 服务的提示词模板以匹配你的品牌语气和内容风格
- 更新 Creatomate 模板以反映你的视觉品牌
- 配置 Discord 通知偏好以管理工作流

此工作流整合了多种 AI 技术，打造无缝的内容生产流水线，每支视频可节省数小时工作量，让你专注于策略而非制作。
