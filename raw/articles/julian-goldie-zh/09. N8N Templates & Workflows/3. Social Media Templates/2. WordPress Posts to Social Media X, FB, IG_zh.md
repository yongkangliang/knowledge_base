## N8N Workflow 描述：从内容创意创建社交媒体帖子

此 workflow 自动化根据 WordPress 帖子在多个平台（Twitter/X、Facebook、LinkedIn 和 Instagram）上创建并发布社交媒体帖子的过程。它使用 AI 模型生成平台特定的文案和图片，并与 Google Sheets、WordPress 以及各种社交媒体 API 集成。

这是一个强大的工具，用于自动化社交媒体帖子的创建和发布，节省时间并确保跨多个渠道的一致性、平台优化的内容。

## 1. 工作原理

此 workflow 旨在简化社交媒体帖子的创建和发布流程。以下是其工作原理：

### 触发器（Trigger）

**Manual Trigger node**：当用户点击"Test workflow"时启动流程。

### 获取数据（Fetch Data）

**Google Sheets node**：从预定义的 Google Sheet 中检索 WordPress Post ID。

**Get Post node**：使用检索到的 Post ID 获取对应的 WordPress 帖子内容。

### 生成社交媒体内容（Generate Social Media Content）

**Social Media Manager node**：使用 AI 模型（OpenRouter）分析 WordPress 帖子，并为 Twitter/X、Facebook、LinkedIn 和 Instagram 生成平台特定的文案。

AI 确保每条文案都针对该平台受众的受众、语气和风格进行了定制，包括标签和号召性用语（call to action）。

### 生成图片（Generate Images）

**Image Instagram** 和 **Image Facebook e Linkedin nodes**：使用 OpenAI 为 Instagram、Facebook 和 LinkedIn 帖子生成平台特定的图片。

### 发布到社交媒体（Publish on Social Media）

workflow 在各平台上发布生成的内容和图片：

- **Publish on X**：在 Twitter/X 上发布文案。
- **Publish on LinkedIn**：在 LinkedIn 上发布文案和图片。
- **Publish on Facebook**：在 Facebook 上发布文案和图片。
- **Publish on Instagram**：在 Instagram 上发布文案和图片。

### 更新 Google Sheets（Update Google Sheets）

workflow 更新 Google Sheet，标记帖子已发布（例如："X OK"、"Facebook OK"、"LinkedIn OK"、"Instagram OK"）。

## 2. 设置步骤

要在 n8n 中设置和使用此 workflow，请按以下步骤操作：

### Google Sheets 设置

- 创建（或克隆）一个 Google Sheet，包含 POST ID、TEXT、TWITTER、FACEBOOK、INSTAGRAM 和 LINKEDIN 列。
- 通过提供 Document ID 和 Sheet Name，将 Google Sheet 连接到 Google Sheets node。

### WordPress 集成

- 在 n8n 中为 Get Post node 设置 WordPress 凭证。
- 确保 WordPress 站点可通过其 REST API 访问。

### AI 模型配置

- 在 n8n 中配置 OpenRouter credentials 用于 Social Media Manager node。
- 确保 AI 模型已设置以生成平台特定的文案。

### 图像生成

- 为 Image Instagram 和 Image Facebook e Linkedin nodes 设置 OpenAI credentials 以生成图片。

### 社交媒体 API 集成

- 为每个社交平台设置凭证：
  - **Twitter/X**：使用 Twitter OAuth2 credentials 配置 Publish on X node。
  - **LinkedIn**：使用 LinkedIn OAuth2 credentials 配置 Publish on LinkedIn node。
  - **Facebook**：使用 Facebook Graph API credentials 配置 Publish on Facebook 和 Publish on Instagram nodes。

### 测试 Workflow

- 在 n8n 中点击"Test workflow"按钮触发 workflow。
- workflow 将执行：
  - 获取 WordPress 帖子内容
  - 生成平台特定的文案和图片
  - 在 Twitter/X、Facebook、LinkedIn 和 Instagram 上发布帖子
  - 更新 Google Sheet 标记帖子已发布

### 可选自定义

- 修改 workflow 以包含额外平台或进一步自定义 AI 生成的内容。
