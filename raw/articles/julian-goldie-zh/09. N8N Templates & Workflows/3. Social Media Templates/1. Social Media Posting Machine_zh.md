此 workflow 面向内容创作者、社交媒体经理和营销团队，需高效跨多个社交平台创作并发布内容。对于希望在 X (Twitter)、Instagram、Facebook、LinkedIn、Threads 和 YouTube Shorts 上保持持续存在感、又不愿耗费数小时手动撰写各平台专属内容的企业而言，此 workflow 十分合适。

## 此 workflow 解决了什么问题？

为不同社交平台定制内容耗时费力，且需了解每个平台的独特要求和受众期望。此 workflow 解决以下挑战：

- 在各平台间保持一致的消息传递，同时尊重各平台的特定格式
- 根据各平台最佳实践生成优化后的内容
- 无需平面设计技能即可制作配套视觉素材
- 简化发布前的审批流程
- 减少重复性内容创作所花费的时间

## 此 workflow 的功能

此自动化内容工厂接收你的内容创意，并将其转化为适用于所有主要社交媒体的平台优化帖子。workflow 流程如下：

1. 通过聊天界面接收你的内容创意或主题
2. 利用 AI 为各平台生成定制内容（X/Twitter、Instagram、Facebook、LinkedIn、Threads、YouTube Shorts）
3. 使用 AI 图像生成合适的配图
4. 通过邮件发送内容供审批，再行发布
5. 维护聊天记忆以改善未来的内容生成

## 设置步骤

- 连接你的社交平台凭证（X/Twitter、Instagram、Facebook、LinkedIn）
- 设置用于审批流程的电子邮件账户
- 配置 OpenAI API key 用于 AI 内容生成
- 更新图像生成服务凭证（默认使用 Pollinations.ai）
- 在 Google Docs nodes 中自定义 system prompts 和 schemas，匹配你的品牌语气和内容要求

## 如何自定义此 workflow

- 修改 Google Docs nodes 中的 system prompts 以匹配你的品牌语气和内容策略
- 调整社交媒体 schemas，加入与你内容相关的具体字段
- 根据需要让额外利益相关者参与审批流程
- 根据营销策略增删社交平台
- 自定义图像生成 prompts 以更好地匹配你的视觉品牌风格
- 与现有的内容日历或 CRM 系统集成

此 workflow 消除了手动为各平台制作同一内容不同版本的需求，在节省数小时工作量的同时，确保你的社交媒体存在感和一致性，实现最优互动效果。
