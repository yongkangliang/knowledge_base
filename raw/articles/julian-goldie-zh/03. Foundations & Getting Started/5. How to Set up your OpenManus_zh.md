# 5. 如何设置你的 OpenManus

https://youtu.be/VpCYyGA29Ow
Github 地址如下
免费 API 方法？设置 Hyperbolic 或 Groq 的 API key = 免费！
操作步骤：
步骤 1：
conda create -n open_manus python=3.12
conda activate open_manus
步骤 2：
git clone https://github.com/mannaandpoem/OpenManus.git
cd OpenManus
步骤 3：
pip install -r requirements.txt
步骤 4：
cp config/config.example.toml config/config.toml
步骤 5：
nano config/config.toml
步骤 6：
配置全局 LLM 设置 > 插入你的 API key
步骤 7：
Control + X > Y > Enter
步骤 8：
python main.py
步骤 9：
测试一下
步骤 10：
有问题？截图问题 + 粘贴到终端，附上 GitHub 指令。
如何设置 API Key：
# 全局 LLM 配置
[llm]
model = "gpt-4o"
base_url = "https://api.openai.com/v1"
api_key = "sk-..." # 替换为你的实际 API key
max_tokens = 4096
temperature = 0.0
# 特定 LLM 模型的可选配置
[llm.vision]
model = "gpt-4o"
base_url = "https://api.openai.com/v1"
api_key = "sk-..." # 替换为你的实际 API key
