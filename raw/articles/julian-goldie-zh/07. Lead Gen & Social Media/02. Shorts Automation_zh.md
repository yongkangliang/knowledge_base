# 02. Shorts 自动化

https://youtu.be/_zjGDnAec0I

剪辑 Shorts 的标准操作流程（SOP）

创建 Shorts 的提示词：

创作 3 个版本的短视频

不应该让人觉得是在推销这个工具——我只是想让观众大开眼界

严格围绕主题展开。包含一个主钩子和一个次级钩子，保持简短有力，让观众一直猜……比如"不是 X 也不是 Y"

分成 3 段，方便分段录制

一定要非常可操作 + 包含钩子和次级钩子

像这样解释："这里有 3 个简单步骤教你怎么做..."

让观众产生情绪共鸣（比如惊讶、不服），让它像一个疯狂又有趣的独白

次级钩子应该真正制造悬念，让观众继续看下去……同时加入一个故事

将语言难度降到小学三年级或更简单

让它感觉新、大、简单、安全：比如紧急、突发新闻、刚刚发布等

钩子示例：

- 正在寻找 X 来帮你做 Y？
- 3 种方法……
- 如果我告诉你……
- 如果你在 X 上有困难，这里有 3 个 Y 你可以使用……
- 你是否（害怕）去（达成某个结果）

次级钩子示例：

- 不要犯这个错误……
- 太疯狂了！原因如下……
- 这里有 2 个例子
- 这里有 2 个原因……

格式：使用这个 3 步流程，根据我的标题创意创建脚本：

第一部分：钩子

如今我们都知道什么是钩子。应尽可能快地抓住注意力。尽量保持简短，在几秒钟内传达。（3-5 秒）

- 例如：如果潜在客户说"太贵了"，这样说……

第二部分：次级钩子（激发兴趣）

应增加上下文或进一步说明为什么他们应该继续阅读内容。

- 例如：99% 的销售人员在这点上完全搞错了。

第三部分：兑现钩子承诺

很简单，兑现你在钩子中提到的内容。尽量去除所有废话，尽快切入正题。
